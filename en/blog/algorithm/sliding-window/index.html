## Expansion and contraction in a minimum covering window

Expansion and contraction in a minimum covering window

After coverage is satisfied, keep shrinking until removing one more character would invalidate it. This relies on monotonicity of coverage; two pointers cannot be applied blindly to problems without that structure.

Problem structure and state design

  • The target is a contiguous subarray or substring whose state can be updated incrementally as elements enter and leave. A fixed-length window follows its right edge. For variable length, prove that both boundaries can move only forward without missing answers.
  • For Minimum Window Substring, expansion cannot destroy existing coverage. Once valid, shrink to find the shortest valid window for that right endpoint. Longest-valid-window problems instead often shrink while invalid and update the answer at a different point.
  • For Sliding Window Maximum, a newer, larger element dominates an older, smaller one: the latter expires sooner and can never become a future maximum. Remove it from the candidate deque’s back.
  • Contiguity alone is insufficient. With negative values, expansion need not increase a sum. A sum-equals-K problem generally calls for prefix sums rather than shrinking a window according to its sum.

Example 1: Sliding Window Maximum (hard)

Problem: LeetCode 239

from collections import deque

class Solution:
    def maxSlidingWindow(self, nums, k):
        q = deque()
        ans = []

        # 把窗口内最大数放在queue头，出窗口则pop掉即可
        for r in range(len(nums)):
            while q and nums[q[-1]] < nums[r]:  # 删除比当前小的原素
                q.pop()
            # 已经没有比当前小的原素，因此可以把index加入表
            q.append(r)
            # 检查left是不是在，不在则删除出窗口内容
            if q[0] < r - k + 1:
                q.popleft()
            # 更新
            if r >= k - 1:
                ans.append(nums[q[0]])
        
        return ans

Implementation: q stores indices whose values decrease from front to back. Remove smaller tail candidates when a new element arrives, and remove the front if it has left the window. The front is then the maximum. Each index enters and leaves at most once, giving O(n) time.

Example 2: Minimum Window Substring (hard)

Problem: LeetCode 76

from collections import Counter, defaultdict

# 请选择 Python3 提交代码，而不是 Python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        cs = Counter()
        ct = Counter(t)
        ans_l, ans_r = -1, len(s)
        l = 0
        for r, ch in enumerate(s):
            cs[ch] += 1
            # 涵盖则挪左边
            while cs >= ct:
                if r - l < ans_r - ans_l:
                    ans_r, ans_l = r, l
                # 挪动l使得到下一个循环
                cs[s[l]] -= 1
                l += 1
        return "" if ans_l < 0 else s[ans_l: ans_r + 1]

Reasoning: Expand the right edge until cs >= ct means every character of t is covered with its required multiplicity. Advance the left edge while coverage remains valid. Once removing a necessary character breaks coverage, expand right again. First obtain a feasible window, then make it as small as possible.
