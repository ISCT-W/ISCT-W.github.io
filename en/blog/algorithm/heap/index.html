## Maintain a median through the two boundary values

Maintain a median through the two boundary values

Two heaps retain the largest value of the smaller half and the smallest value of the larger half. Their sizes must differ by at most one, and every value on the left must remain no greater than every value on the right.

Recognize the structure first

A heap avoids repeated full sorting when candidates arrive or disappear and you only need the current minimum or maximum. For a running median, split the data into smaller and larger halves and maintain their boundary values. A heap guarantees the best element at the top; its internal array is not globally sorted.

Core idea

Heaps suit repeated minimum or maximum extraction. Python’s heapq is a min-heap; negating values gives max-heap behavior.

Teaching skeletons

Define a priority before repeatedly extracting the top. The pseudocode retains placeholders for candidate processing. For state objects, (priority, unique_id, state) prevents equal priorities from triggering comparisons between unorderable objects.

while 堆非空:

    若采用了保留旧条目的更新策略，先检查它是否过期
    处理候选；若产生新候选，按优先级入堆

A two-heap median maintains two invariants: every value in the smaller half is no greater than every value in the larger half, and the smaller half has the same number of elements or one extra.

插入 x:
    x 先进入较小半边的大顶堆
    把大顶堆最大值移到较大半边的小顶堆，恢复两边大小关系
    若小顶堆数量更多，把其最小值移回大顶堆
查询中位数（至少已有一个数）:
    数量为奇数：取大顶堆堆顶
    数量为偶数：取两堆堆顶的平均值

Example: Find Median from Data Stream (hard)

Problem: LeetCode 295

import heapq

class MedianFinder:
    # 维护一个最小堆和一个最大堆，保证，最大堆的所有值比最小堆的小且两边堆数量不差超过1，那pop出来的就是中位数
    def __init__(self):
        self.min_heap = []
        heapq.heapify(self.min_heap)
        self.max_heap = []
        heapq.heapify(self.max_heap)

    def addNum(self, num: int) -> None:
        heapq.heappush(self.max_heap, -num) # 先放到大顶堆 - 可以保证大顶堆一定不少于小顶堆，方便维护
        # 数字丢到小顶堆，保证大顶所有数都比小顶小
        heapq.heappush(self.min_heap, -heapq.heappop(self.max_heap))
        # 平衡数量
        if len(self.min_heap) > len(self.max_heap):
            heapq.heappush(self.max_heap, -heapq.heappop(self.min_heap))

    def findMedian(self) -> float:
        # 奇数 则max_heap多一个
        if len(self.max_heap) > len(self.min_heap):
            return -self.max_heap[0]
        
        # 偶数 则每个堆一个
        return (-self.max_heap[0] + self.min_heap[0]) / 2


# Your MedianFinder object will be instantiated and called as such:
# obj = MedianFinder()
# obj.addNum(num)
# param_2 = obj.findMedian()

Reasoning: A max-heap stores the smaller half and a min-heap the larger half. Maintain ordering across the split and let the max-heap have equal size or one extra element. Insert through both heaps to establish ordering, then rebalance sizes. With an odd count, return the max-heap’s top; with an even count, average both tops.
