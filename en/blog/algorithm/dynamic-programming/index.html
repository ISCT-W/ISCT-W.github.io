## In one-dimensional knapsack, direction determines which round you read

WJunhao WeiAbout 6 min read

In one-dimensional knapsack, direction determines which round you read

View diagram structure (original)
flowchart TD
 A["状态：容量 j 的最优值或可达性"] --> B{"物品可重复使用？"}
 B -->|每件一次| C["j 从大到小"]
 C --> D["读取上一轮的 dp[j-w]"]
 B -->|可以重复| E["j 从小到大"]
 E --> F["允许读取本轮的 dp[j-w]"]

Descending updates prevent the current item from being reused within the same round. Ascending updates allow newly updated states to participate again. This is the easiest distinction to get wrong between 0/1 and unbounded knapsack.

Recognize the structure first

If different choices repeatedly reach the same state, and that state contains everything needed to determine subsequent results, store its answer to avoid recomputation. For optimization problems, also establish that an optimal solution can be obtained from optimal solutions of those subproblems.

Problem structure State and pattern Key justification
Use each number at most once; determine whether a target sum is possible 0/1 knapsack: dp[j] records reachability of j Only reachable sums matter; do not reuse the current item
Reuse denominations; minimize the number needed for a sum Unbounded knapsack: dp[j] is the minimum count for j After taking one value, the remaining target is the same kind of subproblem
Match, delete, insert, or replace characters in two strings Two-sequence DP: dp[i][j] answers a pair of prefixes Comparing final characters reduces the problem to shorter prefixes

Define the state and invariant

Answer four questions: What does dp mean? How is it initialized? How do known states produce new ones? Which traversal order ensures all dependencies are available?

Algorithm skeletons

The three patterns below retain the original placeholders for targets, items, and transitions. After compression to one dimension, traversal direction determines whether a transition reads the previous round or the current one.

# 0/1 背包：每个物品只能取一次；这里演示可达性
dp[0] = True，其余为 False
for 数值 x in 物品:
    for j 从目标倒序到 x:
        dp[j] = dp[j] or dp[j - x]

# 完全背包：每种物品可以反复取；这里演示最少数量
dp[0] = 0，其余为无穷大
for 数值 x in 物品:
    for j 从 x 正序到目标:
        dp[j] = min(dp[j], dp[j - x] + 1)

# 双序列 DP：dp[i][j] 对应 A[:i] 和 B[:j]
建立 (len(A) + 1) × (len(B) + 1) 的表
按题意初始化空前缀对应的第一行、第一列
for i 从 1 到 len(A):
    for j 从 1 到 len(B):
        比较 A[i - 1] 与 B[j - 1]
        从 dp[i - 1][j]、dp[i][j - 1]、dp[i - 1][j - 1]
        中选择题意允许的转移，写入 dp[i][j]
返回目标状态

An empty prefix has an LCS length of 0, while its edit distance to another prefix is that prefix’s length. A two-dimensional DP cannot always be reduced to one row: first establish how every dependency will be retained.

One-dimensional DP

Example 1: Partition Equal Subset Sum

Problem: LeetCode 416

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        summ = sum(nums)
        nums.sort(key=lambda x: -x)
        if summ % 2 or nums[0] > summ // 2: return False
        dp = [0 for _ in range(summ + 1)]
        dp[0] = 1

        for n in nums:
            for i in range(len(dp) - 1, 0, -1):
                if i >= n:
                    dp[i] = dp[i] or dp[i - n]
        return dp[summ // 2] == 1

Implementation: The question becomes whether a subset sums to half the total. dp[i] means sum i is reachable. Each number is available once, so iterate capacities downward to prevent reusing it in the same round.

class Solution:

        # 背包问题：把东西往背包放（外层东西，内层背包）
        # 背包外圈循环物品，内圈循环背包容量；零一背包遵循内圈从大往小循环，完全背包遵循内圈从小往大循环。
            # 0/1 背包倒序：避免当前物品在同一轮被重复使用。
            # 完全背包正序：允许当前物品在同一轮被重复使用。
            
        dp = [100000] * (n + 1)
        dp[0] = 0
        sqaures = [i * i for i in range(1, int(math.sqrt(n)) + 1)]
        for s in sqaures:
            for j in range(s, n + 1): # 放背包
                dp[j] = min(dp[j], dp[j - s] + 1)
        return dp[n]

Implementation: Each perfect square is an unlimited item. dp[j] stores the fewest squares summing to j. Ascending capacities let an updated dp[j-s] reuse the same square.

Two-dimensional DP

Example 3: Longest Common Subsequence

Problem: LeetCode 1143

class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        # 再长也超不过短的字符串长度
        dp = [[0 for _ in range(len(text1) + 1)] for _ in range(len(text2) + 1)]
        
        for i in range(1, len(dp)): 
            for j in range(1, len(dp[0])):
                if text2[i - 1] == text1[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else: dp[i][j] = max(dp[i][j - 1], dp[i - 1][j])
        return dp[-1][-1]

Implementation: dp[i][j] is the LCS length of the first i characters of text2 and first j of text1. Matching final characters extend dp[i-1][j-1]. Otherwise, drop either final character and take the better result.

Example 4: Edit Distance

Problem: LeetCode 72

class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        dp = [[i for i in range(len(word1) + 1)] for _ in range(len(word2) + 1)] # 一边长n一边长0的编辑距离一定为n 同理要修轴向
        for i in range(len(dp)):
            dp[i][0] = i
        dp[0][0] = 0 # 用来防止边界问题

        for i in range(1, len(dp)):
            for j in range(1, len(dp[0])):
                if word1[j-1] == word2[i-1]: # 这位一样那么和去掉这位的编辑距离一样
                    dp[i][j] = dp[i-1][j-1]
                else: # 这位不一样就从三种最近可能里取最小再加一即可
                    dp[i][j] = min(dp[i][j-1], dp[i-1][j], dp[i-1][j-1]) + 1
        return dp[-1][-1]

Implementation: dp[i][j] is the minimum number of operations to turn word1[:j] into word2[:i]. Matching characters use the diagonal state unchanged. Otherwise take the minimum over deletion, insertion, and replacement, then add one. The first row and column describe repeated insertions or deletions between an empty string and a nonempty prefix.

Loop direction in the two knapsack variants

  • 0/1 knapsack: Each item is usable once; update capacities downward.
  • Unbounded knapsack: Items may be reused; update capacities upward.
