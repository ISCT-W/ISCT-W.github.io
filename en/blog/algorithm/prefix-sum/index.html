## Fix the right endpoint and look up a previous prefix

Fix the right endpoint and look up a previous prefix

An interval sum is the difference of two prefixes. Query before recording the current prefix to avoid pairing it with itself. The initial occurrence of prefix 0 represents intervals beginning at the start of the array.

Problem structure and state design

Use prefix sums for repeated contiguous-range sums or counting subarrays with a sum condition. Let P[i] be the sum of the first i elements and P[0] = 0. The half-open interval [l, r) then sums to P[r] - P[l], including when values are negative.

Objective Justification Historical state
Count subarrays summing to K P[r] - P[l] = K; look for earlier P[r] - K Frequency of each prefix sum
Maximum subarray sum For a fixed right endpoint, subtract the smallest earlier prefix Minimum prefix sum
Product of array except self Removing position i leaves a left and a right segment Exclusive prefix and suffix products

For the first two, calculate the answer from earlier prefixes before adding the current prefix, excluding empty intervals. The third uses products, not differences; it needs no division and handles zeros.

Teaching skeletons

Implement the Chinese descriptions and mathematical intervals for the actual problem. The maximum-subarray skeleton assumes a nonempty input.

统计和为 K 的非空子数组：
    prefix = 0，count = {0: 1}，ans = 0
    for x in nums：
        prefix += x
        ans += count.get(prefix-K, 0)
        count[prefix] = count.get(prefix, 0) + 1

求非空子数组最大和：
    prefix = 0，min_prefix = 0，ans = -∞
    for x in nums：
        prefix += x
        ans = max(ans, prefix-min_prefix)
        min_prefix = min(min_prefix, prefix)

排除自身的乘积：
    n = len(nums)，left 和 right 均初始化为 n 个 1
    从左往右：left[i] = left[i-1] * nums[i-1]（i 从 1 开始）
    从右往左：right[i] = right[i+1] * nums[i+1]（i 从 n-2 开始）
    ans[i] = left[i] * right[i]

Example 1: Subarray Sum Equals K

Problem: LeetCode 560

class Solution:
    def subarraySum(self, nums, k):
        # 从左到右扫描，维护当前前缀和 prefix，同时用 count 记录“之前每个前缀和出现过几次”。
        ans = 0
        prefix = 0
        count = {0: 1}

        for num in nums:
            prefix += num

            if prefix - k in count:
                ans += count[prefix - k]

            count[prefix] = count.get(prefix, 0) + 1

        return ans

Implementation: If the current sum is prefix, every previous prefix - k defines a subarray summing to k. {0: 1} includes subarrays beginning at index zero.

Example 2: Maximum Subarray

Problem: LeetCode 53

class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        max_s = -10000
        min_prefix = 0
        sum_s = 0

        for num in nums:
            sum_s += num # 统计所有
            max_s = max(max_s, sum_s - min_prefix, sum_s)
            min_prefix  = min(min_prefix, sum_s)

        return max_s

Implementation: The best subarray ending here is the current prefix minus the smallest earlier prefix. Update min_prefix only after updating the answer, so the current prefix is not used as the interval’s start.

Example 3: Product of Array Except Self

Problem: LeetCode 238

class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        prefix, suffix = [1] * len(nums), [1] * len(nums)
        res = [0] * len(nums)
        # prefix[0], suffix[-1] = nums[0], nums[-1]
        for i in range(1, len(nums)):
            prefix[i] = nums[i - 1] * prefix[i - 1]
        for j in range(len(nums) - 2, -1, -1):
            suffix[j] = nums[j + 1] * suffix[j + 1]

        for k in range(len(nums)):
            res[k] = prefix[k] * suffix[k]
        return res

Implementation: prefix[i] multiplies everything to the left of i; suffix[i] multiplies everything to its right. Their product naturally excludes nums[i].
