Binary search: keep the interval that can contain the answer

## Keep the interval that may contain the answer

WJunhao WeiAbout 7 min read

Keep the interval that may contain the answer

The diagram follows the convention “find the first position satisfying a condition.” Other binary-search problems require their own predicates and boundary definitions; the update rules are not interchangeable.

Recognize the structure first

Binary search applies when candidates can be ordered and one check proves that the answer must lie on one side. A typical predicate changes only once from false to true. Another common argument is that a candidate is too large or too small, making every more extreme candidate invalid as well.

  • Minimum in a rotated array: With distinct elements, nums[i] <= nums[-1] is false in the high segment and true in the low segment. Find the first true position. If the array is not rotated, every position satisfies it.
  • Median of two sorted arrays: Search the partition position in the shorter array. Take more elements from it if the left partition is too small, or fewer if it is too large. The internal ordering of both arrays justifies these moves.

Define the state and invariant

The essential idea is a monotone condition that eliminates half the search space, rather than simply choosing a middle element. Define what the interval means before entering the loop. When moving a boundary, decide whether mid could still be the answer and therefore must remain in the interval.

Teaching skeletons

The first version finds the first position satisfying a monotone condition. Implement check(i) for a sequence of results shaped like False, ..., False, True, ..., True. Returning n means no position satisfies the condition.

left, right = 0, n  # 答案在 [left, right]，n 是未找到的哨兵
while left < right:
    mid = (left + right) // 2
    if check(mid):
        right = mid  # mid 仍可能是第一个成立的位置
    else:
        left = mid + 1
answer = left

The second searches for a partition satisfying constraints. Here is its pseudocode:

在较短数组的所有分割位置 [0, m] 中搜索
while left <= right:
    i = 中间分割位置
    j = 要求的左半总长度 - i
    if i 太小: left = i + 1
    elif i 太大: right = i - 1
    else: 根据分割两侧的边界值计算答案并返回

Boundary updates must match the search objective. Explain why one side can be eliminated before choosing between mid and mid ± 1.

Example 1: Find Minimum in Rotated Sorted Array

Problem: LeetCode 153

class Solution:
    def findMin(self, nums: List[int]) -> int:
        # 旋转后的数组是两段升序数组[A, B]构成，其中A的所有元素都大于B的任何元素（注意，如果没旋转则只有一段）；
        # 因此，最小值一定是B的第一个元素（如果没旋转则是A的第一个）
        # 所以用二分查找去找到分界点即可！
            # mid > nums[-1]：m还在A，最小在右半； mid < nums[-1]：m在B，最小在左半；不停缩小最小区间即可
        l, r = 0, len(nums) - 1

        while l < r:
            m = (l + r) // 2
            if nums[m] > nums[-1]:
                l = m + 1
            else: r = m # 为什么保留m而不是m-1？因为m自己可能就是最小值
        return nums[l]

Implementation: Compare with the last element to tell whether mid is in the high or low segment. If nums[m] > nums[-1], the minimum is strictly to the right. Otherwise, m may itself be the minimum, so set r = m.

Example 2: Median of Two Sorted Arrays (hard)

Problem: LeetCode 4

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        # 核心思想很简单，对两个数组找分界线，使得分界线满足下面要求，然后这两分界线的位置刚好对应中位即可。
        # merged = nums1 + nums2
        # merged.sort()

        # mid = (len(merged) - 1) // 2
        # return merged[mid] if len(merged) % 2 else (merged[mid] + merged[mid + 1]) / 2
    
        """
        问题理解:
        首先，我们需要明确什么是中位数：对于一个有序数组，如果长度是奇数，中位数就是中间那个数；如果是偶数，中位数是中间两个数的平均值。
        对于两个有序数组，我们需要找到合并后的有序数组的中位数。直接合并再找中位数的时间复杂度是O(m+n)，不符合题目要求。我们需要更高效的O(log(min(m,n)))的解法。

        核心思路：二分查找分割线
        我们可以将问题转化为在两个数组中寻找合适的分割线，使得分割线左边的所有元素都小于等于右边的所有元素，并且左右两边的元素数量相等或左边多一个。
        具体来说：
        我们需要在较短的数组上进行二分查找（为了优化时间复杂度）
        对于每个可能的分割位置，计算另一个数组的对应分割位置（见下）
        检查分割线是否满足条件（左边最大值 ≤ 右边最小值）
        根据比较结果调整二分查找的范围

        详细步骤:
        确保第一个数组是较短的：这样我们可以将时间复杂度优化到O(log(min(m,n)))
        定义分割线：分割线将数组分为左右两部分
        对于数组A，分割线在i的位置，左边有i个元素，右边有m-i个元素
        对于数组B，分割线在j的位置，左边有j个元素，右边有n-j个元素

        理想分割条件：
        i + j = (m + n + 1) / 2（确保左边元素数量足够）
        A[i-1] ≤ B[j] 且 B[j-1] ≤ A[i]（左边最大值 ≤ 右边最小值）

        二分查找过程：
        初始化二分查找范围：iMin = 0, iMax = m
        计算i = (iMin + iMax) / 2
        计算j = (m + n + 1) / 2 - i
        根据比较结果调整iMin或iMax
        """
        # 确保nums1是较短的数组
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
        
        m, n = len(nums1), len(nums2)
        imin, imax, half_len = 0, m, (m + n + 1) // 2
        
        while imin <= imax:
            i = (imin + imax) // 2
            j = half_len - i
            
            # 处理边界情况
            if i < m and nums2[j-1] > nums1[i]:
                # i太小，需要增大
                imin = i + 1
            elif i > 0 and nums1[i-1] > nums2[j]:
                # i太大，需要减小
                imax = i - 1
            else:
                # 找到合适的分割线，处理中位数计算
                
                # 计算左半部分最大值
                if i == 0:
                    max_of_left = nums2[j-1]
                elif j == 0:
                    max_of_left = nums1[i-1]
                else:
                    max_of_left = max(nums1[i-1], nums2[j-1])
                
                # 如果总数是奇数，直接返回左半部分最大值
                if (m + n) % 2 == 1:
                    return max_of_left
                
                # 计算右半部分最小值
                if i == m:
                    min_of_right = nums2[j]
                elif j == n:
                    min_of_right = nums1[i]
                else:
                    min_of_right = min(nums1[i], nums2[j])
                
                # 如果是偶数，返回平均值
                return (max_of_left + min_of_right) / 2.0

Reasoning about the partition

Do not merge the arrays. Place a partition in each array so that the total left side has either the same number of elements as the right side or one more, while satisfying:

nums1[i - 1] <= nums2[j]
nums2[j - 1] <= nums1[i]

Search only the shorter array’s partition i; the other is fixed by j = half_len - i.

  • nums2[j - 1] > nums1[i]: i is too small; move right.
  • nums1[i - 1] > nums2[j]: i is too large; move left.
  • Otherwise, the partition is valid. For an odd total length, take the maximum of the left side. For an even length, average that maximum and the minimum of the right side.

Partitions can fall at either end of an array, so the code handles i == 0, j == 0, i == m, and j == n explicitly.
