Graphs, BFS, and tries: similar nodes, different invariants

These three Hot 100 problems share a “graph” category but use different patterns: multi-source BFS for Rotting Oranges, topological sorting for Course Schedule, and a tree-based data structure for Trie.

Define the state before choosing a data structure. Several algorithms use a queue, but its entries and the conditions for removing them differ.

Problem structure and state design

Evidence in the problem Pattern Meaning to preserve
Equal-time transitions; minimum steps or simultaneous spread from several starts Multi-source BFS Process distance layers; mark nodes when enqueued to prevent repeated propagation
Directed prerequisites: finish A before B Topological sorting Indegree counts unmet dependencies; process only zero-indegree nodes
Repeated word insertion, exact lookup, and prefix lookup Trie The root-to-node path is a prefix; exact words also need a terminal marker or separate set

BFS’s minimum-step result relies on equal edge costs. Topological sorting tracks satisfied dependencies. A trie follows character paths. The presence of “nodes” does not make these algorithms interchangeable.

Algorithm skeletons

# 多源 BFS：每一层对应同一时刻
将所有起点标记并入队
时间 = 0
while 队列非空且仍有待到达的目标:
    当前层数量 = len(队列)
    重复当前层数量次:
        取出节点 u
        for u 的每个合法且未访问的邻居 v:
            标记 v，更新剩余目标数，将 v 入队
    时间 += 1
根据剩余目标是否为 0 判断是否全部到达

# Kahn 拓扑排序：建边 A -> B，表示 A 是 B 的前置条件
建立邻接表和入度，将所有入度为 0 的节点入队
已处理数量 = 0
while 队列非空:
    取出节点 u，已处理数量 += 1
    for u 指向的每个节点 v:
        入度[v] -= 1
        if 入度[v] == 0: 将 v 入队
已处理数量 == 节点总数，才说明无环且能全部完成

# Trie：插入和查询都从根开始，每次消耗一个字符
插入(word):
    node = 根
    for 字符 ch in word:
        若 ch 对应的子节点不存在，则创建
        node = node 的 ch 子节点
    标记 node 为单词结尾（或将 word 放入完整词集合）
查询(text, 是否要求完整词):
    从根逐字符向下，任一边不存在就返回 False
    若查前缀，路径走完就返回 True
    若查完整词，还要验证结束标记（或完整词集合）

Example 1: Rotting Oranges

Problem: LeetCode 994

from collections import deque

class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        # 先找到所有的新鲜橘子记录个数为fresh，并找到所有腐烂橘子在deque进行多源BFS即可。
        fresh = 0
        directions = [[-1, 0], [1, 0], [0, -1], [0, 1]]
        m, n = len(grid), len(grid[0])
        rots = deque()

        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    fresh += 1
                if grid[i][j] == 2:
                    rots.append([i, j])
        minutes = 0
        while rots and fresh:  # 继续条件：有fresh并且还能继续rot
            for _ in range(len(rots)):
                u, v = rots.popleft()
                for d in directions:
                    if 0 <= u + d[0] <= m - 1 and 0 <= v + d[1] <= n - 1 and grid[u + d[0]][v + d[1]] == 1:
                        grid[u + d[0]][v + d[1]] = 2
                        rots.append([u + d[0], v + d[1]])
                        fresh -= 1
            minutes += 1
        return minutes if not fresh else -1

Implementation: Enqueue every rotten orange at once. Each round processes only the nodes present at its start and represents one minute. Newly rotten oranges spread in the next round. Any remaining fresh oranges are unreachable.

Example 2: Course Schedule

Problem: LeetCode 207

from collections import defaultdict

class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        # 拓扑排序：
        # 入度为 0 的课，说明它没有先修课，可以直接学。
        # 每次把入度为 0 的课“修掉”，
        # 它指向的下一门课入度 -1。
        # 如果最后所有课都能修完，说明无环。
        
        # 邻接表：graph[b]存所有以b为前置课的课
        graph = [ [] for _ in range(numCourses) ]

        # 入度数组： in_degree[i] 表示i还有多少门前置课没修
        in_degree = [0] * numCourses

        # 建图：[ a, b ] 表示先修b才能修a
        for a , b in prerequisites:
            graph[b].append(a)
            in_degree[a] += 1
        
        # 初始入队所有入度为0的课(没有前置可直接修)
        queue = deque( i for i in range(numCourses) if in_degree[i] == 0 )
        finished = 0

        # 每弹出一门课，代表修完它，把它指向的课入度-1
        while queue:
            x = queue.popleft()
            finished += 1

            for y in graph[x]:
                in_degree[y] -= 1
                if in_degree[y] == 0:
                    queue.append(y)

        # 如果修完的课数等于总课数，说明无环
        return finished == numCourses

Implementation: Kahn’s algorithm repeatedly removes courses of indegree 0. If fewer than all courses are processed, a cycle exists. Remaining nodes may lie on the cycle or downstream of it.

The original submission is preserved. For standalone execution, add from collections import deque; the imported defaultdict is unused here.

Example 3: Implement Trie (Prefix Tree)

Problem: LeetCode 208

class Node:
    def __init__(self, val=0):
        self.val = val
        self.next = {}

class Trie:
    def __init__(self):
        self.root = Node()  # 服务于startwith
        self.contents = set()  # 服务于search

    def insert(self, word: str) -> None:
        self.contents.add(word)
        head = word[0]
        if head not in self.root.next.keys():
            new_node = Node(head)
            self.root.next[head] = new_node
        
        head = self.root.next.get(word[0])        
        for i in range(1, len(word)):
            if word[i] in head.next:
                cur_node = head.next[word[i]]
            else:
                cur_node = Node(word[i])
                head.next[word[i]] = cur_node
            head = cur_node
        return

    def search(self, word: str) -> bool:
        return True if word in self.contents else False

    def startsWith(self, prefix: str) -> bool:
        head = self.root
        for i in range(len(prefix)):
            if prefix[i] not in head.next.keys():
                return False
            head = head.next.get(prefix[i])
        return True
    

# Your Trie object will be instantiated and called as such:
# obj = Trie()
# obj.insert(word)
# param_2 = obj.search(word)
# param_3 = obj.startsWith(prefix)

Implementation: Each node’s next maps characters to children. Insertion constructs the character path; startsWith only checks that it exists. This implementation uses a separate contents set for exact-word lookup.
