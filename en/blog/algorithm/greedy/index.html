## Closing a partition’s boundary

WJunhao WeiAbout 3 min read

Closing a partition’s boundary

View diagram structure (original)
flowchart TD
 Q{"还有未扫描的字符？"} -->|否| Z["返回所有片段长度"]
 Q -->|是| A["扫描下一个位置 i"]
 A --> B["end = max(end, 当前字符最后位置)"]
 B --> C{"i 已到达 end？"}
 C -->|否| Q
 C -->|是| D["记录当前片段长度"]
 D --> E["下一个片段从 i+1 开始"]
 E --> Q

Every occurrence of a character in a partition must stay in that partition. The furthest last occurrence therefore defines a necessary boundary. Cutting as soon as the scan reaches it adds no restrictions to later partitions.

Recognize the structure first

Use greedy reasoning when there is a sequence of local choices and you can prove that making the chosen move still permits an optimal continuation. Exchange arguments, unavoidable bounds, and invariants are common proofs. A request for a maximum or minimum alone is not enough.

In Partition Labels, a partition must contain the final occurrence of each character it includes. Its end cannot precede the largest of those positions. Cutting at the earliest valid end leaves the remainder unrestricted and preserves as many future cuts as possible.

Core idea

At each step, choose the currently favorable option. The important part is proving it cannot harm the optimal continuation. A common pattern maintains the furthest boundary that the current interval must reach.

Steps and teaching skeleton

Define the local choice, prove it safe, then identify the state to maintain. There is no universal greedy implementation. This skeleton covers only “track the furthest required end, then cut at the earliest valid position.”

求出每个元素要求覆盖到的位置（本题是字符最后出现的位置）
start = 0，end = 0
for 位置 i 从左到右:
    end = max(end, 当前元素要求覆盖到的位置)
    if i == end:
        记录区间 [start, end]
        start = i + 1

When reviewing, explain both why cutting before end is invalid and why cutting immediately at end cannot worsen the answer.

Example: Partition Labels

Problem: LeetCode 763

class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        if len(s) == 1: return [1]
        l, max_r = 0, -1
        ans = []
        for i, ch in enumerate(s):
            cur_r = i # 防止根本就没有重复导致的一路走到尾！！！！
            for j in range(i+1, len(s)):
                if s[j] == ch:
                    cur_r = j
            max_r = max(max_r, cur_r) # 每次找到当前最右并更新直到相遇就说明是一个串了
            if i == max_r: # 已经找完
                ans.append(max_r - l + 1)
                l = i + 1
                
        return ans

Implementation: Scan the partition’s characters and extend max_r to their last occurrences. At i == max_r, none of its characters will appear later, so the partition can end immediately.

This code scans the remaining suffix for each last occurrence and takes O(n²) in the worst case. Precomputing last positions in a hash table reduces the same greedy approach to O(n).
