Linked lists: preserve the next node before rewiring

## Save the unprocessed part before reversing

WJunhao WeiAbout 7 min read

Save the unprocessed part before reversing

View diagram structure (original)
flowchart TD
 A["prev = 空，curr = 原链表头"] --> B{"curr 非空？"}
 B -->|否| Z["返回 prev：反转后的头"]
 B -->|是| C["先保存 nxt = curr.next"]
 C --> D["令 curr.next 指向 prev"]
 D --> E["prev 移到 curr，curr 移到 nxt"]
 E --> B

Save the original successor before changing a pointer so that the remaining list is not lost. After each iteration, prev points to the completed part and curr to the unprocessed part.

Recognize the structure first

Goal Approach and justification
Reverse, delete, or rearrange nodes Rewire local next pointers after saving the unprocessed successor
Detect a cycle or find its entry Different pointer speeds cause a meeting inside a cycle; without a cycle, the fast pointer reaches null
Reverse groups of K Split into a complete group and the remaining list; verify K nodes, reverse, and attach the recursive result
LRU lookup and recency changes in O(1) A hash table locates nodes; a doubly linked list removes/inserts known nodes in constant time. A singly linked list cannot directly find a predecessor

Define the state and invariant

  • Draw the pointer changes first. Check that the successor is saved before breaking a link.
  • Consider a dummy head when the head may change, and fast/slow pointers for cycles or midpoints.
  • For recursive list processing, define the contract: which range is accepted, which endpoints are returned, and who connects the next segment.

Teaching skeletons

The following pseudocode covers separate patterns. Fill in the original Chinese placeholders for each problem; do not combine them into one generic pointer loop.

迭代反转：
    pre = None，cur = head
    while cur 非空：
        next_node = cur.next       # 保存未处理部分
        cur.next = pre             # 接入已反转部分
        pre = cur，cur = next_node
    return pre

本篇递归反转 rev(cur, pre)：
    if cur 为空：return pre
    new_head = rev(cur.next, cur)
    cur.next = pre                 # 回溯时连向原前驱
    return new_head

环入口：
    slow = fast = head
    while fast 和 fast.next 非空：
        slow 前进一步，fast 前进两步
        若相遇：一个指针回到 head，两者同步前进一步直到相遇，返回该节点
    return None

K 个一组翻转：
    从 head 找满 K 个节点；不足则 return head
    保存 next_group，翻转本组，得到 new_head 和 new_tail
    new_tail.next = 递归处理(next_group, K)
    return new_head

LRU：
    初始化 key→节点 的字典及双向链表头尾哨兵
    get：未命中返回 -1；命中则移到最前并返回值
    put：已有键更新并移到最前；新键加入字典和链表最前
         若超容量，同时删除链表最后的实际节点及其字典条目

During iterative reversal, pre points to the processed part and cur to the remaining part. The recursive version changes directions while unwinding. LRU maintains the same actual nodes in its dictionary and list, with the most recently used node at the front and the least recent at the back.

Example 1: Reverse Linked List

Problem: LeetCode 206

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # pre = None
        # cur = head
        # while cur:
        #     tmp = cur.next
        #     cur.next = pre
        #     pre = cur
        #     cur = tmp
        # return pre
        
        pre = None
        def rev(cur, pre):
            if not cur: return pre
            res = rev(cur.next, cur)
            cur.next = pre
            return res
        revd = rev(head, pre)
        return revd

Implementation: The commented version is iterative; the active version is recursive. rev(cur, pre) reverses the list starting at cur and ultimately makes cur point to pre. Recursion carries the new predecessor forward, then assigns cur.next = pre while unwinding.

Example: Call rev(1, None) for 1 -> 2 -> 3 -> None:

rev(1, None)
  -> rev(2, 1)
       -> rev(3, 2)
            -> rev(None, 3)，返回节点 3

Unwinding sets 3.next = 2, 2.next = 1, and 1.next = None, then returns the new head 3.

Example 2: Linked List Cycle II

Problem: LeetCode 142

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        s, l = head, head

        while True:
            if not l or not l.next: return None
            s = s.next
            l = l.next.next
            if s == l: break
        l = head
        while l != s:
            l, s = l.next, s.next
        return l

Implementation: The fast pointer advances twice per step and the slow pointer once. After they meet, reset one to the head and move both one step at a time. Their next meeting is the cycle entry.

Why it works: Let a be the distance from the head to the entry, b from entry to first meeting, and c the cycle length. At the meeting, the fast pointer has traveled a whole number of extra cycles. This implies that a differs from the forward distance from meeting to entry by whole cycles, so equal-speed pointers meet at the entry.

Example 3: Reverse Nodes in K-Group (hard)

Problem: LeetCode 25

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        def reverse(head, tail):
            pre = tail.next
            cur = head
            while pre != tail: # 关键循环，建议自己画链子 - 先保存旧 next，然后pre接上新next，然后往后 - 其实是链表很通用的过程
                suc = cur.next
                cur.next = pre
                pre = cur
                cur = suc
            return tail, head

        if not head or not head.next: return head
        tail = head
        for _ in range(k - 1): # 找到当前的tail以进入当前修改
            tail = tail.next
            if not tail: return head
        suc = tail.next # 记录下一组的开头
        new_head, _  = reverse(head, tail) # 反转这一组
        head.next = self.reverseKGroup(suc, k) # 递归处理剩余部分
        return new_head

What grouping and recursion do

The contract of reverseKGroup(head, k) is to process the entire list starting at head and return its new head.

  1. Walk k - 1 steps to find the current group’s tail. If fewer than k nodes remain, return the list unchanged.
  2. reverse(head, tail) reverses only the closed interval [head, tail] and returns its new head (the old tail) and new tail (the old head).
  3. Save the next group’s start as suc = tail.next before the original boundary is lost.
  4. Recursively process the remainder and attach it through head.next = self.reverseKGroup(suc, k) as in the implementation’s endpoint convention.

Example: For 1 -> 2 -> 3 -> 4 -> 5 with k = 2:

  • Reverse [1, 2] into 2 -> 1, making 1 the new tail.
  • Recursively turn 3 -> 4 -> 5 into 4 -> 3 -> 5.
  • Attach the result to 1.next, producing 2 -> 1 -> 4 -> 3 -> 5.

Inside reverse, initializing pre = tail.next temporarily connects the group’s old head to the next segment. The head returned by the recursive call later replaces that connection.

Example 4: LRU Cache

Problem: LeetCode 146

class Node:
    def __init__(self, key=0, value=0): # 按照使用顺序排序
        self.key = key
        self.value = value
        self.prev = None
        self.next = None


class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache = {} # O(1)查找

        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _add_front(self, node):
        node.next = self.head.next
        node.prev = self.head

        self.head.next.prev = node
        self.head.next = node

    def get(self, key: int) -> int:
        if key not in self.cache: return -1
        
        node = self.cache.get(key)

        # 刚访问放在一开始
        self._remove(node)
        self._add_front(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        # 1. 已经有只需要更新；
        if key in self.cache:
            node = self.cache.get(key)
            node.value = value

            # 更新位置到一开始
            self._remove(node)
            self._add_front(node)

        # 2.新加入则新建节点；期间如果超过长度则remove tail.prev
        else:
            node = Node(key, value)
            self.cache[key] = node
            self._add_front(node)

            if len(self.cache) > self.capacity:
                old = self.tail.prev
                self._remove(old)
                del self.cache[old.key]

# Your LRUCache object will be instantiated and called as such:
# obj = LRUCache(capacity)
# param_1 = obj.get(key)
# obj.put(key,value)

Implementation: The hash table finds nodes in O(1); the doubly linked list removes and moves them in O(1). Nodes near head are recent, while tail.prev is least recently used. Both get and updating an existing key move its node to the front.
