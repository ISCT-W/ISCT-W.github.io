Monotonic stacks: resolve earlier candidates with the current element

## The current element resolves earlier candidates

WJunhao WeiAbout 4 min read

The current element resolves earlier candidates

In Daily Temperatures, the stack holds indices still waiting for a warmer day. Each index is pushed and popped at most once, so the total work is linear.

Recognize the structure first

  • Consider a monotonic stack for the first greater or smaller element on either side of every position, or for widths and areas determined by those boundaries.
  • Before popping, ask whether the current element determines the top’s answer or makes that candidate unnecessary. A warmer day resolves the next-greater query; a shorter bar stops a rectangle from extending rightward.
  • The stack usually stores unresolved indices. Indices stay ordered, while their values are monotone in the required direction. At most one push and pop per index gives O(n) total time.
  • Comparisons depend on whether “greater” or “smaller” is strict. Equal elements must be handled consistently with the boundary definition. The temperature and water examples retain equals in a nonincreasing stack; the rectangle example retains equals in a nondecreasing stack.

Core idea

Maintain increasing or decreasing values. Whenever a new value breaks the required order, keep popping and calculate answers for the removed entries.

The teaching pseudocode retains Chinese placeholders for the condition and answer calculation.

"""
单调栈通用模版：
1. 栈中通常保存下标，方便同时获得元素值、距离和区间宽度
2. 遍历每个元素
3. 当前元素破坏单调性时，不断弹栈并结算答案
4. 当前下标入栈
5. 必要时用哨兵处理栈内剩余元素
"""

stack = []
for i, value in enumerate(nums):
    while stack and 当前元素破坏单调性:
        j = stack.pop()
        根据 i、j 和新的栈顶计算答案
    stack.append(i)

Example 1: Daily Temperatures

Problem: LeetCode 739

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        ans = [0] * len(temperatures)
        stack = []  # 尚未找到更高温度的下标；对应温度单调递减

        for i, temperature in enumerate(temperatures):
            while stack and temperature > temperatures[stack[-1]]:
                j = stack.pop()
                ans[j] = i - j
            stack.append(i)

        return ans

Reasoning: The stack contains unresolved days. A warmer current day is the first warmer day for each popped index j; the wait is i - j.

Example 2: Trapping Rain Water

Problem: LeetCode 42

class Solution:
    def trap(self, height: List[int]) -> int:
        ans = 0
        stack = []  # 下标对应的高度单调递减

        for i, current_height in enumerate(height):
            while stack and current_height > height[stack[-1]]:
                bottom = stack.pop()
                if not stack:
                    break

                left = stack[-1]
                width = i - left - 1
                bounded_height = min(height[left], current_height) - height[bottom]
                ans += width * bounded_height

            stack.append(i)

        return ans

Reasoning: The popped bar is a basin floor. The new stack top and current bar form its left and right boundaries. Water in this layer is width × effective height.

Example 3: Maximal Rectangle in a matrix

Problem: LeetCode 85

class Solution:
    def maximalRectangle(self, matrix: List[List[str]]) -> int:
        if not matrix:
            return 0

        heights = [0] * len(matrix[0])
        ans = 0

        for row in matrix:
            for i, value in enumerate(row):
                heights[i] = heights[i] + 1 if value == '1' else 0
            ans = max(ans, self.largestRectangleArea(heights))

        return ans

    def largestRectangleArea(self, heights: List[int]) -> int:
        heights = [0] + heights + [0]  # 两侧哨兵
        stack = []  # 下标对应的高度单调递增
        ans = 0

        for i, current_height in enumerate(heights):
            while stack and current_height < heights[stack[-1]]:
                height = heights[stack.pop()]
                width = i - stack[-1] - 1
                ans = max(ans, height * width)
            stack.append(i)

        return ans

Reasoning: Treat each row as the base of a histogram. heights[i] counts consecutive 1s in that column. At a shorter bar, a popped height can extend no further right; the new top and current index define its boundaries.

What the three examples share

  • Temperatures: Popping determines the first greater element to the right.
  • Rain water: Popping settles a basin layer using two boundaries.
  • Rectangle: Convert each row to a histogram; popping establishes the maximum width for that height.
