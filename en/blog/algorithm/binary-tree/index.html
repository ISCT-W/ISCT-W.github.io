Binary trees: define what recursion returns

## Two kinds of information in maximum path sum

WJunhao WeiAbout 5 min read

Two kinds of information in maximum path sum

View diagram structure (original)
flowchart TD
 L["L = max(0, 左子树返回值)"] --> N["当前节点"]
 R["R = max(0, 右子树返回值)"] --> N
 N --> A["value + L + R：更新全局答案"]
 N --> P["value + max(L, R)：返回父节点"]

A complete path may join both children at the current node. A path returned to the parent can use only one side; using both would create a branch. Negative contributions can be discarded, but the global answer must still handle a tree whose values are all negative.

Recognize the structure first

  • Consider recursive divide-and-conquer when the problem splits into similar problems on the left and right subtrees. Define the function’s scope and return value before deciding when to visit the root.
  • To reconstruct a tree, the first preorder element identifies the root and its inorder position separates the subtrees. Distinct node values allow the root to be located uniquely.
  • For downward paths with arbitrary starting nodes, separate choosing the start from extending a path from a fixed start. Each path is counted exactly once by its own starting node.
  • When a path may cross both subtrees, combine both contributions to update the answer, but return only a single extendable branch to the parent.

Define the state and invariant

Decide what the recursive function returns: one-sided information ending at the current node, or the complete answer for its subtree. A global variable is often useful when the final path combines both children.

Teaching skeletons

The following pseudocode illustrates three forms of recursion. The Chinese placeholders for splitting and construction should be implemented for the chosen node type and interval representation.

构造二叉树 build(前序, 中序)：
    if 区间为空：return None
    用前序首元素建立根，在中序中定位根
    按中序左右长度，同步划分两种遍历的左右子树区间
    root.left = build(左前序, 左中序)
    root.right = build(右前序, 右中序)
    return root

统计向下路径：
    extend(node, remain)：          # 必须从 node 开始
        if node 为空：return 0
        return (node.val == remain) + extend(node.left, remain-node.val)
                                   + extend(node.right, remain-node.val)
    all_paths(node, target)：       # 枚举起点
        if node 为空：return 0
        return extend(node, target) + all_paths(node.left, target)
                                    + all_paths(node.right, target)

最大路径和（非空树）：
    ans = -∞
    gain(node)：                   # 返回以 node 为端点的最大单边贡献
        if node 为空：return 0
        left = max(0, gain(node.left))
        right = max(0, gain(node.right))
        ans = max(ans, node.val+left+right)
        return node.val + max(left, right)
    gain(root)，返回 ans

Continue downward even after a fixed-start path reaches the target sum, because later nodes may contain zeros or negative values. The nested recursion here takes O(n²) in the worst case. An optimization uses DFS with prefix-sum counts along the current root-to-node path, removing counts during backtracking.

Example 1: Construct Binary Tree from Preorder and Inorder Traversal

Problem: LeetCode 105

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        if len(inorder) == 0: return
        root = TreeNode(preorder[0])
        mid = inorder.index(preorder[0])

        # 构建子树
        root.left = self.buildTree(preorder[1:mid+1], inorder[:mid])
        root.right = self.buildTree(preorder[mid+1:], inorder[mid+1:])

        return root

Implementation: The first preorder element is the root. Its inorder position determines the left and right subtree sizes. Split the preorder array using those sizes and recursively construct both subtrees.

Example 2: Path Sum III

Problem: LeetCode 437

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        # 对于单个递归不能够混合带/不带当前节点，因为会导致单个情况被遍历多次！
        def calc_ans(node, remain):
            if not node: return 0
            ans = 0
            if node.val == remain:
                ans += 1
            ans += calc_ans(node.left, remain-node.val)
            ans += calc_ans(node.right, remain-node.val)
            return ans
        
        if not root: return 0
        # 计算包含当前节点的结果
        ans = calc_ans(root, targetSum)

        # 计算不包含当前节点的结果
        ans += self.pathSum(root.left, targetSum)
        ans += self.pathSum(root.right, targetSum)
        return ans

Implementation: calc_ans counts paths that must begin at the current node. The outer pathSum then treats each child as a new starting node, covering every possible start.

Example 3: Binary Tree Maximum Path Sum (hard)

Problem: LeetCode 124

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        # 和求最大直径基本一样，唯独注意这里的最大值不一定是一整条路径，所以更新最大值的时候计算 max(l + r, l, r, 0) + root.val!
        self.ans = -1000000
        def depth(root):
            if not root: return 0
            l = depth(root.left)
            r = depth(root.right)
            root_val = root.val + max(l, 0) + max(r, 0)
            self.ans = max(self.ans, root_val)
            return max(l, r, 0) + root.val
        depth(root)
        return self.ans

Keep the two path definitions separate

  • The parent must be able to extend the result of depth(root), so it includes at most one child: root.val + max(l, r, 0).
  • A complete path with its highest node here may use both children: root.val + max(l, 0) + max(r, 0). Use it to update the global answer, never as the return value to the parent.
  • Replace negative child contributions with 0 to skip those branches. Initialize the global answer sufficiently low so that an all-negative tree still selects its largest single node.
