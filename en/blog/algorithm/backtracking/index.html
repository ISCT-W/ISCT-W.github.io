## Choose, recurse, and undo

WJunhao WeiAbout 4 min read

Choose, recurse, and undo

View diagram structure (original)
flowchart TD
 A["进入当前递归层"] --> B{"已构成完整答案？"}
 B -->|是| C["保存路径副本并返回"]
 B -->|否| H{"还有未尝试的候选？"}
 H -->|否| R["返回上一层"]
 H -->|是| D["取一个候选并检查合法性"]
 D --> V{"合法？"}
 V -->|否| H
 V -->|是| E["修改共享路径 / 棋盘状态"]
 E --> F["递归探索下一层"]
 F --> G["撤销本层修改"]
 G --> H

When a recursive call modifies shared state in place, undo that level’s changes when it returns. Passing a new copy of the path instead provides the isolation that explicit undo would otherwise supply.

Recognize the structure first

Use a decision tree when a problem asks for all valid solutions and each solution can be built through successive choices. In palindrome partitioning, one level decides where the next substring ends; in N-Queens, it decides which column to use in the current row. Prune a partial solution as soon as no later choice can repair it.

A practical order of work

  1. Define what one recursion level does and which state determines the next candidates.
  2. Establish the success condition, then enumerate candidates, validate them, and recurse.
  3. Undo changes to a shared path or board on return. Fresh copies need no undo; saving a shared path as an answer still requires a copy.

General template

Backtracking is depth-first search on a decision tree: choose a candidate, explore the next level, and undo the choice. Identify the path path, the next starting position, valid candidates, and the stopping condition before writing the recursion.

The following teaching pseudocode keeps the original Chinese placeholders for problem-specific steps. Skip invalid candidates before recursing.

def backtrack(state):
    if 满足结束条件:
        保存答案
        return

    for choice in 当前可选项:
        做选择
        backtrack(下一状态)
        撤销选择

Example 1: Palindrome Partitioning

Problem: LeetCode 131. Palindrome Partitioning

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        ans = []

        def backtracing(idx, cur):
            if idx >= len(s): 
                ans.append(cur)
                return
            
            for i in range(idx, len(s)):
                candidate = s[idx: i+1]
                if candidate == candidate[::-1]:
                    backtracing(i+1, cur + [candidate])
        
        backtracing(0, [])
        return ans

Implementation: idx is the start of the next substring; the loop enumerates its end i. Recurse only if the slice is a palindrome. Because cur + [candidate] creates a fresh path, no explicit undo is needed.

Example 2: N-Queens (hard)

Problem: LeetCode 51. N-Queens

class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        # 还是经典回溯，每次放一行直到放到最后一行；放的时候检查同列，左上与右上即可
        board = [['.'] * n for _ in range(n)]
        res = []

        def backtracing(row):
            if row == n: # 走完就是一种成功情况
                tmp = [''.join(i) for i in board]
                res.append(tmp)
                return
            for col in range(n): # 验证是否在这个位置可以放，可以就放并且回溯
                if not self.isValid(board, row, col): continue
                board[row][col] = 'Q'
                backtracing(row + 1)
                board[row][col] = '.'

        backtracing(0)
        return res

    def isValid(self, board, row, col):
        n = len(board)
        
        # 检查同col上方是否有
        for i in range(row):
            if board[i][col] == 'Q': return False

        # 检查右上对角线
        for i, j in zip(range(row - 1, -1, -1), range(col + 1, n, 1)):
            if board[i][j] == 'Q': return False
        
        # 检查左上对角线
        for i, j in zip(range(row - 1, -1, -1), range(col - 1, -1, -1)):
            if board[i][j] == 'Q': return False
    
        return True

Reasoning: There is one queen per row, so the recursion depth is the row number. Try each column, checking only the occupied rows above: the same column and both upward diagonals. Place a valid queen, recurse, then restore '.'. Once row == n, every row is filled successfully; record a copy of the board.
