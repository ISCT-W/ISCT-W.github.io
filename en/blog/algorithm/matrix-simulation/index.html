Matrix simulation: shrink the unvisited rectangle

## Shrink the unvisited region after every edge

WJunhao WeiAbout 3 min read

Shrink the unvisited region after every edge

When only one row or column remains, a single turn can exhaust the region. Checking boundaries only at the start of the outer loop is therefore insufficient.

Recognize the structure first

When a problem gives visitation or movement rules and asks for an ordered output or matrix modification, direct simulation is often enough. Spiral traversal has a useful invariant: after visiting an outer edge, the remaining cells still form a smaller rectangle. Four boundaries replace a separate visited flag for every cell.

Define the state and invariant

Specify the state—position, direction, or boundaries—along with movement rules, visitation timing, and termination. Here, shrink the appropriate boundary after each edge, then verify that the remaining region is valid. The four boundaries must enclose exactly the unvisited cells, including the final single row or column.

Teaching skeleton: four shrinking boundaries

This pseudocode assumes a nonempty matrix. Expand “visit an edge” into the appropriate loop. Other simulation problems need states suited to their own rules and may not admit four boundaries.

top = 0，bottom = 行数-1，left = 0，right = 列数-1
while top <= bottom 且 left <= right：
    访问上边：从左到右；top += 1
    若区域已空：结束
    访问右边：从上到下；right -= 1
    若区域已空：结束
    访问下边：从右到左；bottom -= 1
    若区域已空：结束
    访问左边：从下到上；left += 1

Example: Spiral Matrix

Problem: LeetCode 54

class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        ans = []
        top, left, bottom, right = 0, 0, len(matrix) - 1, len(matrix[0]) - 1

        while top <= bottom and left <= right:
            if top <= bottom:
                for i in range(left, right + 1):
                    ans.append(matrix[top][i])
                top += 1
            if left <= right:
                for j in range(top, bottom + 1):
                    ans.append(matrix[j][right])
                right -= 1
            if top <= bottom:
                for k in range(right, left - 1, -1):
                    ans.append(matrix[bottom][k])
                bottom -= 1
            if left <= right:
                for l in range(bottom, top - 1, -1):
                    ans.append(matrix[l][left])
                left += 1

        return ans

Implementation: Visit the top, right, bottom, and left edges in order, updating top/right/bottom/left. The additional checks prevent revisiting a lone row or column in the final round.
