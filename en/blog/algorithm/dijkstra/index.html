The minimum-effort path uses max(current cost, new edge height difference) as its candidate cost. It shares the relaxation framework of additive shortest paths, but uses a different definition of path cost.

Problem structure and state design

  • If a worse cost at the same state can never improve later transitions, retain only dist[state] when searching for an optimal path from a start to other states or a target.
  • Extending a path must not reduce its cost, and a shared transition must preserve the ordering of costs. Both nonnegative additive costs cost + weight and bottleneck costs max(cost, weight) satisfy these properties. General shortest paths with negative edges do not.
  • Pop the cheapest candidate from a min-heap, discard stale records, and relax its neighbors. Once a valid record is popped, its optimal cost is settled; a target may be returned at that point.
  • If future choices also depend on remaining uses, keys, or similar information, include those in the state. Position alone is insufficient.

General template

The skeleton below retains the original Chinese placeholders for problem-specific operations. The main choices are usually the state definition and the computation of new_cost.

"""
Dijkstra 通用模版：
1. 建图 / 定义状态空间
2. 初始化 dist
3. 起点状态入堆

while heap 非空:
    取出当前 cost 最优的状态

    如果这是过期状态:
        continue

    for 每一个可以转移到的下一状态:
        计算 new_cost

        if new_cost 优于 dist[next_state]:
            更新 dist
            next_state 入堆
"""

Example: Path With Minimum Effort

Problem: LeetCode 1631

class Solution:
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
        """
        Dijkstra 通用模版：
        1. 建图 / 定义状态空间
        2. 初始化 dist
        3. 起点状态入堆

        while heap 非空:
            取出当前 cost 最优的状态

            如果这是过期状态:
                continue

            for 每一个可以转移到的下一状态:
                计算 new_cost

                if new_cost 优于 dist[next_state]:
                    更新 dist
                    next_state 入堆
        """
        m, n = len(heights), len(heights[0])
        dists = [[float('inf')] * n for _ in range(m)]
        dists[0][0] = 0

        import heapq
        pq = [(0, 0, 0)] # cost, r, c
        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]
        while pq:
            cost, r, c = heapq.heappop(pq)
            if cost > dists[r][c]: continue
            if r == m - 1 and c == n - 1: return cost
            for dr, dc in directions:
                nr, nc = r + dr, c + dc 
                if 0 <= nr < m and 0 <= nc < n:
                    edge_cost = abs(heights[nr][nc] - heights[r][c])
                    new_cost = max(cost, edge_cost)
                    if new_cost < dists[nr][nc]:
                        dists[nr][nc] = new_cost
                        heapq.heappush(pq, (new_cost, nr, nc))

        return dists[-1][-1]

Mapping the code to the template

  • States: Each cell (r, c) is a node; moves to its four neighbors are edges.
  • Distances: dists[r][c] is the least effort needed to reach that cell from the start.
  • Initial heap entry: (0, 0, 0) gives the starting cell a cost of zero.
  • Stale entries: Skip cost > dists[r][c], because a better route is already known.
  • Transition: An edge costs the absolute height difference. A path costs its largest edge, so new_cost = max(cost, edge_cost).
  • Relaxation: If the new cost is smaller, update dists and push the new candidate onto the heap.
