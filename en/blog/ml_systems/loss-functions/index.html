Loss Functions: Label Structure, Gradients, and Task Metrics

A loss turns a task into a numerical objective, but the objective is not automatically the desired outcome.

WJunhao WeiAbout 9 min read

A loss turns a task into a numerical objective, but the objective is not automatically the desired outcome. Mutually exclusive labels, independent attributes, continuous targets, and region relationships call for different forms. Weights, masks, reductions, and numerical implementations determine which examples drive updates.

Classification: start with label structure

Binary cross-entropy

For probability ppp and y∈{0,1}y\in\{0,1\}y∈{0,1}:

LBCE=−[ylog⁡p+(1−y)log⁡(1−p)].\mathcal{L}_{\mathrm{BCE}} =-\left[y\log p+(1-y)\log(1-p)\right].LBCE​=−[ylogp+(1−y)log(1−p)].

For logit zzz, the stable form is:

L(z,y)=max⁡(z,0)−zy+log⁡(1+e−∣z∣).\mathcal{L}(z,y) =\max(z,0)-zy+\log\left(1+e^{-|z|}\right).L(z,y)=max(z,0)−zy+log(1+e−∣z∣).

Uses

Binary classification and multilabel classification, where each label has an independent Sigmoid/BCE objective and probabilities need not sum to one.

Cautions

Pass logits to a logits-based loss without applying Sigmoid first. pos_weight scales positive terms, unlike whole-sample weights. For imbalance, evaluate thresholds and precision/recall/PR-AUC as well as weighting. Multilabel targets need per-class binary or soft labels, not one class index.

Softmax cross-entropy

For one true class yyy among KKK mutually exclusive classes:

LCE=−log⁡ezy∑j=1Kezj=−zy+log⁡∑j=1Kezj.\mathcal{L}_{\mathrm{CE}} =-\log\frac{e^{z_y}}{\sum_{j=1}^{K}e^{z_j}} =-z_y+\log\sum_{j=1}^{K}e^{z_j}.LCE​=−log∑j=1K​ezj​ezy​​=−zy​+logj=1∑K​ezj​.

With soft targets qqq:

LCE(q,p)=−∑k=1Kqklog⁡pk.\mathcal{L}_{\mathrm{CE}}(q,p) =-\sum_{k=1}^{K}q_k\log p_k.LCE​(q,p)=−k=1∑K​qk​logpk​.

Cautions

Use BCE for independent multilabel targets. Feed raw logits to stable LogSumExp-based implementations. Check ignored labels, padding, and reduction denominators. Class weights change the objective, requiring class-specific metrics. Label smoothing can reduce overconfidence but affect calibration, rare classes, and learning precise labels.

Focal loss

A common binary form is:

Lfocal=−αt(1−pt)γlog⁡pt,\mathcal{L}_{\mathrm{focal}} =-\alpha_t(1-p_t)^\gamma\log p_t,Lfocal​=−αt​(1−pt​)γlogpt​,

ptp_tpt​ is the true-class probability and γ≥0\gamma\geq0γ≥0; zero γ\gammaγ gives weighted cross-entropy.

Why use it?

Many easy negatives can dominate training. (1−pt)γ(1-p_t)^\gamma(1−pt​)γ suppresses easy examples and emphasizes harder ones.

Cautions

Validate γ\gammaγ and α\alphaα rather than maximizing them. Incorrect labels can look hard too, amplifying noise. Calibration and thresholds still need testing. Implement through stable logits-based BCE/CE instead of taking logs of tiny probabilities.

KL divergence and distillation

DKL(P∥Q)=∑iPilog⁡PiQi.D_{\mathrm{KL}}(P\Vert Q) =\sum_i P_i\log\frac{P_i}{Q_i}.DKL​(P∥Q)=i∑​Pi​logQi​Pi​​.

KL is asymmetric. Distillation commonly fits student QQQ to teacher PPP:

LKD=T2DKL(softmax⁡(zt/T)∥softmax⁡(zs/T)).\mathcal{L}_{\mathrm{KD}} =T^2D_{\mathrm{KL}} \left( \operatorname{softmax}(z_t/T) \Vert \operatorname{softmax}(z_s/T) \right).LKD​=T2DKL​(softmax(zt​/T)∥softmax(zs​/T)).

T2T^2T2 compensates for temperature-induced gradient scaling. Check whether the API expects probabilities or log probabilities and what batchmean versus mean divides by.

Probability formulas and stable computation

Explicit Sigmoid followed by BCE is mathematically valid but extreme logits can round probabilities to zero/one, making logarithms infinite. Combined logits losses avoid this.

Choose Softmax CE versus Sigmoid BCE by exclusivity, not the number of classes. Focal loss changes easy/hard contributions; it does not repair sampling bias, noisy labels, or thresholds automatically.

Regression: the cost of errors and outliers

Let e=y^−ye=\hat y-ye=y^​−y.

MSE / L2

LMSE=1n∑i=1nei2.\mathcal{L}_{\mathrm{MSE}}=\frac{1}{n}\sum_{i=1}^{n}e_i^2.LMSE​=n1​i=1∑n​ei2​.

MSE penalizes large errors quadratically, with gradients linear in error. It is outlier-sensitive and corresponds to Gaussian-noise maximum likelihood. Target scaling changes loss quadratically and error gradients linearly, so scale handling matters.

MAE / L1

LMAE=1n∑i=1n∣ei∣.\mathcal{L}_{\mathrm{MAE}}=\frac{1}{n}\sum_{i=1}^{n}|e_i|.LMAE​=n1​i=1∑n​∣ei​∣.

MAE is more outlier-robust and corresponds to Laplace noise. At zero, use a subgradient; elsewhere gradient magnitude is constant, making local optimization less smooth than MSE.

Huber / Smooth L1

Lδ(e)={12e2,∣e∣≤δ,δ(∣e∣−12δ),∣e∣>δ.\mathcal{L}_{\delta}(e)= \begin{cases} \frac{1}{2}e^2,&|e|\leq\delta,\\ \delta\left(|e|-\frac{1}{2}\delta\right),&|e|>\delta. \end{cases}Lδ​(e)={21​e2,δ(∣e∣−21​δ),​∣e∣≤δ,∣e∣>δ.​

The quadratic center and linear tails balance smoothness and robustness. Choose δ\deltaδ relative to target scale; Huber and Smooth L1 can use different scaling conventions.

Quantile / pinball loss

For quantile τ∈(0,1)\tau\in(0,1)τ∈(0,1):

ρτ(e)={τe,e≥0,(τ−1)e,e<0.\rho_\tau(e)= \begin{cases} \tau e,&e\geq 0,\\ (\tau-1)e,&e<0. \end{cases}ρτ​(e)={τe,(τ−1)e,​e≥0,e<0.​

This estimates conditional quantiles and asymmetric risk; τ=0.9\tau=0.9τ=0.9 targets an upper quantile rather than a mean. Check quantile crossing when predicting several levels.

Choosing regression losses

Data/goal Starting point Reason
Approximately Gaussian noise; costly large errors MSE Strong gradients for large errors
Many outliers MAE Linear error penalty
Smooth locally, robust in tails Huber Quadratic/linear compromise
Quantiles or uncertainty intervals Quantile Direct conditional quantiles

The choice depends on how outliers and asymmetric errors should affect the task, not merely the smallest numerical loss.

Region overlap and box geometry

Dice loss

Soft Dice often takes the form:

Dice⁡(p,y)=2∑ipiyi+ε∑ipi+∑iyi+ε,LDice=1−Dice⁡(p,y).\operatorname{Dice}(p,y) =\frac{2\sum_i p_i y_i+\varepsilon} {\sum_i p_i+\sum_i y_i+\varepsilon}, \qquad \mathcal{L}_{\mathrm{Dice}}=1-\operatorname{Dice}(p,y).Dice(p,y)=∑i​pi​+∑i​yi​+ε2∑i​pi​yi​+ε​,LDice​=1−Dice(p,y).

Benefits

It directly targets overlap and often emphasizes small foregrounds more than mean pixel CE.

Cautions

Handle empty masks and gradients explicitly. Per-image, per-class, and whole-batch calculations assign different weights. Dice and pixel BCE/CE are complementary, and the position/size of ε\varepsilonε matters for small objects.

IoU/Jaccard and Tversky

IoU⁡(p,y)=∑ipiyi+ε∑ipi+∑iyi−∑ipiyi+ε.\operatorname{IoU}(p,y) =\frac{\sum_i p_i y_i+\varepsilon} {\sum_i p_i+\sum_i y_i-\sum_i p_i y_i+\varepsilon}.IoU(p,y)=∑i​pi​+∑i​yi​−∑i​pi​yi​+ε∑i​pi​yi​+ε​.

Tversky weights false positives and negatives separately:

TI⁡=TP+εTP+αFP+βFN+ε.\operatorname{TI} =\frac{TP+\varepsilon} {TP+\alpha FP+\beta FN+\varepsilon}.TI=TP+αFP+βFN+εTP+ε​.

Higher missed-detection costs can justify increasing the FN weight, subject to implementation conventions. Focal Tversky emphasizes low-overlap cases but is also more sensitive to noise and hyperparameters.

Bounding-box regression

L1/Smooth L1 depend on coordinate scale and parameterization. IoU directly measures overlap but supplies limited information for disjoint boxes. GIoU, DIoU, and CIoU add enclosing-region, center-distance, and aspect-ratio geometry. Detection also includes classification, objectness, matching, or mask terms; their weights determine gradient contributions.

Combine region and pixel supervision

Dice emphasizes global overlap and small foregrounds; BCE/CE teaches local pixel probabilities. Validate their relative weights and empty-mask behavior when combining them.

Shape representations through relative relationships

Triplet loss

Ltriplet=max⁡(0,d(a,p)−d(a,n)+m),\mathcal{L}_{\mathrm{triplet}} =\max\left(0, d(a,p)-d(a,n)+m \right),Ltriplet​=max(0,d(a,p)−d(a,n)+m),

a,p,na,p,na,p,n are anchor, positive, and negative, with margin mmm. Easy random negatives yield many zero-loss triplets; only the hardest can select mislabeled/outlier examples. Design mining and match distance, embedding normalization, and margin.

InfoNCE

For one positive among candidates:

LInfoNCE=−log⁡exp⁡(s(q,k+)/τ)∑jexp⁡(s(q,kj)/τ).\mathcal{L}_{\mathrm{InfoNCE}} =-\log \frac{\exp\left(s(q,k^+)/\tau\right)} {\sum_j\exp\left(s(q,k_j)/\tau\right)}.LInfoNCE​=−log∑j​exp(s(q,kj​)/τ)exp(s(q,k+)/τ)​.

sss is often dot product or cosine similarity and τ\tauτ the temperature.

Cautions

Temperature controls sharpness and gradient scale. Larger batches add negatives, memory, and communication, including possible semantic false negatives. Cosine similarity usually requires L2 normalization. Verify cross-device candidate gathering and gradients. Better retrieval recall alone establishes neither calibrated embeddings nor useful downstream thresholds.

Temperature and hard negatives

Lower temperature emphasizes difficult negatives but can amplify noise and gradients; higher values smooth the distribution. Tune jointly with normalization, batch negatives, and data noise.

Generative-model objectives

Autoregressive language modeling

LNLL=−∑t=1Tlog⁡pθ(xt∣x<t).\mathcal{L}_{\mathrm{NLL}} =-\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).LNLL​=−t=1∑T​logpθ​(xt​∣x<t​).

Usually implemented as token CE, it requires correctly shifted inputs/labels and masks for padding, prompts, or unsupervised tokens. Token versus sequence means weight lengths differently. Perplexity is commonly:

PPL⁡=exp⁡(1TLNLL).\operatorname{PPL}=\exp\left(\frac{1}{T}\mathcal{L}_{\mathrm{NLL}}\right).PPL=exp(T1​LNLL​).

Do not directly compare PPL across different tokenizers, cleaning, or masks.

Diffusion noise prediction

For ε\varepsilonε prediction:

Ldiff=Ex0,ε,t[w(t)∥ε−εθ(xt,t,c)∥22].\mathcal{L}_{\mathrm{diff}} =\mathbb{E}_{x_0,\varepsilon,t} \left[ w(t) \left\| \varepsilon-\varepsilon_\theta(x_t,t,c) \right\|_2^2 \right].Ldiff​=Ex0​,ε,t​[w(t)∥ε−εθ​(xt​,t,c)∥22​].

Models may instead predict x0x_0x0​ or vvv; objective and sampler must agree. Timestep sampling and SNR weights change emphasis. Lower MSE does not necessarily mean better perception or text matching. Latent scales, VAE processing, and condition dropout also affect training.

VAE ELBO

LVAE=Lrecon+βDKL(qϕ(z∣x)∥p(z)).\mathcal{L}_{\mathrm{VAE}} =\mathcal{L}_{\mathrm{recon}} +\beta D_{\mathrm{KL}} \left(q_\phi(z\mid x)\Vert p(z)\right).LVAE​=Lrecon​+βDKL​(qϕ​(z∣x)∥p(z)).

Reconstruction controls fidelity; KL structures the latent distribution. Excessive KL can cause posterior collapse, while weak KL leaves poor structure. Annealing, free bits, and decoder-capacity adjustments are common tools.

Ask whether labels are exclusive, independent, continuous, or structured; which errors cost more; whether classes, sizes, or lengths are imbalanced; whether outputs are logits, probabilities, coordinates, or normalized embeddings; and how the loss relates to deployment metrics.

Implementation determines the actual optimization

Logits and numerical stability

Pass logits directly to CE/BCEWithLogits. Use LogSumExp, log_softmax, and stable softplus instead of logging tiny probabilities. Check mixed-precision scaling, overflow, and reduction precision.

Reduction and masking

Sum, sample mean, token mean, and sequence mean are not interchangeable. A masked mean is:

L=∑imiℓi∑imi,\mathcal{L} =\frac{\sum_i m_i\ell_i}{\sum_i m_i},L=∑i​mi​∑i​mi​ℓi​​,

mi∈{0,1}m_i\in\{0,1\}mi​∈{0,1} selects valid positions. Including padding in the denominator changes weights. Averaging device-local means differs from a global valid-token mean when device token counts differ.

Class imbalance

Resampling changes data distribution; class weights change gradient contributions; focal weighting changes easy/hard emphasis; thresholds change decisions without changing training. Report per-class metrics or precision/recall/PR-AUC and evaluate the methods together.

Combining loss scales

Ltotal=∑k=1KλkLk.\mathcal{L}_{\mathrm{total}} =\sum_{k=1}^{K}\lambda_k\mathcal{L}_k.Ltotal​=k=1∑K​λk​Lk​.

Choose λk\lambda_kλk​ with gradient directions/norms and task outcomes in mind, not only scalar loss magnitudes. Track components and key gradients so one objective does not silently dominate.

Noisy labels and hard cases

High loss can signal genuine difficulty, corrupted data, incorrect labels, or distribution shifts. Focal weighting and mining amplify these examples, so inspect quality first.

Loss and metrics can disagree

Minimum CE need not maximize F1; minimum MSE need not minimize business cost; better Dice need not improve boundaries; lower diffusion MSE need not improve images. Select models using validation task metrics, calibration, and failure slices.

From training loss to deployed behavior

Poor deployment despite falling loss can arise from objective mismatch, incorrect class/length weights, leakage, domain shift, untuned thresholds, degraded calibration, or averages hiding long-tail failures. Inspect slices and the end-to-end decision path.
