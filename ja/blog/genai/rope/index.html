RoPE：回転の幾何で Attention に位置を埋め込む

RoPE は Query と Key のチャネル対を二次元ベクトルとし、位置に応じて回転します。

W韋 君豪読了目安 11 分

RoPE は Query と Key のチャネル対を二次元ベクトルとし、位置に応じて回転します。位置 mmm の Query と nnn の Key では次が成り立ちます。

(Rmq)⊤(Rnk)=q⊤Rn−mk(R_m q)^\top(R_n k)=q^\top R_{n-m}k(Rm​q)⊤(Rn​k)=q⊤Rn−m​k

個別の回転には絶対位置を使いますが、内積の位置依存は相対変位 n−mn-mn−m になります。標準 RoPE は学習する絶対位置表を必要とせず、学習長を超える位置も計算できます。ただし計算可能性と外挿の信頼性は別で、長文脈には周波数調整、補間、継続学習が必要になることがあります。

基本の仕組み

各 Head の回転対象次元を偶数 drd_rdr​ とし、平面 (2i,2i+1)(2i,2i+1)(2i,2i+1) を周波数 θi\theta_iθi​ で回します。

R(mθi)=[cos⁡mθi−sin⁡mθisin⁡mθicos⁡mθi]R(m\theta_i)= \begin{bmatrix} \cos m\theta_i & -\sin m\theta_i\\ \sin m\theta_i & \cos m\theta_i \end{bmatrix}R(mθi​)=[cosmθi​sinmθi​​−sinmθi​cosmθi​​]

代表的な周波数は次式です。

θi=base⁡−2i/dr,i=0,…,dr2−1.\theta_i=\operatorname{base}^{-2i/d_r}, \qquad i=0,\ldots,\frac{d_r}{2}-1.θi​=base−2i/dr​,i=0,…,2dr​​−1.

古典的な base は 10000 ですが、モデルごとに値、部分回転、スケーリングが異なります。高周波は局所変化、低周波は長い尺度を表し、複数の尺度を組み合わせます。

位置表現が必要な理由

位置機構のない双方向 Self-Attention は順列同変です。入力順を入れ替えると出力も対応して入れ替わるだけで、順番や距離を明示しません。

Attention⁡(Q,K,V)=softmax⁡(QK⊤dh)V.\operatorname{Attention}(Q,K,V) = \operatorname{softmax} \left( \frac{QK^\top}{\sqrt{d_h}} \right)V.Attention(Q,K,V)=softmax(dh​​QK⊤​)V.

Causal Mask は前方だけを見る制約で対称性を崩しますが、正確な距離や絶対位置を直接表すわけではありません。RoPE は Q/K の対応付けへ位置を加えます。正弦位置表現は通常、入力へ加算します。

xm′=xm+PE⁡(m),x_m'=x_m+\operatorname{PE}(m),xm′​=xm​+PE(m),

RoPE は先に射影してから回転します。

qm′=Rmqm,km′=Rmkm.q_m'=R_mq_m, \qquad k_m'=R_mk_m.qm′​=Rm​qm​,km′​=Rm​km​.

正弦位置表現から RoPE へ

正弦位置表現では一定の変位を線形変換で表せます。sin/cos の一組を次のように置きます。

θi=10000−2i/d,pm(i)=[sin⁡(mθi)cos⁡(mθi)].\theta_i=10000^{-2i/d}, \qquad p_m^{(i)}= \begin{bmatrix} \sin(m\theta_i)\\ \cos(m\theta_i) \end{bmatrix}.θi​=10000−2i/d,pm(i)​=[sin(mθi​)cos(mθi​)​].

加法定理から次式を得ます。

pm+Δ(i)=[sin⁡((m+Δ)θi)cos⁡((m+Δ)θi)]=[cos⁡(Δθi)sin⁡(Δθi)−sin⁡(Δθi)cos⁡(Δθi)]⏟Ai(Δ)[sin⁡(mθi)cos⁡(mθi)].\begin{aligned} p_{m+\Delta}^{(i)} &= \begin{bmatrix} \sin((m+\Delta)\theta_i)\\ \cos((m+\Delta)\theta_i) \end{bmatrix}\\ &= \underbrace{ \begin{bmatrix} \cos(\Delta\theta_i) & \sin(\Delta\theta_i)\\ -\sin(\Delta\theta_i) & \cos(\Delta\theta_i) \end{bmatrix}}_{A_i(\Delta)} \begin{bmatrix} \sin(m\theta_i)\\ \cos(m\theta_i) \end{bmatrix}. \end{aligned}pm+Δ(i)​​=[sin((m+Δ)θi​)cos((m+Δ)θi​)​]=Ai​(Δ)[cos(Δθi​)−sin(Δθi​)​sin(Δθi​)cos(Δθi​)​]​​[sin(mθi​)cos(mθi​)​].​

Ai(Δ)A_i(\Delta)Ai​(Δ) は回転行列で、符号は sin/cos の順序によります。位置を Δ\DeltaΔ 動かすことは、各平面を Δθi\Delta\theta_iΔθi​ 回転することです。

元の Transformer はそのベクトルを内容に加えます。

xm′=xm+pm.x_m'=x_m+p_m.xm′​=xm​+pm​.

射影後は内容、位置、交差項が混ざり、利用方法をデータから学ぶ必要があります。RoPE は回転を Q/K に直接適用します。

qm′=Rmqm,kn′=Rnkn.q_m'=R_mq_m, \qquad k_n'=R_nk_n.qm′​=Rm​qm​,kn′​=Rn​kn​.

相対位置が Attention の幾何へ直接入ります。

(qm′)⊤kn′=qm⊤Rm⊤Rnkn=qm⊤Rn−mkn.(q_m')^\top k_n' =q_m^\top R_m^\top R_nk_n =q_m^\top R_{n-m}k_n.(qm′​)⊤kn′​=qm⊤​Rm⊤​Rn​kn​=qm⊤​Rn−m​kn​.

正弦 PE は複数周波数の位相を Embedding に加えます。RoPE はその回転関係を Q/K に作用させ、内積へ相対変位を組み込みます。

内積に相対位置だけが残る理由

回転後のベクトルは次のとおりです。

qm′=Rmqm,kn′=Rnkn.q_m'=R_mq_m, \qquad k_n'=R_nk_n.qm′​=Rm​qm​,kn′​=Rn​kn​.

その内積は次式です。

(qm′)⊤kn′=(Rmqm)⊤(Rnkn)=qm⊤Rm⊤Rnkn=qm⊤R−mRnkn=qm⊤Rn−mkn.\begin{aligned} (q_m')^\top k_n' &=(R_mq_m)^\top(R_nk_n)\\ &=q_m^\top R_m^\top R_nk_n\\ &=q_m^\top R_{-m}R_nk_n\\ &=\boxed{q_m^\top R_{n-m}k_n}. \end{aligned}(qm′​)⊤kn′​​=(Rm​qm​)⊤(Rn​kn​)=qm⊤​Rm⊤​Rn​kn​=qm⊤​R−m​Rn​kn​=qm⊤​Rn−m​kn​​.​

二つの回転恒等式を使っています。

Rm⊤=R−m,RaRb=Ra+b.R_m^\top=R_{-m}, \qquad R_aR_b=R_{a+b}.Rm⊤​=R−m​,Ra​Rb​=Ra+b​.

絶対位置で回し、内積では相対位置に依存する、という説明が正確です。規約によって m−nm-nm−n と書く場合もありますが、本質は変位への依存です。

複素数で見る

(x1,x2)(x_1,x_2)(x1​,x2​) を z=x1+ix2z=x_1+\mathrm{i}x_2z=x1​+ix2​ とすると、回転は単位複素数の積です。

zm′=zeimθ.z_m'=ze^{\mathrm{i}m\theta}.zm′​=zeimθ.

共役を使う内積で位相差が現れます。

qmeimθ‾(kneinθ)=qm‾knei(n−m)θ.\overline{q_me^{\mathrm{i}m\theta}} \left(k_ne^{\mathrm{i}n\theta}\right) = \overline{q_m}k_n e^{\mathrm{i}(n-m)\theta}.qm​eimθ​(kn​einθ)=qm​​kn​ei(n−m)θ.

位置を位相に変え、その差を比較する仕組みです。

通常は Q/K を回転し、V は回しません。注目先は QK で決まり、V は集約する内容だからです。Head の最初の drd_rdr​ 次元だけを回すモデルもあります。

二つの性質

1. ノルムを保つ

回転行列は直交行列です。

Rm⊤Rm=I.R_m^\top R_m=I.Rm⊤​Rm​=I.

したがって次が成り立ちます。

∥Rmq∥22=q⊤Rm⊤Rmq=∥q∥22.\lVert R_mq\rVert_2^2 =q^\top R_m^\top R_mq =\lVert q\rVert_2^2.∥Rm​q∥22​=q⊤Rm⊤​Rm​q=∥q∥22​.

位置が大きくなっても、直接 Q/K のノルムを増やさず、向きと位相を変えます。

2. 同位置の内積を保つ

m=nm=nm=n の場合は次式です。

(Rmq)⊤(Rmk)=q⊤Rm⊤Rmk=q⊤k.(R_mq)^\top(R_mk) =q^\top R_m^\top R_mk =q^\top k.(Rm​q)⊤(Rm​k)=q⊤Rm⊤​Rm​k=q⊤k.

同じ回転は元の内容類似度を保ち、異なる位置で相対回転が生じます。

複数周波数を使う理由

平面 iii の波長は次式です。

λi=2πθi.\lambda_i=\frac{2\pi}{\theta_i}.λi​=θi​2π​.

高周波は隣接位置、低周波は長い尺度に向きます。各平面は周期的でも周期が異なるため、「2π2\pi2π を超えると全位置が衝突する」とは限りません。問題は未学習の多周波位相、有限精度、相対距離の分布変化です。

距離減衰は保証されるか

各平面の寄与を展開すると次のような項が現れます。

∑i[aicos⁡(Δθi)+bisin⁡(Δθi)],Δ=n−m.\sum_i \left[ a_i\cos(\Delta\theta_i) +b_i\sin(\Delta\theta_i) \right], \qquad \Delta=n-m.i∑​[ai​cos(Δθi​)+bi​sin(Δθi​)],Δ=n−m.

∣Δ∣|\Delta|∣Δ∣ が増すと位相が散らばり、ある統計条件では振動が相殺して局所性を示します。ただし厳密で単調な減衰でも、ALiBi の線形罰則でもありません。学習した内容により長距離 Attention も可能です。

Causal ALiBi は Head ごとに異なる傾きを使えます。

smn=qm⊤kndh−αh(m−n),m≥n.s_{mn} = \frac{q_m^\top k_n}{\sqrt{d_h}} -\alpha_h(m-n), \qquad m\ge n.smn​=dh​​qm⊤​kn​​−αh​(m−n),m≥n.

RoPE は Q/K の幾何を変え、ALiBi は logit に距離バイアスを足します。

難所は長文脈への外挿

Ltarget≫LtrainL_{\mathrm{target}}\gg L_{\mathrm{train}}Ltarget​≫Ltrain​ でも sin/cos は計算できますが、位相の組み合わせと距離は学習分布を外れます。

∣n−m∣>Ltrain.|n-m|>L_{\mathrm{train}}.∣n−m∣>Ltrain​.

つまり次の区別が必要です。

position index 可计算  ⇏  模型能可靠利用该位置\boxed{ \text{position index 可计算} \;\not\Rightarrow\; \text{模型能可靠利用该位置} }position index 可计算⇒模型能可靠利用该位置​

未学習の相対位相、高周波の周回、一律圧縮による局所解像度低下、長距離依存を学んでいない Attention や学習過程が課題です。

Position Interpolation

拡張比を定義します。

s=LtargetLtrain,s=\frac{L_{\mathrm{target}}}{L_{\mathrm{train}}},s=Ltrain​Ltarget​​,

位置を次のように写します。

m′=ms,m'=\frac{m}{s},m′=sm​,

その上で回転を計算します。

R(msθi).R\left(\frac{m}{s}\theta_i\right).R(sm​θi​).

学習範囲へ近づける一方、隣接位相差は θi/s\theta_i/sθi​/s となり、局所解像度が下がります。通常は長文脈での継続学習も必要です。

base と NTK-aware scaling

base を増やすと一部の周波数が下がり、波長が伸びます。

θi=base⁡−2i/dr,λi=2πθi.\theta_i=\operatorname{base}^{-2i/d_r}, \qquad \lambda_i=\frac{2\pi}{\theta_i}.θi​=base−2i/dr​,λi​=θi​2π​.

大きいほど良いわけではなく、局所解像度と事前学習分布も変わります。NTK-aware は周波数を再配分して局所と長距離を両立しようとします。式はモデル設定と学習方式に従います。

Dynamic NTK と YaRN

Dynamic NTK は実際の長さに応じて調整します。キャッシュ途中で規則を変えるなら、新 Query と既存 Key の周波数整合が必要です。YaRN は周波数別の補間・外挿と Attention の大きさや温度補正を組み合わせます。モデル設定、継続学習、評価に従って使用します。

方式 操作 利点 費用・リスク
直接外挿 位置をそのまま延長 変更不要 位相・距離が分布外
位置補間 一律圧縮 学習範囲へ写せる 局所解像度低下
base / NTK-aware 周波数を再配置 局所と長距離の両立 モデル依存
Dynamic 長さ別に調整 短系列への影響が小さい キャッシュ整合
YaRN 系 周波数別調整と尺度補正 細かな拡張制御 実装・学習が複雑

実装と KV Cache

典型的な実装は次の形です。

def apply_rope(q, k, cos, sin):
    q_rot = q * cos + rotate_half(q) * sin
    k_rot = k * cos + rotate_half(k) * sin
    return q_rot, k_rot

二次元回転の本体は次式です。

(x1,x2)↦(x1cos⁡ϕ−x2sin⁡ϕ,  x1sin⁡ϕ+x2cos⁡ϕ).(x_1,x_2) \mapsto \left( x_1\cos\phi-x_2\sin\phi,\; x_1\sin\phi+x_2\cos\phi \right).(x1​,x2​)↦(x1​cosϕ−x2​sinϕ,x1​sinϕ+x2​cosϕ).

Interleaved は (x0,x1),(x2,x3),…(x_0,x_1),(x_2,x_3),\ldots(x0​,x1​),(x2​,x3​),…、Half-split は前半と後半の対応次元を組にします。重み、rotate_half、cos/sin 配列で規約をそろえる必要があり、事前学習後に勝手に変更すると表現が変わります。

自己回帰生成では通常、回転済み Key を保存します。

{R0k0, R1k1, …, Rtkt}.\left\{ R_0k_0,\, R_1k_1,\, \ldots,\, R_tk_t \right\}.{R0​k0​,R1​k1​,…,Rt​kt​}.

新 Q/K だけを正しい位置で回し、過去の Key と照合します。左 Padding の position_ids、分割 Prefill と Decode の連続位置、Packed Sequence の位置リセットと分離 Mask、スケーリングと既存 Cache、GQA/MQA の Head 間周波数、cos/sin Cache の device・dtype・容量を確認します。

FlashAttention とも併用でき、Kernel 前または融合 Kernel 内で回転します。速度向上は余分な Tensor とメモリ転送を減らせるかに依存します。

R1q=[01],R2k=[−1−1],(R1q)⊤(R2k)=−1.R_1q=\begin{bmatrix}0\\1\end{bmatrix}, \qquad R_2k=\begin{bmatrix}-1\\-1\end{bmatrix}, \qquad (R_1q)^\top(R_2k)=-1.R1​q=[01​],R2​k=[−1−1​],(R1​q)⊤(R2​k)=−1.

マルチモーダル座標と実装上の境界

画像には行・列、動画には時間もあります。多軸 RoPE は次元を軸へ配分し、軸ごとの相対位相を作ります。番号付け、周波数配分、学習解像度・時間幅が性能を左右し、二次元化だけで任意解像度への汎化は保証されません。

相対位置恒等式には Q/K の互換な回転族が必要です。周波数、配置、動的調整の不一致で崩れ得るため、長文脈障害ではまず位置とキャッシュの整合を確認します。
