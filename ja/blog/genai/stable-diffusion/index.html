Stable Diffusion：加噪から潜在空間での条件付き生成へ

Stable Diffusion はノイズから始め、妥当な画像表現へ近づく方向を繰り返し予測し、最後に潜在変数を画像へ復号します。

W韋 君豪読了目安 11 分

Stable Diffusion はノイズから始め、妥当な画像表現へ近づく方向を繰り返し予測し、最後に潜在変数を画像へ復号します。理解の要点は三つです。拡散モデルが加噪とノイズ除去を定義し、Latent Diffusion が計算を圧縮表現へ移し、テキスト条件と guidance がプロンプトへの応答を調整します。

ここでは、8 倍ダウンサンプリングの自己符号化器、U-Net、CLIP テキストエンコーダーを使う従来の Stable Diffusion v1 を扱います。後続モデルでは構造や学習目標が異なるため、v1 の構成をシリーズ全体へ当てはめることはできません。公式リポジトリ

ノイズ予測から画像を生成できる理由

Lsimple=Ex0,t,ϵ[∥ϵ−ϵθ(xt,t)∥22].\mathcal L_{\mathrm{simple}} =\mathbb E_{x_0,t,\epsilon} \left[\|\epsilon-\epsilon_\theta(x_t,t)\|_2^2\right].Lsimple​=Ex0​,t,ϵ​[∥ϵ−ϵθ​(xt​,t)∥22​].

同じ画素パターンでもノイズ強度によって意味が異なるため、時刻の入力が必要です。モデルが学ぶのは多数の例に共通する条件付きノイズ除去であり、新しい生成結果に対応する元画像を持っているわけではありません。

潜在空間で何が安くなるか

Latent Diffusion はまず自己符号化器を学習します。エンコーダー E\mathcal EE が画像を z0z_0z0​ に圧縮し、その空間で拡散を学び、デコーダー D\mathcal DD が画素を復元します。

z0=E(x0),x^0=D(z0).z_0=\mathcal E(x_0), \qquad \hat x_0=\mathcal D(z_0).z0​=E(x0​),x^0​=D(z0​).

強すぎる圧縮は細部を失い、弱すぎる圧縮は計算負荷を残します。捨てた情報を拡散モデルが必ず復元できるわけでもありません。原論文では、この知覚的圧縮と生成モデリングを分けて学習します。Latent Diffusion

図の構造を見る（原文）
flowchart TD
    X["训练图像 x0"] --> E["图像编码器 E"]
    E --> Z["干净潜变量 z0"]
    Z --> N["按时间步 t 加高斯噪声"]
    N --> ZT["含噪潜变量 zt"]
    TXT["文本提示"] --> TE["文本编码器"]
    TE --> C["条件 Token 表示 c"]
    ZT --> U["U-Net 预测噪声"]
    C --> U
    TIME["时间步 t"] --> U
    U --> LOSS["训练：与已知噪声计算 MSE"]
    START["推理：高斯潜变量 zT"] --> STEP["当前潜变量"]
    STEP --> DU["U-Net 与条件引导"]
    C --> DU
    DU --> SCH["采样器更新到更低噪声"]
    SCH --> STEP
    SCH --> FIN["到达最终潜变量"]
    FIN --> D["图像解码器 D"]
    D --> IMG["生成图像"]

図の上側は学習で、実画像から潜在変数と既知ノイズの教師信号を作ります。下側は推論で、ランダムな潜在変数を反復的にノイズ除去して復号します。文から画像を作る際に、対象画像を先に符号化する必要はありません。時刻列がループの終わりを決め、サンプラーが状態を更新し、U-Net が予測します。

v1 では 512×512512\times512512×512 の画像が 64×64×464\times64\times464×64×4 の潜在変数になります。空間位置は 64 分の 1 ですが、チャネル数や自己符号化器のコストもあるため、実行時間まで正確に 64 分の 1 になるとはいえません。主な利点は、何度も呼び出すノイズ除去ネットワークを小さな格子上で動かせることです。

潜在空間の条件付き目的関数は次のとおりです。

zt=αˉtz0+1−αˉtϵ,LLDM=Ez0,c,t,ϵ[∥ϵ−ϵθ(zt,t,c)∥22].z_t=\sqrt{\bar\alpha_t}z_0+ \sqrt{1-\bar\alpha_t}\epsilon, \qquad \mathcal L_{\mathrm{LDM}} =\mathbb E_{z_0,c,t,\epsilon} \left[\|\epsilon-\epsilon_\theta(z_t,t,c)\|_2^2\right].zt​=αˉt​​z0​+1−αˉt​​ϵ,LLDM​=Ez0​,c,t,ϵ​[∥ϵ−ϵθ​(zt​,t,c)∥22​].

自己符号化器が潜在変数を供給し、拡散ネットワークがノイズ強度ごとの条件付き分布を学びます。実装では潜在変数のスケーリングも使うため、符号化、加噪、復号で尺度をそろえます。

テキスト条件が U-Net に入る経路

テキストエンコーダーがプロンプトを token 表現 ccc に変換します。Cross-Attention の Query は画像潜在特徴、Key と Value はテキスト特徴から作ります。

Q=WQh,K=WKc,V=WVc,Q=W_Qh,\qquad K=W_Kc,\qquad V=W_Vc,Q=WQ​h,K=WK​c,V=WV​c, CrossAttn⁡(h,c)=softmax⁡(QK⊤dk)V.\operatorname{CrossAttn}(h,c) =\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.CrossAttn(h,c)=softmax(dk​​QK⊤​)V.

空間位置ごとに異なるテキスト情報を参照できますが、単語と画素領域の固定対応や、個数・位置関係・綴りの正しさを保証する仕組みではありません。従来の v1 の文から画像への経路に、CLIP の画像エンコーダーは必須ではありません。

Classifier-Free Guidance と条件の強さ

学習中に一定確率で条件を落とし、一つのモデルで条件付きと無条件の予測を学びます。推論では二つの出力を組み合わせます。

ϵcfg=ϵθ(zt,t,∅)+w[ϵθ(zt,t,c)−ϵθ(zt,t,∅)].\epsilon_{\mathrm{cfg}} =\epsilon_\theta(z_t,t,\varnothing) +w\left[\epsilon_\theta(z_t,t,c) -\epsilon_\theta(z_t,t,\varnothing)\right].ϵcfg​=ϵθ​(zt​,t,∅)+w[ϵθ​(zt​,t,c)−ϵθ​(zt​,t,∅)].

この定義では w=0w=0w=0 が無条件、w=1w=1w=1 が通常の条件付き予測、w>1w>1w>1 が条件方向の増幅です。(1+w)ϵc−wϵu(1+w)\epsilon_c-w\epsilon_u(1+w)ϵc​−wϵu​ と書く文献もあるので、値を比較する前に定義を確認します。Classifier-Free Guidance

guidance を強めると条件への一致が高まりやすい一方、多様性の低下、過飽和、偏りの増幅が起こり得ます。一般的な負のプロンプトは無条件側のテキストを置き換えて対比方向を変えるもので、特定物体の不出現を保証する論理制約ではありません。複数 seed で条件追従と品質を評価します。

サンプラーは経路を、スケジュールは尺度を決める

サンプラーはネットワーク出力から次のノイズ水準へ状態を更新します。scheduler は時刻選択、ノイズ尺度、予測形式も扱う場合があります。DDPM は確率的な逆遷移を使い、DDIM は同じ学習目標と整合する過程を構成し、設定によって決定的生成や少ないステップを可能にします。DDIM

DDIM の確率性パラメーターをゼロにし、初期ノイズと設定を固定すると経路は決定的になり得ます。ただし、初期ノイズを変えれば別の画像を生成できます。ステップ削減は呼び出し回数を減らす一方、近似誤差を増やし、品質はモデル、解法、guidance に依存します。

比較時はモデル、プロンプト、解像度、guidance、評価方法をそろえます。高次解法は一ステップで複数回ネットワークを呼ぶ場合があるので、名目上のステップ数と実際の評価回数を区別します。

画像変換、局所編集、低ランク適応

画像から画像への生成では、入力を符号化して選んだ水準までノイズを加え、条件付きで除去します。弱いノイズは元情報を多く残し、強いノイズは大きな変更を許します。局所編集には、モデルとサンプラーが対応するマスクなどの領域条件が必要です。文章だけで領域外の画素を完全に保持する保証は得られません。

LoRA は選んだ重みに低ランク更新を加えます。

W=W0+ΔW,ΔW=αrBA,W=W_0+\Delta W, \qquad \Delta W=\frac{\alpha}{r}BA,W=W0​+ΔW,ΔW=rα​BA,

W0∈Rdout×dinW_0\in\mathbb R^{d_{out}\times d_{in}}W0​∈Rdout​×din​ を固定し、B∈Rdout×rB\in\mathbb R^{d_{out}\times r}B∈Rdout​×r と A∈Rr×dinA\in\mathbb R^{r\times d_{in}}A∈Rr×din​ を学習します。学習パラメーター数は doutdind_{out}d_{in}dout​din​ から約 r(dout+din)r(d_{out}+d_{in})r(dout​+din​) へ減ります。U-Net の Attention 射影などに適用し、方式によってはテキストエンコーダーも調整します。対象モジュールが変更可能な計算経路を決めます。LoRA、Diffusers の学習ガイド

学習状態とアダプター容量は減りますが、少量データでの汎化は保証されません。姿勢や背景が限られると、概念と偶然の属性が結び付くことがあります。構図、背景、プロンプトの組み合わせ、seed を変え、元の能力への影響も確認します。

生成品質は複数の観点で確かめる

写実性、条件との一致、構造の正しさ、多様性は別の評価軸です。FID は生成集合と参照集合の特徴統計を比較しますが、各画像がプロンプトを満たすかは判断できません。図文類似度も個数、否定、局所文字を見落とし得るため、構造化したプロンプト、人による確認、専用指標を組み合わせます。

編集では領域外の不要な変更を、概念適応では学習画像の再現と未見場面への汎化を区別します。一枚の成功例だけで全体の性能を示すことはできません。
