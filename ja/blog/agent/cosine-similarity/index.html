検索スコアはなぜ 0.9 付近に集まるのか：コサイン類似度と Agent の根拠判断

高次元での集中、共通方向、学習温度、スコア変換を分けて考え、Agent の検索結果を根拠として評価する方法を整理します。

W韋 君豪読了目安 8 分

Agent が知識ベースを検索すると、1 件目が 0.93、2 件目が 0.92、その後も 0.9 前後という結果が返ることがあります。どれも関連性が高そうですが、読んでみると話題が近いだけで、質問には答えていない文書もあります。

ここで思い浮かぶのが「次元の呪い」です。embedding が高次元すぎるために、コサイン類似度で文書を区別できなくなったのでしょうか。

分けて考えたいのは、スコアが集中する理由と、高い値に集中する理由です。高次元の幾何は、一定の仮定の下で集中を説明しますが、0.9 という値を直接説明するものではありません。

高次元のランダムベクトルでは、コサイン類似度は 0 に近づく

コサイン類似度は、二つの非零ベクトルの向きがどれだけ近いかを測ります。

cos⁡(x,y)=x⊤y∥x∥∥y∥\operatorname{cos}(x,y)=\frac{x^\top y}{\|x\|\|y\|}cos(x,y)=∥x∥∥y∥x⊤y​

単位ベクトルの場合は内積そのものです。x,yx,yx,y が独立で、ddd 次元の単位球面上に一様に分布するなら、

E[x⊤y]=0,Var⁡(x⊤y)=1d\mathbb E[x^\top y]=0,\qquad \operatorname{Var}(x^\top y)=\frac1dE[x⊤y]=0,Var(x⊤y)=d1​

となります。回転対称性を使えば、一方の向きを固定した内積は、もう一方のランダムな単位ベクトルの、その方向の座標とみなせます。各座標は対等で、二乗和は 1 なので、各座標の二次モーメントは 1/d1/d1/d です。

1024 次元なら標準偏差は約 0.031 です。次元が増えるほど二つのランダムな方向は直交に近づき、コサイン類似度は 0 付近に集中します。球面上のランダムな角度を扱う研究でも、この現象が厳密に示されています。Cai・Fan・Jiang，2013

独立、一様、単位球面という仮定は省略できません。学習されたテキスト embedding は通常、これらの仮定を満たしません。次元数だけで類似度の分布は決まりません。

共通の方向がスコアの基準値を押し上げる

簡単なモデルを考えます。

x=α u+1−α ax=\sqrt{\alpha}\,u+\sqrt{1-\alpha}\,ax=α​u+1−α​a y=α u+1−α by=\sqrt{\alpha}\,u+\sqrt{1-\alpha}\,by=α​u+1−α​b

u,a,bu,a,bu,a,b は単位ベクトルで、a,ba,ba,b は uuu と直交するとします。両者には共通方向 uuu が含まれ、a,ba,ba,b がそれぞれ異なる成分を表します。このとき、

cos⁡(x,y)=α+(1−α)a⊤b\operatorname{cos}(x,y)=\alpha+(1-\alpha)a^\top bcos(x,y)=α+(1−α)a⊤b

です。a,ba,ba,b が uuu に直交する高次元の単位球面上で独立かつ一様なら、a⊤ba^\top ba⊤b は 0 に近づきます。α=0.9\alpha=0.9α=0.9 なら、全体のコサイン類似度は 0.9 付近に集中します。

つまり、共通方向が高い基準値を作り、異なる成分の高次元分布が変動の大きさを決めるわけです。これは数学的な例であり、実際のモデルを常に固定比率で分解できるという主張ではありません。

初期の研究では、BERT、ELMo、GPT-2 の文脈付き単語表現に、異方性と呼ばれる方向の偏りが観察されました。ただし、すべての Transformer の表現が同じ方向に集まるとは限りません。後続研究では反例も示されています。Ethayarajh，2019；Anisotropy is Not Inherent to Transformers，2024

平均コサイン類似度だけで異方性を完全に記述することもできません。一本の直線の正負二方向にしかベクトルがなくても、両方向が対称なら平均コサイン類似度は 0 になり得ます。

学習では小さなスコア差でも強い信号になる

E5 の公式 FAQ は、コサイン類似度が 0.7–1.0 に分布することを想定内の挙動とし、InfoNCE 対照学習で使う 0.01 という低い温度と関連づけています。E5 公式説明

正例に対する対照学習の損失は、次のように書けます。

L=−log⁡exp⁡(s+/τ)∑jexp⁡(sj/τ)L=-\log\frac{\exp(s_+/\tau)}{\sum_j\exp(s_j/\tau)}L=−log∑j​exp(sj​/τ)exp(s+​/τ)​

sjs_jsj​ はクエリと候補の類似度、τ\tauτ は温度です。正例と負例の差が 0.05、温度が 0.01 なら、指数項の比は、

exp⁡(0.050.01)=e5≈148\exp\left(\frac{0.05}{0.01}\right)=e^5\approx148exp(0.010.05​)=e5≈148

となります。小さく見える差でも、学習目的の中では大きな違いになります。

ただし、これは温度がスコア差をどう増幅するかを示す計算です。低温度なら必ずコサイン類似度が 0.9 に集中する、とは導けません。 分布はデータ、モデル、学習過程全体にも左右されます。

固定したクエリに対し、全候補のスコアに同じ定数を足しても softmax は変わりません。この目的関数は「0.9 が何％の関連確率を表すか」を直接定めていません。候補間の相対的な競争を学習するもので、信頼度が自動的に校正されるわけではありません。

より直接的な二つの要因：スコア変換と Top-K

幾何を考える前に、画面の数値が何かを確認します。

例えば Elasticsearch の dense_vector で cosine 類似度を使う場合、文書の _score は次の式です。

_score=1+cos⁡(q,d)2\text{\_score}=\frac{1+\operatorname{cos}(q,d)}2_score=21+cos(q,d)​

この設定では、表示値 0.9 は元のコサイン類似度 0.8 に相当し、スコア差も半分になります。クエリ方式によって計算は異なり得るため、score という名前だけで元のコサイン類似度だと判断せず、実際の設定を確認します。Elasticsearch 公式文書

検索結果は通常 Top-K だけです。文書集合全体の分布が広くても、上位数件だけなら狭い区間に収まることがあります。重複文書や大きく重なったチャンクも、候補を似通わせる可能性があります。

「返された 10 件が 0.9 付近」と「無関係な文書をランダムに選んでも 0.9 付近」は、別々に調べる必要があります。

Agent では、文書が回答の根拠になるかが重要

以下は説明用の例で、実モデルの測定結果ではありません。

候補文書 コサイン類似度 内容
A 0.93 質問に必要な結論を明示している
B 0.92 同じ話題を扱うが答えはない
C 0.91 対象バージョンが異なり、そのまま引用できない

どれも高得点ですが、根拠としての価値は違います。意味が近くても、質問のバージョン、時点、条件を満たすとは限らず、Agent の最終的な主張を支持する保証もありません。

検索システムを確認するなら、次の順で見ます。

  1. スコアの定義を確認する。 少数のベクトル対で元のコサイン類似度を計算し、サービスの出力と比べます。
  2. 入力処理を確認する。 クエリと文書のモデルの組み合わせ、接頭辞、pooling、重要部分の切り捨てを確認します。例えば E5 はタスクに応じた接頭辞を指定しています。E5 の使用方法
  3. 候補の種類を分けて比べる。 Top-K だけでなく、ランダムな文書、実際に関連する文書、同じ話題でも答えにならない難しい負例を見ます。
  4. 順位と回答保留を別々に評価する。 Recall@K、MRR、nDCG で検索や順位を評価します。根拠不足を検出する場合は、答えのないクエリも用意し、検証データでしきい値を選び、独立したテストデータで確認します。

答えが候補に入っているのに順位が低い場合は、reranker を評価できます。質問と文書を一緒に読んで細かな関連性を判断しますが、そのスコアも校正なしに回答正解率とは解釈できません。

スコアを広く分布させるためだけに、すべてのベクトルを白色化したり次元削減したりする必要はありません。L2 正規化はコサイン類似度を変えず、スコアを単調に引き伸ばしても順位は変わりません。中心化、白色化、次元削減は幾何構造を変えるため、効果はタスク評価で判断します。異方性の研究でも「一様なほど良い」が普遍的な法則ではないことが示されています。Stable Anisotropic Regularization

0.9 付近に集中したスコアを見たら、その数値の意味、関連文書と無関係な文書の区別、そして候補が実際に回答を支持するかを調べます。コサイン類似度は Agent が読むべき資料を探す助けになります。その資料を根拠として使えるかは、さらに判断が必要です。
