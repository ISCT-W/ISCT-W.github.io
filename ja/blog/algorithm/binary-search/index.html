二分探索：答えが存在し得る区間を残す

## 答えを含み得る区間を残す

W韋 君豪読了目安 7 分

答えを含み得る区間を残す

図の構造を見る（原文）
flowchart TD
 A["搜索第一个真：半开区间 [l, r)"] --> B{"l 小于 r？"}
 B -->|否| Z["返回 l；等于 n 表示不存在"]
 B -->|是| M["mid = l + (r-l) // 2"]
 M --> C{"条件在 mid 成立？"}
 C -->|是| D["r = mid，保留最左的真"]
 C -->|否| E["l = mid + 1，排除左侧假值"]
 D --> B
 E --> B

図では「条件を満たす最初の位置を探す」という規約を使っています。別の問題では判定条件と区間の境界を定義し直す必要があり、更新式をそのまま流用することはできません。

まず問題の構造を見極める

候補に順序を付け、一度の判定で答えが片側にしか存在しないと証明できるとき、二分探索が使えます。典型例は、条件が偽から真へ一度だけ変わる場合です。「この候補は大きすぎるので、それ以上もすべて不適切」と説明できる場合も同様です。

  • 回転した配列の最小値： 重複がなければ、nums[i] <= nums[-1] は大きい値の区間で偽、小さい値の区間で真になります。最初の真を探します。回転していない場合はすべて真です。
  • 二つのソート済み配列の中央値： 短い方の配列の分割位置を二分探索します。左側に取る個数が少なすぎれば右へ、多すぎれば左へ動かします。両配列が内部で整列済みであることが根拠です。

状態と不変条件を明確にする

本質は中央の値を見ることではなく、探索空間の半分を除ける単調な条件を見つけることです。ループの前に区間の意味を定めます。境界を更新するときは、mid 自体が答えになり得るかを判断し、残すか除外するかを決めます。

学習用の骨格

最初の例は、単調な条件を満たす最初の位置を探します。check(i) の結果が False, ..., False, True, ..., True となるように問題に合わせて実装します。戻り値 n は、該当する位置がないことを表します。

left, right = 0, n  # 答案在 [left, right]，n 是未找到的哨兵
while left < right:
    mid = (left + right) // 2
    if check(mid):
        right = mid  # mid 仍可能是第一个成立的位置
    else:
        left = mid + 1
answer = left

二つ目は、制約を満たす分割位置を探す疑似コードです。

在较短数组的所有分割位置 [0, m] 中搜索
while left <= right:
    i = 中间分割位置
    j = 要求的左半总长度 - i
    if i 太小: left = i + 1
    elif i 太大: right = i - 1
    else: 根据分割两侧的边界值计算答案并返回

境界の更新は探索目標と対応させます。なぜ片側を捨てられるのかを先に説明し、その後で mid と mid ± 1 を選びます。

例1：回転したソート済み配列の最小値

問題：LeetCode 153

class Solution:
    def findMin(self, nums: List[int]) -> int:
        # 旋转后的数组是两段升序数组[A, B]构成，其中A的所有元素都大于B的任何元素（注意，如果没旋转则只有一段）；
        # 因此，最小值一定是B的第一个元素（如果没旋转则是A的第一个）
        # 所以用二分查找去找到分界点即可！
            # mid > nums[-1]：m还在A，最小在右半； mid < nums[-1]：m在B，最小在左半；不停缩小最小区间即可
        l, r = 0, len(nums) - 1

        while l < r:
            m = (l + r) // 2
            if nums[m] > nums[-1]:
                l = m + 1
            else: r = m # 为什么保留m而不是m-1？因为m自己可能就是最小值
        return nums[l]

実装のポイント： 末尾の要素との比較で、mid が大きい値の区間と小さい値の区間のどちらにあるかを判定します。nums[m] > nums[-1] なら最小値は右側です。それ以外では m 自体が最小値の可能性があるため、r = m とします。

例2：二つのソート済み配列の中央値（Hard）

問題：LeetCode 4

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        # 核心思想很简单，对两个数组找分界线，使得分界线满足下面要求，然后这两分界线的位置刚好对应中位即可。
        # merged = nums1 + nums2
        # merged.sort()

        # mid = (len(merged) - 1) // 2
        # return merged[mid] if len(merged) % 2 else (merged[mid] + merged[mid + 1]) / 2
    
        """
        问题理解:
        首先，我们需要明确什么是中位数：对于一个有序数组，如果长度是奇数，中位数就是中间那个数；如果是偶数，中位数是中间两个数的平均值。
        对于两个有序数组，我们需要找到合并后的有序数组的中位数。直接合并再找中位数的时间复杂度是O(m+n)，不符合题目要求。我们需要更高效的O(log(min(m,n)))的解法。

        核心思路：二分查找分割线
        我们可以将问题转化为在两个数组中寻找合适的分割线，使得分割线左边的所有元素都小于等于右边的所有元素，并且左右两边的元素数量相等或左边多一个。
        具体来说：
        我们需要在较短的数组上进行二分查找（为了优化时间复杂度）
        对于每个可能的分割位置，计算另一个数组的对应分割位置（见下）
        检查分割线是否满足条件（左边最大值 ≤ 右边最小值）
        根据比较结果调整二分查找的范围

        详细步骤:
        确保第一个数组是较短的：这样我们可以将时间复杂度优化到O(log(min(m,n)))
        定义分割线：分割线将数组分为左右两部分
        对于数组A，分割线在i的位置，左边有i个元素，右边有m-i个元素
        对于数组B，分割线在j的位置，左边有j个元素，右边有n-j个元素

        理想分割条件：
        i + j = (m + n + 1) / 2（确保左边元素数量足够）
        A[i-1] ≤ B[j] 且 B[j-1] ≤ A[i]（左边最大值 ≤ 右边最小值）

        二分查找过程：
        初始化二分查找范围：iMin = 0, iMax = m
        计算i = (iMin + iMax) / 2
        计算j = (m + n + 1) / 2 - i
        根据比较结果调整iMin或iMax
        """
        # 确保nums1是较短的数组
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
        
        m, n = len(nums1), len(nums2)
        imin, imax, half_len = 0, m, (m + n + 1) // 2
        
        while imin <= imax:
            i = (imin + imax) // 2
            j = half_len - i
            
            # 处理边界情况
            if i < m and nums2[j-1] > nums1[i]:
                # i太小，需要增大
                imin = i + 1
            elif i > 0 and nums1[i-1] > nums2[j]:
                # i太大，需要减小
                imax = i - 1
            else:
                # 找到合适的分割线，处理中位数计算
                
                # 计算左半部分最大值
                if i == 0:
                    max_of_left = nums2[j-1]
                elif j == 0:
                    max_of_left = nums1[i-1]
                else:
                    max_of_left = max(nums1[i-1], nums2[j-1])
                
                # 如果总数是奇数，直接返回左半部分最大值
                if (m + n) % 2 == 1:
                    return max_of_left
                
                # 计算右半部分最小值
                if i == m:
                    min_of_right = nums2[j]
                elif j == n:
                    min_of_right = nums1[i]
                else:
                    min_of_right = min(nums1[i], nums2[j])
                
                # 如果是偶数，返回平均值
                return (max_of_left + min_of_right) / 2.0

分割の考え方

配列を実際に結合せず、それぞれに区切りを置きます。左右の総要素数を同じにするか、左を一つだけ多くし、同時に次を満たします。

nums1[i - 1] <= nums2[j]
nums2[j - 1] <= nums1[i]

短い配列の分割位置 i だけを二分探索し、もう一方は j = half_len - i で決まります。

  • nums2[j - 1] > nums1[i]：i が小さすぎるため右へ移動します。
  • nums1[i - 1] > nums2[j]：i が大きすぎるため左へ移動します。
  • どちらでもなければ正しい分割です。総要素数が奇数なら左側の最大値、偶数なら左側の最大値と右側の最小値の平均を取ります。

区切りが配列の端になる場合があるため、i == 0、j == 0、i == m、j == n を個別に処理します。
