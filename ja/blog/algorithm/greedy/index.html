貪欲法：局所的な選択が安全であることを示す

## 文字列の区間を閉じる境界

W韋 君豪読了目安 3 分

文字列の区間を閉じる境界

図の構造を見る（原文）
flowchart TD
 Q{"还有未扫描的字符？"} -->|否| Z["返回所有片段长度"]
 Q -->|是| A["扫描下一个位置 i"]
 A --> B["end = max(end, 当前字符最后位置)"]
 B --> C{"i 已到达 end？"}
 C -->|否| Q
 C -->|是| D["记录当前片段长度"]
 D --> E["下一个片段从 i+1 开始"]
 E --> Q

区間に含まれる文字は、そのすべての出現が同じ区間に収まらなければなりません。最後の出現位置の最大値が必要な境界です。走査がそこに達したら直ちに区切っても、後続の区間に制約を加えません。

まず問題の構造を見極める

段階的な局所選択があり、「この選択を先にしても、後で最適解を得られる」と証明できる場合に貪欲法を考えます。交換法、越えられない境界、不変条件などで証明します。最大値や最小値を求めるというだけでは貪欲法とは判断できません。

Partition Labelsでは、区間内の各文字の最後の出現位置まで含める必要があります。切れ目はそれらの最大値より前には置けません。最も早い合法な切れ目で区切れば、後続を制限せず、残りの分割機会を最大限残せます。

基本の考え方

各段階で現在有利な選択をします。重要なのは直感ではなく、その選択が後続の最適解を損なわないという証明です。現在の区間が到達すべき最遠の境界を管理する形がよく使われます。

手順と学習用の骨格

局所的な選択を定義し、安全性を証明してから、管理する状態を決めます。あらゆる貪欲法を表すコードはありません。以下は「必要な最遠境界を管理し、最も早い合法位置で区切る」パターンだけの骨格です。

求出每个元素要求覆盖到的位置（本题是字符最后出现的位置）
start = 0，end = 0
for 位置 i 从左到右:
    end = max(end, 当前元素要求覆盖到的位置)
    if i == end:
        记录区间 [start, end]
        start = i + 1

復習では、なぜ end より前では切れないのか、なぜ end ですぐ切っても悪化しないのかを確認します。

例：Partition Labels

問題：LeetCode 763

class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        if len(s) == 1: return [1]
        l, max_r = 0, -1
        ans = []
        for i, ch in enumerate(s):
            cur_r = i # 防止根本就没有重复导致的一路走到尾！！！！
            for j in range(i+1, len(s)):
                if s[j] == ch:
                    cur_r = j
            max_r = max(max_r, cur_r) # 每次找到当前最右并更新直到相遇就说明是一个串了
            if i == max_r: # 已经找完
                ans.append(max_r - l + 1)
                l = i + 1
                
        return ans

実装のポイント： 区間内の文字を走査し、それぞれの最終出現位置まで max_r を広げます。i == max_r になれば、その区間の文字は後に現れないため直ちに分割できます。

掲載コードは毎回後続部分を走査して最終位置を探すため最悪 O(n²) です。最終位置をハッシュ表で前計算すれば、同じ貪欲な考え方で O(n) にできます。
