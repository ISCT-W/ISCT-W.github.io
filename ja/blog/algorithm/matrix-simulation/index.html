## 一辺を走査するたびに未訪問領域を縮める

W韋 君豪読了目安 3 分

一辺を走査するたびに未訪問領域を縮める

図の構造を見る（原文）
flowchart TD
 A{"还有未遍历的行与列？"} -->|否| Z["遍历结束"]
 A -->|是| B["沿上边从左向右，top 加 1"]

 C -->|是| Z
 C -->|否| D["沿右边从上向下，right 减 1"]

一行や一列だけが残った場合は、一度曲がるだけで領域を使い切ることがあります。外側のループの先頭だけで境界を確認しても不十分です。

まず問題の構造を見極める

訪問や移動の規則が与えられ、その順序で出力または行列を変更する問題なら、直接シミュレーションできます。螺旋走査では外側の一辺を訪問するたびに、未訪問領域が小さな長方形として残ります。そのため、各マスに印を付けず四つの境界だけを管理できます。

状態と不変条件を明確にする

位置・方向・境界などの状態、移動規則、訪問のタイミング、終了条件を決めます。ここでは一辺を終えるたびに対応する境界を縮め、残りの領域が有効か確認します。「四つの境界が未訪問領域をちょうど囲む」という不変条件を保ち、最後の一行や一列の重複訪問を防ぎます。

学習用の骨格：四つの境界を縮める

以下は空でない行列の疑似コードです。「一辺を訪問する」は対応するループに展開します。別の行列シミュレーションでは規則に応じた状態を選び、必ずしも四境界で扱えるとは限りません。

top = 0，bottom = 行数-1，left = 0，right = 列数-1
while top <= bottom 且 left <= right：
    访问上边：从左到右；top += 1
    若区域已空：结束
    访问右边：从上到下；right -= 1
    若区域已空：结束
    访问下边：从右到左；bottom -= 1
    若区域已空：结束
    访问左边：从下到上；left += 1

例：Spiral Matrix

問題：LeetCode 54

class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        ans = []
        top, left, bottom, right = 0, 0, len(matrix) - 1, len(matrix[0]) - 1

        while top <= bottom and left <= right:
            if top <= bottom:
                for i in range(left, right + 1):
                    ans.append(matrix[top][i])
                top += 1
            if left <= right:
                for j in range(top, bottom + 1):
                    ans.append(matrix[j][right])
                right -= 1
            if top <= bottom:
                for k in range(right, left - 1, -1):
                    ans.append(matrix[bottom][k])
                bottom -= 1
            if left <= right:
                for l in range(bottom, top - 1, -1):
                    ans.append(matrix[l][left])
                left += 1

        return ans

実装のポイント： 上・右・下・左の順で外周を走査し、top/right/bottom/left を更新します。途中の境界判定は、最後に残る一行や一列を二度訪問しないために必要です。
