筆記試験のあとに振り返るソート：Pythonの実装6つ

筆記試験でソートが出てきて、かなり忘れていることに気づいた。バブル、挿入、クイック、マージ、選択、計数ソートを短く復習する。

W韋 君豪読了目安 4 分

筆記試験でこれらのソートアルゴリズムに出会い、かなり忘れていることに気づきました。あとで見返せるように、6つのPython実装と、それぞれの動きを短くまとめておきます。

バブルソート

def bubble_sort(nums):
    n = len(nums)
    for i in range(n):
        for j in range(n - 1 - i):
            if nums[j] > nums[j + 1]:
                nums[j], nums[j + 1] = nums[j + 1], nums[j]
    return nums

隣り合う要素の順序が逆なら交換します。1周ごとに未整列部分の最大値が右端へ移るため、内側のループは n - 1 - i までです。この実装には早期終了がなく、時間計算量は常に O(n2)O(n^2)O(n2) です。

挿入ソート

def insertion_sort(nums):
    for i in range(1, len(nums)):
        x = nums[i]
        j = i - 1
        while j >= 0 and nums[j] > x:
            nums[j + 1] = nums[j]
            j -= 1
        nums[j + 1] = x
    return nums

左側を整列済みとみなし、現在の要素を x に保存します。x より大きい要素を右へずらし、空いた位置に挿入します。最悪の時間計算量は O(n2)O(n^2)O(n2)、すでに整列済みなら O(n)O(n)O(n) です。

クイックソート

def quick_sort(nums):
    if len(nums) <= 1:
        return nums

    pivot = nums[len(nums) // 2]
    left = [x for x in nums if x < pivot]
    mid = [x for x in nums if x == pivot]
    right = [x for x in nums if x > pivot]

    return quick_sort(left) + mid + quick_sort(right)

中央の位置にある要素を pivot とし、それより小さい・等しい・大きい値に分けて、左右のグループを再帰的に整列します。平均時間は O(nlog⁡n)O(n\log n)O(nlogn)、最悪は O(n2)O(n^2)O(n2) です。中央の位置の要素が中央値とは限らず、この実装は新しいリストを作るためインプレースではありません。

マージソート

def merge_sort(nums):
    if len(nums) <= 1:
        return nums

    mid = len(nums) // 2
    left = merge_sort(nums[:mid])
    right = merge_sort(nums[mid:])

    res = []
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            res.append(left[i])
            i += 1
        else:
            res.append(right[j])
            j += 1

    return res + left[i:] + right[j:]

配列を半分ずつに分け、それぞれを再帰的に整列してから、2本のポインタで併合します。時間計算量は O(nlog⁡n)O(n\log n)O(nlogn) です。<= によって同じ値なら左側を先に取り、最後に残った側の要素をつなげます。

選択ソート

def selection_sort(nums):
    n = len(nums)

    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if nums[j] < nums[min_idx]:
                min_idx = j
        nums[i], nums[min_idx] = nums[min_idx], nums[i]

    return nums

未整列部分から最小値を探し、位置 i の要素と交換します。バブルソートと違い、各周で最小値を決めてから1回交換する形で、時間計算量は O(n2)O(n^2)O(n2) です。

計数ソート

def counting_sort(nums):
    if not nums:
        return nums

    mn, mx = min(nums), max(nums)
    count = [0] * (mx - mn + 1)

    for x in nums:
        count[x - mn] += 1

    res = []
    for i, c in enumerate(count):
        res.extend([i + mn] * c)

    return res

各整数の出現回数を数え、小さい値から順に配列を復元します。添字を x - mn とするため負の整数にも対応します。値の範囲を k=max⁡(nums)−min⁡(nums)+1k = \max(nums)-\min(nums)+1k=max(nums)−min(nums)+1 とすると時間は O(n+k)O(n+k)O(n+k) ですが、範囲が広いとカウント配列が多くのメモリを使います。
