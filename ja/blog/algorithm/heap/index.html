## 二つの境界値で中央値を管理する

W韋 君豪読了目安 4 分

二つの境界値で中央値を管理する

図の構造を見る（原文）
flowchart LR
 A["新元素"] --> B["按大小关系放入一侧"]
 B --> L["较小一半：最大堆"]
 B --> R["较大一半：最小堆"]
 L <--> S["重新平衡数量"]
 S <--> R
 L --> M["奇数取较多侧堆顶；偶数取两堆顶均值"]
 R --> M

二つのヒープで、小さい半分の最大値と大きい半分の最小値を保持します。個数差を1以下に保つだけでなく、左側のすべての値が右側以下であることも必要です。

まず問題の構造を見極める

候補が増減し、その都度最小値や最大値だけが必要なら、ヒープで全体の再ソートを避けられます。動的な中央値なら小さい半分と大きい半分に分け、境界の要素を管理します。ヒープが保証するのは先頭が最良であることだけで、内部配列全体がソートされているわけではありません。

基本の考え方

ヒープは最小値・最大値を繰り返し取り出す処理に適しています。Pythonの heapq は最小ヒープなので、最大ヒープとして使う場合は値を負にして保存します。

学習用の骨格

優先度を定義し、先頭を繰り返し取り出します。以下の疑似コードでは候補の処理などを問題に応じて補います。状態オブジェクトを保存するときは (priority, unique_id, state) とすれば、優先度が同じ場合にも比較不能なオブジェクト同士を比較せずに済みます。

把初始候选按优先级放入堆
while 堆非空:
    取出当前优先级最优的候选
    若采用了保留旧条目的更新策略，先检查它是否过期
    处理候选；若产生新候选，按优先级入堆

二つのヒープで中央値を求める場合の不変条件は二つです。小さい半分の全要素が大きい半分の全要素以下であることと、小さい半分の個数が同じか一つ多いことです。

插入 x:
    x 先进入较小半边的大顶堆
    把大顶堆最大值移到较大半边的小顶堆，恢复两边大小关系
    若小顶堆数量更多，把其最小值移回大顶堆
查询中位数（至少已有一个数）:
    数量为奇数：取大顶堆堆顶
    数量为偶数：取两堆堆顶的平均值

例：データストリームの中央値（Hard）

問題：LeetCode 295

import heapq

class MedianFinder:
    # 维护一个最小堆和一个最大堆，保证，最大堆的所有值比最小堆的小且两边堆数量不差超过1，那pop出来的就是中位数
    def __init__(self):
        self.min_heap = []
        heapq.heapify(self.min_heap)
        self.max_heap = []
        heapq.heapify(self.max_heap)

    def addNum(self, num: int) -> None:
        heapq.heappush(self.max_heap, -num) # 先放到大顶堆 - 可以保证大顶堆一定不少于小顶堆，方便维护
        # 数字丢到小顶堆，保证大顶所有数都比小顶小
        heapq.heappush(self.min_heap, -heapq.heappop(self.max_heap))
        # 平衡数量
        if len(self.min_heap) > len(self.max_heap):
            heapq.heappush(self.max_heap, -heapq.heappop(self.min_heap))

    def findMedian(self) -> float:
        # 奇数 则max_heap多一个
        if len(self.max_heap) > len(self.min_heap):
            return -self.max_heap[0]
        
        # 偶数 则每个堆一个
        return (-self.max_heap[0] + self.min_heap[0]) / 2


# Your MedianFinder object will be instantiated and called as such:
# obj = MedianFinder()
# obj.addNum(num)
# param_2 = obj.findMedian()

考え方： 最大ヒープに小さい半分、最小ヒープに大きい半分を入れます。左右の大小関係を保ち、最大ヒープの個数を同数か一つ多くします。挿入時は二つのヒープを経由して大小関係を整え、個数を調整します。奇数個なら最大ヒープの先頭、偶数個なら両方の先頭の平均が中央値です。
