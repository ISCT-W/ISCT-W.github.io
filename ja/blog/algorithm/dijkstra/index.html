## 距離表と最小ヒープで探索を進める

W韋 君豪読了目安 4 分

距離表と最小ヒープで探索を進める

図の構造を見る（原文）
flowchart TD

 Q -->|否| Z["结束：返回已求得距离"]

 D --> E{"比已知距离更优？"}

 F --> N
 E -->|否| N

最小労力経路では、候補のコストを max(現在のコスト, 新しい辺の高低差) で計算します。加算型の最短経路と緩和の枠組みは共通ですが、経路コストの定義が異なります。

問題の構造と状態設計

  • 同じ状態に高いコストで到達しても、その後の遷移が有利にならないなら、始点から各状態や終点への最適経路を求める際に dist[state] だけを保持できます。
  • 経路を延ばしてもコストが下がらず、同じ遷移がコストの大小関係を保つことが重要です。非負の辺を持つ最短経路の cost + weight と、ボトルネック経路の max(cost, weight) はどちらも満たします。負の辺がある一般の最短経路にはそのまま使えません。
  • 最小ヒープから最も安い候補を取り出し、古い記録を飛ばして隣接状態を緩和します。有効な記録を取り出した時点で最適コストが確定するため、それが終点なら返せます。
  • 残り使用回数や鍵の有無などが次の選択に影響するなら、それらも状態に含めます。位置だけで距離を管理してはいけません。

基本テンプレート

以下の骨格では、問題ごとに実装する処理を中国語のプレースホルダーで残しています。主な変更点は状態の定義と new_cost の計算方法です。

"""
Dijkstra 通用模版：
1. 建图 / 定义状态空间
2. 初始化 dist
3. 起点状态入堆

while heap 非空:
    取出当前 cost 最优的状态

    如果这是过期状态:
        continue

    for 每一个可以转移到的下一状态:
        计算 new_cost

        if new_cost 优于 dist[next_state]:
            更新 dist
            next_state 入堆
"""

例：最小労力の経路

問題：LeetCode 1631

class Solution:
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
        """
        Dijkstra 通用模版：
        1. 建图 / 定义状态空间
        2. 初始化 dist
        3. 起点状态入堆

        while heap 非空:
            取出当前 cost 最优的状态

            如果这是过期状态:
                continue

            for 每一个可以转移到的下一状态:
                计算 new_cost

                if new_cost 优于 dist[next_state]:
                    更新 dist
                    next_state 入堆
        """
        m, n = len(heights), len(heights[0])
        dists = [[float('inf')] * n for _ in range(m)]
        dists[0][0] = 0

        import heapq
        pq = [(0, 0, 0)] # cost, r, c
        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]
        while pq:
            cost, r, c = heapq.heappop(pq)
            if cost > dists[r][c]: continue
            if r == m - 1 and c == n - 1: return cost
            for dr, dc in directions:
                nr, nc = r + dr, c + dc 
                if 0 <= nr < m and 0 <= nc < n:
                    edge_cost = abs(heights[nr][nc] - heights[r][c])
                    new_cost = max(cost, edge_cost)
                    if new_cost < dists[nr][nc]:
                        dists[nr][nc] = new_cost
                        heapq.heappush(pq, (new_cost, nr, nc))

        return dists[-1][-1]

コードとテンプレートの対応

  • 状態空間： 各マス (r, c) がノードで、上下左右への移動が辺です。
  • 距離： dists[r][c] は始点からそのマスまでの最小労力です。
  • 初期要素： (0, 0, 0) は始点のコストが0であることを示します。
  • 古い状態： cost > dists[r][c] なら、既により良い経路があるため無視します。
  • 遷移： 辺のコストは高低差の絶対値、経路の労力は最大の辺コストなので、new_cost = max(cost, edge_cost) です。
  • 緩和： コストが改善すれば dists を更新し、新しい候補をヒープに入れます。
