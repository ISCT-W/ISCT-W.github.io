バックトラッキング：選択・探索・取り消し

## 選択して再帰し、元に戻す

W韋 君豪読了目安 4 分

選択して再帰し、元に戻す

図の構造を見る（原文）
flowchart TD
 A["进入当前递归层"] --> B{"已构成完整答案？"}
 B -->|是| C["保存路径副本并返回"]
 B -->|否| H{"还有未尝试的候选？"}
 H -->|否| R["返回上一层"]
 H -->|是| D["取一个候选并检查合法性"]
 D --> V{"合法？"}
 V -->|否| H
 V -->|是| E["修改共享路径 / 棋盘状态"]
 E --> F["递归探索下一层"]
 F --> G["撤销本层修改"]
 G --> H

共有状態をその場で変更する場合は、再帰から戻ったときに、その階層で加えた変更を取り消します。毎回新しい経路のコピーを渡す場合は、オブジェクトの分離が取り消しの役割を担います。

まず問題の構造を見極める

すべての有効な解を列挙し、各解を複数の候補から段階的に選んで構築できるなら、選択の過程を決定木として考えられます。回文分割では「次の区間をどこで切るか」、Nクイーンでは「この行のどの列に置くか」が一つの階層です。途中の状態を後の選択で修正できないと分かったら、その場で枝刈りします。

実装を考える順番

  1. 一つの階層の役割と、次の候補を決めるために必要な状態を定義します。
  2. 解が完成する条件を決め、候補の列挙、妥当性の確認、再帰へと進みます。
  3. 共有する経路や盤面を変更した場合は、戻る際に取り消します。毎回コピーを渡すなら不要です。ただし、共有経路を解として保存するときもコピーが必要です。

基本テンプレート

バックトラッキングは、決定木上の深さ優先探索です。候補を一つ選び、次の階層を探索し、選択を取り消します。まず経路 path、次の開始位置、有効な候補、終了条件を明確にします。

以下は学習用の疑似コードです。問題ごとに補う箇所を示す中国語のプレースホルダーは原文のまま残しています。無効な候補は再帰の前に除外します。

def backtrack(state):
    if 满足结束条件:
        保存答案
        return

    for choice in 当前可选项:
        做选择
        backtrack(下一状态)
        撤销选择

例1：回文分割

問題：LeetCode 131. Palindrome Partitioning

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        ans = []

        def backtracing(idx, cur):
            if idx >= len(s): 
                ans.append(cur)
                return
            
            for i in range(idx, len(s)):
                candidate = s[idx: i+1]
                if candidate == candidate[::-1]:
                    backtracing(i+1, cur + [candidate])
        
        backtracing(0, [])
        return ans

実装のポイント： idx は次の区間の開始位置で、ループで終端 i を列挙します。切り出した文字列が回文の場合だけ再帰します。cur + [candidate] は新しい経路を作るため、明示的な取り消しは不要です。

例2：Nクイーン（Hard）

問題：LeetCode 51. N-Queens

class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        # 还是经典回溯，每次放一行直到放到最后一行；放的时候检查同列，左上与右上即可
        board = [['.'] * n for _ in range(n)]
        res = []

        def backtracing(row):
            if row == n: # 走完就是一种成功情况
                tmp = [''.join(i) for i in board]
                res.append(tmp)
                return
            for col in range(n): # 验证是否在这个位置可以放，可以就放并且回溯
                if not self.isValid(board, row, col): continue
                board[row][col] = 'Q'
                backtracing(row + 1)
                board[row][col] = '.'

        backtracing(0)
        return res

    def isValid(self, board, row, col):
        n = len(board)
        
        # 检查同col上方是否有
        for i in range(row):
            if board[i][col] == 'Q': return False

        # 检查右上对角线
        for i, j in zip(range(row - 1, -1, -1), range(col + 1, n, 1)):
            if board[i][j] == 'Q': return False
        
        # 检查左上对角线
        for i, j in zip(range(row - 1, -1, -1), range(col - 1, -1, -1)):
            if board[i][j] == 'Q': return False
    
        return True

考え方： 各行にクイーンを一つ置くため、再帰の深さが行番号になります。列を順に試し、既に置いたクイーンがある上方向の同じ列、左上と右上の対角線だけを確認します。置けるなら次の行へ進み、戻ったら '.' に戻します。row == n で全行への配置が完了するため、盤面のコピーを記録します。
