## 一次元ナップサックでは更新方向が参照する段階を決める

W韋 君豪読了目安 7 分

一次元ナップサックでは更新方向が参照する段階を決める

図の構造を見る（原文）
flowchart TD
 A["状态：容量 j 的最优值或可达性"] --> B{"物品可重复使用？"}
 B -->|每件一次| C["j 从大到小"]
 C --> D["读取上一轮的 dp[j-w]"]
 B -->|可以重复| E["j 从小到大"]
 E --> F["允许读取本轮的 dp[j-w]"]

降順の更新は、同じ段階で同じ品物を繰り返し使うことを防ぎます。昇順では、今更新した状態からさらに遷移できます。0/1ナップサックと個数制限なしナップサックで、特に間違えやすい違いです。

まず問題の構造を見極める

異なる選択が同じ状態に何度も到達し、その状態に以降の結果を決める情報がすべて含まれるなら、結果を保存して再計算を避けられます。最適値を求める場合は、部分問題の最適解から全体の最適解へ遷移できることも確認します。

問題の構造 状態とパターン 根拠
各数を高々一度使い、目標和を作れるか調べる 0/1ナップサック：dp[j] は和 j の到達可能性 到達可能な和だけを管理し、同じ品物を再利用しない
額面を繰り返し使い、必要個数を最小化する 個数制限なし：dp[j] は和 j を作る最少個数 一つ選んだ後の残りも同型の部分問題
二つの文字列の一致・削除・挿入・置換 二系列DP：dp[i][j] は二つの接頭辞の解 末尾を比較すると短い接頭辞へ移れる

状態と不変条件を明確にする

dp の意味、初期値、既知の状態からの遷移、依存先が計算済みになる走査順序。この四つを決めます。

アルゴリズムの骨格

以下は三つのパターンです。目標、品物、遷移を示す原文のプレースホルダーは問題に合わせて実装します。一次元に圧縮すると、更新方向が前の段階と現在の段階のどちらを読むかを決めます。

# 0/1 背包：每个物品只能取一次；这里演示可达性
dp[0] = True，其余为 False
for 数值 x in 物品:
    for j 从目标倒序到 x:
        dp[j] = dp[j] or dp[j - x]

# 完全背包：每种物品可以反复取；这里演示最少数量
dp[0] = 0，其余为无穷大
for 数值 x in 物品:
    for j 从 x 正序到目标:
        dp[j] = min(dp[j], dp[j - x] + 1)

# 双序列 DP：dp[i][j] 对应 A[:i] 和 B[:j]
建立 (len(A) + 1) × (len(B) + 1) 的表
按题意初始化空前缀对应的第一行、第一列
for i 从 1 到 len(A):
    for j 从 1 到 len(B):
        比较 A[i - 1] 与 B[j - 1]
        从 dp[i - 1][j]、dp[i][j - 1]、dp[i - 1][j - 1]
        中选择题意允许的转移，写入 dp[i][j]
返回目标状态

最長共通部分列では空の接頭辞の答えは 0 ですが、編集距離では相手の接頭辞の長さです。二次元状態を一行に圧縮できるとは限らないため、すべての依存関係をどう残すか先に確認します。

一次元DP

例1：和が等しい部分集合への分割

問題：LeetCode 416

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        summ = sum(nums)
        nums.sort(key=lambda x: -x)
        if summ % 2 or nums[0] > summ // 2: return False
        dp = [0 for _ in range(summ + 1)]
        dp[0] = 1

        for n in nums:
            for i in range(len(dp) - 1, 0, -1):
                if i >= n:
                    dp[i] = dp[i] or dp[i - n]
        return dp[summ // 2] == 1

実装のポイント： 全体の和の半分を作れる部分集合があるか、という問題に置き換えます。dp[i] は和 i を作れるかを表します。各数は一度しか使えないため、容量を大きい方から更新します。

問題：LeetCode 279

class Solution:
    def numSquares(self, n: int) -> int:
        # mins = [100000] * (n + 1)
        # mins[0] = 0
        # mins[1] = 1

        # for i in range(2, len(mins)):

        #         if i >= j ** 2:
        #             mins[i] = min(mins[i], mins[i-j**2]+1)
        # return mins[-1]

        # 背包问题：把东西往背包放（外层东西，内层背包）
        # 背包外圈循环物品，内圈循环背包容量；零一背包遵循内圈从大往小循环，完全背包遵循内圈从小往大循环。
            # 0/1 背包倒序：避免当前物品在同一轮被重复使用。
            # 完全背包正序：允许当前物品在同一轮被重复使用。
            
        dp = [100000] * (n + 1)
        dp[0] = 0
        sqaures = [i * i for i in range(1, int(math.sqrt(n)) + 1)]
        for s in sqaures:
            for j in range(s, n + 1): # 放背包
                dp[j] = min(dp[j], dp[j - s] + 1)
        return dp[n]

実装のポイント： 各平方数を何度でも使える品物と考え、dp[j] に和 j を作る最少個数を保存します。容量を昇順で更新するため、今更新した dp[j-s] から同じ平方数を再利用できます。

二次元DP

例3：最長共通部分列

問題：LeetCode 1143

class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        # 再长也超不过短的字符串长度
        dp = [[0 for _ in range(len(text1) + 1)] for _ in range(len(text2) + 1)]
        
        for i in range(1, len(dp)): 
            for j in range(1, len(dp[0])):
                if text2[i - 1] == text1[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else: dp[i][j] = max(dp[i][j - 1], dp[i - 1][j])
        return dp[-1][-1]

実装のポイント： dp[i][j] は text2 の先頭 i 文字と text1 の先頭 j 文字の最長共通部分列長です。末尾が同じなら dp[i-1][j-1] に追加し、異なるなら片方の末尾を除いた二つの結果の大きい方を使います。

例4：編集距離

問題：LeetCode 72

class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        dp = [[i for i in range(len(word1) + 1)] for _ in range(len(word2) + 1)] # 一边长n一边长0的编辑距离一定为n 同理要修轴向
        for i in range(len(dp)):
            dp[i][0] = i
        dp[0][0] = 0 # 用来防止边界问题

        for i in range(1, len(dp)):
            for j in range(1, len(dp[0])):
                if word1[j-1] == word2[i-1]: # 这位一样那么和去掉这位的编辑距离一样
                    dp[i][j] = dp[i-1][j-1]
                else: # 这位不一样就从三种最近可能里取最小再加一即可
                    dp[i][j] = min(dp[i][j-1], dp[i-1][j], dp[i-1][j-1]) + 1
        return dp[-1][-1]

実装のポイント： dp[i][j] は word1[:j] を word2[:i] に変える最少操作数です。文字が同じなら左上の値をそのまま使い、違うなら削除・挿入・置換の最小値に1を足します。先頭行と先頭列は、空文字列との間の連続した挿入または削除を表します。

二種類のナップサックの更新方向

  • 0/1ナップサック： 各品物は一度まで。容量を降順に更新します。
  • 個数制限なしナップサック： 同じ品物を繰り返し使えます。容量を昇順に更新します。
