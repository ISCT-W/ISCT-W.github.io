## 最小被覆区間の拡張と縮小

W韋 君豪読了目安 4 分

最小被覆区間の拡張と縮小

図の構造を見る（原文）
flowchart TD
 Q{"右端还有字符？"} -->|否| Z["返回已记录的最短窗口"]
 Q -->|是| A["右端加入一个字符，更新计数"]
 A --> C{"已覆盖全部需求？"}
 C -->|否| Q
 C -->|是| D["记录更短答案"]
 D --> E["移除左端字符、更新计数，左端前进"]
 E --> C

必要な文字を覆えたら、もう一文字減らすと無効になるところまで縮めます。これは被覆条件の単調性を使っています。この構造がない問題に二つのポインタをそのまま適用してはいけません。

問題の構造と状態設計

  • 対象は連続した部分配列や部分文字列で、要素の追加・除去に応じて情報を差分更新できます。固定長なら右端に合わせて動かします。可変長では、答えを見落とさず両端を一方向に動かせる証明が必要です。
  • Minimum Window Substringでは拡張しても成立した被覆条件は壊れません。成立したら縮め、現在の右端で最短を探します。最長の合法区間では通常「無効な間に縮める」ため、解を更新するタイミングが異なります。
  • 区間最大値では、新しい要素が大きく右にあるなら、古い小さい要素は先に期限切れになり、今後最大になれません。候補キューの末尾から除けます。
  • 連続区間というだけでは不十分です。負数があると拡張しても和が増えるとは限らず、和がKの問題では和の大小で縮める方法を直接使わず、通常は累積和を使います。

学習用の骨格

中国語のプレースホルダーを、具体的なカウンタ、判定条件、答えの更新処理に置き換えます。

最短覆盖窗口：
    left = 0，初始化窗口统计
    for right 从左到右：
        加入 s[right]
        while 窗口覆盖全部需求：
            用 [left, right] 更新最短答案
            移出 s[left]
            left += 1

固定长度 k 的最大值：
    初始化双端队列 q（存下标，数值非递增）
    for right 从左到右：
        删除队尾所有比 nums[right] 小的候选
        right 入队尾
        删除队首所有小于 right-k+1 的过期下标
        if right >= k-1：记录 nums[q[0]]

例1：スライディングウィンドウの最大値（Hard）

問題：LeetCode 239

from collections import deque

class Solution:
    def maxSlidingWindow(self, nums, k):
        q = deque()
        ans = []

        # 把窗口内最大数放在queue头，出窗口则pop掉即可
        for r in range(len(nums)):
            while q and nums[q[-1]] < nums[r]:  # 删除比当前小的原素
                q.pop()
            # 已经没有比当前小的原素，因此可以把index加入表
            q.append(r)
            # 检查left是不是在，不在则删除出窗口内容
            if q[0] < r - k + 1:
                q.popleft()
            # 更新
            if r >= k - 1:
                ans.append(nums[q[0]])
        
        return ans

実装のポイント： q は添字を保存し、値が先頭から末尾へ減少するように保ちます。新しい値より小さい末尾候補と、区間から外れた先頭を削除します。先頭が現在の最大値です。各添字は高々一度ずつ出入りするため、時間は O(n) です。

例2：最小被覆部分文字列（Hard）

問題：LeetCode 76

from collections import Counter, defaultdict

# 请选择 Python3 提交代码，而不是 Python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        cs = Counter()
        ct = Counter(t)
        ans_l, ans_r = -1, len(s)
        l = 0
        for r, ch in enumerate(s):
            cs[ch] += 1
            # 涵盖则挪左边
            while cs >= ct:
                if r - l < ans_r - ans_l:
                    ans_r, ans_l = r, l
                # 挪动l使得到下一个循环
                cs[s[l]] -= 1
                l += 1
        return "" if ans_l < 0 else s[ans_l: ans_r + 1]

考え方： cs >= ct で t の全文字と必要個数を満たすまで右端を広げます。その後は左端を進め、有効な最短区間を探します。必要な文字を除いて条件が崩れたら、再び右へ拡張します。まず実行可能な解を作り、そこからできるだけ縮める考え方です。
