二分木：再帰の戻り値を定義する

## 最大経路和で扱う二種類の情報

W韋 君豪読了目安 6 分

最大経路和で扱う二種類の情報

図の構造を見る（原文）
flowchart TD
 L["L = max(0, 左子树返回值)"] --> N["当前节点"]
 R["R = max(0, 右子树返回值)"] --> N
 N --> A["value + L + R：更新全局答案"]
 N --> P["value + max(L, R)：返回父节点"]

完成した経路は、現在のノードで左右の子をつなげられます。一方、親へ返す経路は片側だけを選びます。両側を返すと分岐ができてしまうからです。負の寄与は捨てられますが、全ノードが負の場合も最終解として扱う必要があります。

まず問題の構造を見極める

  • 左右の部分木上の同型の問題に分け、その結果を結合できるなら再帰的な分割統治を考えます。関数が扱う範囲と戻り値を決めてから、根を処理するタイミングを選びます。
  • 木の復元では、行きがけ順の先頭が根を示し、通りがけ順での根の位置が左右の境界を決めます。値の重複がないため、根の位置を一意に決定できます。
  • 任意の始点から下方向へ伸びる経路を数える場合は、始点の選択と、固定した始点からの探索を分けます。各経路を、その経路自身の始点で一度だけ数えられます。
  • 左右両方を通る経路では、現在のノードで両側の寄与を合わせて解を更新できます。ただし、親には延長可能な一本の枝だけを返します。

状態と不変条件を明確にする

再帰の戻り値を先に定義します。典型的には「現在のノードを端点とする片側の情報」か「現在の部分木全体の解」です。左右を組み合わせる経路では、最終解を別の変数に記録することがよくあります。

学習用の骨格

以下は三種類の再帰を示す疑似コードです。分割や構築を示す中国語の箇所は、ノード型や区間の表現に合わせて実装します。

构造二叉树 build(前序, 中序)：
    if 区间为空：return None
    用前序首元素建立根，在中序中定位根
    按中序左右长度，同步划分两种遍历的左右子树区间
    root.left = build(左前序, 左中序)
    root.right = build(右前序, 右中序)
    return root

统计向下路径：
    extend(node, remain)：          # 必须从 node 开始
        if node 为空：return 0
        return (node.val == remain) + extend(node.left, remain-node.val)
                                   + extend(node.right, remain-node.val)
    all_paths(node, target)：       # 枚举起点
        if node 为空：return 0
        return extend(node, target) + all_paths(node.left, target)
                                    + all_paths(node.right, target)

最大路径和（非空树）：
    ans = -∞
    gain(node)：                   # 返回以 node 为端点的最大单边贡献
        if node 为空：return 0
        left = max(0, gain(node.left))
        right = max(0, gain(node.right))
        ans = max(ans, node.val+left+right)
        return node.val + max(left, right)
    gain(root)，返回 ans

固定した始点からの経路が目標和に達しても、その先に0や負の数がある可能性があるため探索を続けます。ここでの二重の再帰は最悪 O(n²) です。改善するなら、DFSで根から現在のノードまでの累積和の個数を管理し、戻る際に個数を取り消します。

例1：行きがけ順と通りがけ順から二分木を復元する

問題：LeetCode 105

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        if len(inorder) == 0: return
        root = TreeNode(preorder[0])
        mid = inorder.index(preorder[0])

        # 构建子树
        root.left = self.buildTree(preorder[1:mid+1], inorder[:mid])
        root.right = self.buildTree(preorder[mid+1:], inorder[mid+1:])

        return root

実装のポイント： 行きがけ順の先頭は必ず根です。通りがけ順での根の位置から左右の部分木の長さを求め、行きがけ順も同じ長さに基づいて分割し、再帰的に構築します。

例2：Path Sum III

問題：LeetCode 437

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        # 对于单个递归不能够混合带/不带当前节点，因为会导致单个情况被遍历多次！
        def calc_ans(node, remain):
            if not node: return 0
            ans = 0
            if node.val == remain:
                ans += 1
            ans += calc_ans(node.left, remain-node.val)
            ans += calc_ans(node.right, remain-node.val)
            return ans
        
        if not root: return 0
        # 计算包含当前节点的结果
        ans = calc_ans(root, targetSum)

        # 计算不包含当前节点的结果
        ans += self.pathSum(root.left, targetSum)
        ans += self.pathSum(root.right, targetSum)
        return ans

実装のポイント： calc_ans は現在のノードを必ず始点とする経路を数えます。外側の pathSum が左右の子を新しい始点として扱い、すべての始点を網羅します。

例3：二分木の最大経路和（Hard）

問題：LeetCode 124

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        # 和求最大直径基本一样，唯独注意这里的最大值不一定是一整条路径，所以更新最大值的时候计算 max(l + r, l, r, 0) + root.val!
        self.ans = -1000000
        def depth(root):
            if not root: return 0
            l = depth(root.left)
            r = depth(root.right)
            root_val = root.val + max(l, 0) + max(r, 0)
            self.ans = max(self.ans, root_val)
            return max(l, r, 0) + root.val
        depth(root)
        return self.ans

二種類の経路を区別する

  • depth(root) の戻り値は親が延長するため、左右どちらか一方だけを使います：root.val + max(l, r, 0)。
  • 現在のノードを最高点とする完成した経路は両側を使えます：root.val + max(l, 0) + max(r, 0)。これは全体の解の更新にのみ使い、親には返しません。
  • 子の寄与が負なら 0 にして、その枝を使わないことを表します。全体の解は十分小さい値で初期化するため、全ノードが負でも最大値の単一ノードを選べます。
