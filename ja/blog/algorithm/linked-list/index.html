## 反転前に未処理の部分を保存する

W韋 君豪読了目安 8 分

反転前に未処理の部分を保存する

図の構造を見る（原文）
flowchart TD
 A["prev = 空，curr = 原链表头"] --> B{"curr 非空？"}
 B -->|否| Z["返回 prev：反转后的头"]
 B -->|是| C["先保存 nxt = curr.next"]
 C --> D["令 curr.next 指向 prev"]
 D --> E["prev 移到 curr，curr 移到 nxt"]
 E --> B

ポインタを変える前に元の後続ノードを保存することで、残りのリストを失わずに済みます。各反復の後、prev は処理済み部分、curr は未処理部分を指します。

まず問題の構造を見極める

目的 手法と根拠
ノードの反転・削除・並べ替え 未処理の後続を保存してから、局所的に next を変更する
閉路の判定・入口の探索 速度差によって閉路内で出会う。閉路がなければ速いポインタが先にnullへ達する
K個ずつの反転 完全な一組と残りに分け、K個あることを確認して反転し、再帰の結果をつなぐ
LRUのキー検索と順序変更を O(1) にする ハッシュ表でノードを見つけ、双方向リストで削除・挿入する。単方向では前のノードを直接特定できない

状態と不変条件を明確にする

  • ポインタの変化を図にし、切断前に後続を保存したか確認します。
  • 先頭を変える場合はダミーヘッド、閉路や中点には高速・低速ポインタを検討します。
  • 再帰では、受け取る範囲、返す端点、次の区間を接続する担当を明確にします。

学習用の骨格

以下は別々のパターンの疑似コードです。中国語の箇所は問題に応じて補い、すべてを同じポインタループにまとめないようにします。

迭代反转：
    pre = None，cur = head
    while cur 非空：
        next_node = cur.next       # 保存未处理部分
        cur.next = pre             # 接入已反转部分
        pre = cur，cur = next_node
    return pre

本篇递归反转 rev(cur, pre)：
    if cur 为空：return pre
    new_head = rev(cur.next, cur)
    cur.next = pre                 # 回溯时连向原前驱
    return new_head

环入口：
    slow = fast = head
    while fast 和 fast.next 非空：
        slow 前进一步，fast 前进两步
        若相遇：一个指针回到 head，两者同步前进一步直到相遇，返回该节点
    return None

K 个一组翻转：
    从 head 找满 K 个节点；不足则 return head
    保存 next_group，翻转本组，得到 new_head 和 new_tail
    new_tail.next = 递归处理(next_group, K)
    return new_head

LRU：
    初始化 key→节点 的字典及双向链表头尾哨兵
    get：未命中返回 -1；命中则移到最前并返回值
    put：已有键更新并移到最前；新键加入字典和链表最前
         若超容量，同时删除链表最后的实际节点及其字典条目

反転中の pre は処理済み部分、cur は未処理部分です。再帰版では戻りながら向きを変えます。LRUの不変条件は、辞書とリストが同じ実ノードを含み、先頭が最近使用、末尾が最も長く未使用であることです。

例1：連結リストの反転

問題：LeetCode 206

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # pre = None
        # cur = head
        # while cur:
        #     tmp = cur.next
        #     cur.next = pre
        #     pre = cur
        #     cur = tmp
        # return pre
        
        pre = None
        def rev(cur, pre):
            if not cur: return pre
            res = rev(cur.next, cur)
            cur.next = pre
            return res
        revd = rev(head, pre)
        return revd

実装のポイント： コメント部分が反復版で、実行されるのは再帰版です。rev(cur, pre) は cur からのリストを反転し、最終的に cur を pre に向けます。次のノードへ新しい前駆を渡し、戻る際に cur.next = pre を実行します。

例： 1 -> 2 -> 3 -> None に rev(1, None) を呼びます。

rev(1, None)
  -> rev(2, 1)
       -> rev(3, 2)
            -> rev(None, 3)，返回节点 3

戻る際に 3.next = 2、2.next = 1、1.next = None と設定し、新しい先頭 3 を返します。

例2：Linked List Cycle II

問題：LeetCode 142

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        s, l = head, head

        while True:
            if not l or not l.next: return None
            s = s.next
            l = l.next.next
            if s == l: break
        l = head
        while l != s:
            l, s = l.next, s.next
        return l

実装のポイント： 速いポインタは2歩、遅い方は1歩進みます。最初に出会ったら片方を先頭に戻し、両方を1歩ずつ進めます。次の合流点が閉路の入口です。

理由： 先頭から入口までを a、入口から最初の合流点までを b、閉路長を c とします。合流時に速い方は整数周だけ余分に進んでいます。ここから、a と合流点から入口への距離の差は閉路長の整数倍となり、同じ速度なら入口で出会うと分かります。

例3：K個ずつノードを反転する（Hard）

問題：LeetCode 25

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        def reverse(head, tail):
            pre = tail.next
            cur = head
            while pre != tail: # 关键循环，建议自己画链子 - 先保存旧 next，然后pre接上新next，然后往后 - 其实是链表很通用的过程
                suc = cur.next
                cur.next = pre
                pre = cur
                cur = suc
            return tail, head

        if not head or not head.next: return head
        tail = head
        for _ in range(k - 1): # 找到当前的tail以进入当前修改
            tail = tail.next
            if not tail: return head
        suc = tail.next # 记录下一组的开头
        new_head, _  = reverse(head, tail) # 反转这一组
        head.next = self.reverseKGroup(suc, k) # 递归处理剩余部分
        return new_head

グループ化と再帰の役割

reverseKGroup(head, k) は、head から始まるリスト全体を処理し、新しい先頭を返します。

  1. k - 1 歩進んで一組の tail を探します。K個なければそのまま返します。
  2. reverse(head, tail) は閉区間 [head, tail] だけを反転し、元の tail を新しい先頭、元の head を新しい末尾として返します。
  3. 元の境界を失う前に suc = tail.next で次の組の開始位置を保存します。
  4. 残りを再帰処理し、実装の端点の扱いに従って head.next = self.reverseKGroup(suc, k) でつなぎます。

例： 1 -> 2 -> 3 -> 4 -> 5、k = 2 の場合です。

  • [1, 2] を 2 -> 1 に反転し、1 が新しい末尾になります。
  • 残りの 3 -> 4 -> 5 を再帰で 4 -> 3 -> 5 にします。
  • 1.next に接続し、2 -> 1 -> 4 -> 3 -> 5 を得ます。

reverse で pre = tail.next とすると、元の先頭が一時的に次の区間へつながります。その後、再帰が返す新しい先頭で接続を置き換えます。

例4：LRUキャッシュ

問題：LeetCode 146

class Node:
    def __init__(self, key=0, value=0): # 按照使用顺序排序
        self.key = key
        self.value = value
        self.prev = None
        self.next = None


class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache = {} # O(1)查找

        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _add_front(self, node):
        node.next = self.head.next
        node.prev = self.head

        self.head.next.prev = node
        self.head.next = node

    def get(self, key: int) -> int:
        if key not in self.cache: return -1
        
        node = self.cache.get(key)

        # 刚访问放在一开始
        self._remove(node)
        self._add_front(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        # 1. 已经有只需要更新；
        if key in self.cache:
            node = self.cache.get(key)
            node.value = value

            # 更新位置到一开始
            self._remove(node)
            self._add_front(node)

        # 2.新加入则新建节点；期间如果超过长度则remove tail.prev
        else:
            node = Node(key, value)
            self.cache[key] = node
            self._add_front(node)

            if len(self.cache) > self.capacity:
                old = self.tail.prev
                self._remove(old)
                del self.cache[old.key]

# Your LRUCache object will be instantiated and called as such:
# obj = LRUCache(capacity)
# param_1 = obj.get(key)
# obj.put(key,value)

実装のポイント： ハッシュ表でノードを O(1) で探し、双方向リストで O(1) の削除・移動を行います。head 側ほど最近使われ、tail.prev が最も長く使われていません。get と既存キーの更新は、どちらもノードを先頭に移します。
