単調スタック：現在の要素で過去の候補を確定する

## 現在の要素が過去の候補の答えを決める

W韋 君豪読了目安 4 分

現在の要素が過去の候補の答えを決める

図の構造を見る（原文）
flowchart LR
 A["新的温度 T[i]"] --> B{"比栈顶温度高？"}
 B -->|是| C["弹出下标 j，答案为 i-j"]
 C --> B
 B -->|否或栈空| D["把 i 入栈"]
 D --> E["等待下一个元素"]

Daily Temperaturesのスタックには、まだ暖かい日が見つかっていない添字を保存します。各添字は高々一度ずつ追加・削除されるため、全体の処理量は線形です。

まず問題の構造を見極める

  • 各位置の左右で最初に大きい・小さい要素を探す場合や、その境界から幅や面積を計算する場合に単調スタックを考えます。
  • 削除前に、現在の要素で先頭候補の答えが確定したか、保持する必要がなくなったかを確認します。高い気温は次に大きい値を確定し、低い棒は長方形の右方向への拡張を止めます。
  • 通常は未確定の添字を保存します。添字は順序を保ち、対応する値が必要な方向に単調になります。各添字の追加・削除は一度ずつで、時間は O(n) です。
  • 比較演算子は「厳密に大きい・小さい」かどうかで決めます。同値を削除するかは境界の定義と合わせます。気温と雨水の例は同値を残した非増加、長方形の例は同値を残した非減少です。

基本の考え方

値が増加または減少する列を保ちます。新しい要素が単調性を崩したら、条件を満たすまで取り出し、その時点で答えを計算します。

以下の学習用疑似コードでは、判定条件と計算手順を中国語のプレースホルダーで残しています。

"""
单调栈通用模版：
1. 栈中通常保存下标，方便同时获得元素值、距离和区间宽度
2. 遍历每个元素
3. 当前元素破坏单调性时，不断弹栈并结算答案
4. 当前下标入栈
5. 必要时用哨兵处理栈内剩余元素
"""

stack = []
for i, value in enumerate(nums):
    while stack and 当前元素破坏单调性:
        j = stack.pop()
        根据 i、j 和新的栈顶计算答案
    stack.append(i)

例1：Daily Temperatures

問題：LeetCode 739

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        ans = [0] * len(temperatures)
        stack = []  # 尚未找到更高温度的下标；对应温度单调递减

        for i, temperature in enumerate(temperatures):
            while stack and temperature > temperatures[stack[-1]]:
                j = stack.pop()
                ans[j] = i - j
            stack.append(i)

        return ans

考え方： スタックは答えが未確定の日を保持します。現在の気温が高ければ、取り出された日 j にとって初めて暖かい日であり、待ち時間は i - j です。

例2：Trapping Rain Water

問題：LeetCode 42

class Solution:
    def trap(self, height: List[int]) -> int:
        ans = 0
        stack = []  # 下标对应的高度单调递减

        for i, current_height in enumerate(height):
            while stack and current_height > height[stack[-1]]:
                bottom = stack.pop()
                if not stack:
                    break

                left = stack[-1]
                width = i - left - 1
                bounded_height = min(height[left], current_height) - height[bottom]
                ans += width * bounded_height

            stack.append(i)

        return ans

考え方： 取り出す棒がくぼみの底です。新しい先頭と現在の棒が左右の壁となり、この層の水量は 幅 × 有効な高さ です。

例3：行列中の最大長方形

問題：LeetCode 85

class Solution:
    def maximalRectangle(self, matrix: List[List[str]]) -> int:
        if not matrix:
            return 0

        heights = [0] * len(matrix[0])
        ans = 0

        for row in matrix:
            for i, value in enumerate(row):
                heights[i] = heights[i] + 1 if value == '1' else 0
            ans = max(ans, self.largestRectangleArea(heights))

        return ans

    def largestRectangleArea(self, heights: List[int]) -> int:
        heights = [0] + heights + [0]  # 两侧哨兵
        stack = []  # 下标对应的高度单调递增
        ans = 0

        for i, current_height in enumerate(heights):
            while stack and current_height < heights[stack[-1]]:
                height = heights[stack.pop()]
                width = i - stack[-1] - 1
                ans = max(ans, height * width)
            stack.append(i)

        return ans

考え方： 各行をヒストグラムの底辺とし、heights[i] にその列で連続する 1 の高さを記録します。低い棒に出会うと、取り出した高さは右へ伸ばせません。新しい先頭と現在の添字が左右の境界です。

三問の共通点

  • 気温： 取り出す際に、右側で最初に大きい要素が確定します。
  • 雨水： 左右の境界を使い、くぼみの一層を計算します。
  • 長方形： 各行をヒストグラムに変え、取り出す際にその高さの最大幅を決めます。
