## 右端を固定し、過去の累積値を探す

W韋 君豪読了目安 4 分

右端を固定し、過去の累積値を探す

図の構造を見る（原文）
flowchart TD
 I["初始化：历史计数 count[0] = 1"] --> Q{"还有元素？"}
 Q -->|否| Z["返回答案"]
 Q -->|是| A["读入下一个元素，更新前缀和 S"]
 A --> B["查询历史 S-k 的出现次数"]
 B --> C["把次数累加到答案"]
 C --> D["最后再记录当前 S"]
 D --> Q

区間和は二つの累積和の差です。現在の累積和を記録する前に照会すれば、自分自身との組を除外できます。初期値として累積和 0 を一回数えるのは、配列先頭から始まる区間のためです。

問題の構造と状態設計

連続区間の和を繰り返し求める場合や、和の条件を満たす部分配列を数える場合に累積和を考えます。P[i] を先頭 i 要素の和、P[0] = 0 とすると、半開区間 [l, r) の和は P[r] - P[l] です。負の値があっても成り立ちます。

目的 根拠 保存する過去の状態
和がKの部分配列数 P[r] - P[l] = K より、過去の P[r] - K を探す 各累積和の出現回数
最大部分配列和 右端を固定し、最小の過去の累積和を引く 最小累積和
自分以外の全要素の積 i を除くと左右二つの区間に分かれる 自身を含まない接頭・接尾の積

最初の二つでは、過去の値から解を計算してから現在の値を追加し、空区間を除きます。三つ目は累積積であり、累積和の引き算は使いません。除算も不要なので0を扱えます。

学習用の骨格

中国語の説明と数学的な区間表記は問題に合わせて実装します。最大部分配列和は空でない入力を前提とします。

统计和为 K 的非空子数组：
    prefix = 0，count = {0: 1}，ans = 0
    for x in nums：
        prefix += x
        ans += count.get(prefix-K, 0)
        count[prefix] = count.get(prefix, 0) + 1

求非空子数组最大和：
    prefix = 0，min_prefix = 0，ans = -∞
    for x in nums：
        prefix += x
        ans = max(ans, prefix-min_prefix)
        min_prefix = min(min_prefix, prefix)

排除自身的乘积：
    n = len(nums)，left 和 right 均初始化为 n 个 1
    从左往右：left[i] = left[i-1] * nums[i-1]（i 从 1 开始）
    从右往左：right[i] = right[i+1] * nums[i+1]（i 从 n-2 开始）
    ans[i] = left[i] * right[i]

例1：和がKの部分配列

問題：LeetCode 560

class Solution:
    def subarraySum(self, nums, k):
        # 从左到右扫描，维护当前前缀和 prefix，同时用 count 记录“之前每个前缀和出现过几次”。
        ans = 0
        prefix = 0
        count = {0: 1}

        for num in nums:
            prefix += num

            if prefix - k in count:
                ans += count[prefix - k]

            count[prefix] = count.get(prefix, 0) + 1

        return ans

実装のポイント： 現在の累積和が prefix なら、過去の prefix - k の各出現が和 k の部分配列を作ります。{0: 1} で先頭から始まる区間も数えられます。

例2：最大部分配列和

問題：LeetCode 53

class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        max_s = -10000
        min_prefix = 0
        sum_s = 0

        for num in nums:
            sum_s += num # 统计所有
            max_s = max(max_s, sum_s - min_prefix, sum_s)
            min_prefix  = min(min_prefix, sum_s)

        return max_s

実装のポイント： 現在位置で終わる最大和は、現在の累積和から過去の最小累積和を引いた値です。min_prefix は答えの計算後に更新し、現在の累積和自身を始点として使わないようにします。

例3：自分以外の要素の積

問題：LeetCode 238

class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        prefix, suffix = [1] * len(nums), [1] * len(nums)
        res = [0] * len(nums)
        # prefix[0], suffix[-1] = nums[0], nums[-1]
        for i in range(1, len(nums)):
            prefix[i] = nums[i - 1] * prefix[i - 1]
        for j in range(len(nums) - 2, -1, -1):
            suffix[j] = nums[j + 1] * suffix[j + 1]

        for k in range(len(nums)):
            res[k] = prefix[k] * suffix[k]
        return res

実装のポイント： prefix[i] は i より左の積、suffix[i] は右の積です。両者を掛ければ自然に nums[i] だけを除外できます。
