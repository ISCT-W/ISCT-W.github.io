LoRA：低ランク更新、量子化基盤、適応的な予算配分

パラメーター効率のよい微調整は、適応を小さな学習空間に制限し、勾配、最適化器の状態、タスク別重みの保存量を減らします。

W韋 君豪読了目安 8 分

パラメーター効率のよい微調整は、適応を小さな学習空間に制限し、勾配、最適化器の状態、タスク別重みの保存量を減らします。LoRA は低ランク更新、QLoRA は基盤の量子化、AdaLoRA はランク予算の配分に注目します。節約する資源は異なるため、活性値メモリ、対象モジュール、タスク性能も含めて判断します。

基盤と低ランク分岐の両方が出力に寄与しますが、更新するのはアダプターだけです。重みの固定は基盤を通る計算や活性値メモリの消滅を意味しません。

更新を低ランク行列に制限する

LoRA は基盤重み WWW を固定し、更新を次のように表します。

W′=W+ΔW,ΔW=αrBAW'=W+\Delta W, \qquad \Delta W=\frac{\alpha}{r}BAW′=W+ΔW,ΔW=rα​BA

A∈Rr×dinA\in\mathbb R^{r\times d_{in}}A∈Rr×din​、B∈Rdout×rB\in\mathbb R^{d_{out}\times r}B∈Rdout​×r、r≪din,doutr\ll d_{in},d_{out}r≪din​,dout​ です。A/B だけを学習することで、勾配、最適化器状態、学習重みの保存量を減らします。

増分ゼロから始める初期化

元の LoRA は AAA をガウス乱数、B=0B=0B=0 で初期化します。

ΔW0=αrB0A0=0,h0=(W+ΔW0)x=Wx.\Delta W_0=\frac{\alpha}{r}B_0A_0=0, \qquad h_0=(W+\Delta W_0)x=Wx.ΔW0​=rα​B0​A0​=0,h0​=(W+ΔW0​)x=Wx.

挿入直後は元モデルの出力を保ちつつ、ランダムな A0A_0A0​ が BBB の学習に必要な非ゼロ方向を提供します。

上流勾配を g=∂L/∂hg=\partial\mathcal L/\partial hg=∂L/∂h とし、バッチ次元を省くと次式です。

∂L∂B=αrg(Ax)⊤,∂L∂A=αrB⊤gx⊤.\frac{\partial\mathcal L}{\partial B} =\frac{\alpha}{r}g(Ax)^\top, \qquad \frac{\partial\mathcal L}{\partial A} =\frac{\alpha}{r}B^\top gx^\top.∂B∂L​=rα​g(Ax)⊤,∂A∂L​=rα​B⊤gx⊤.

最初は通常 BBB に非ゼロ勾配が入り、AAA の勾配はゼロです。BBB が動いた後は両方を学習できます。両因子をゼロにすると、双方の勾配がゼロになり、学習を開始できません。

一方をランダム、他方をゼロにすれば初期関数を保ちつつ学習できます。両方ゼロでは関数は保てても更新が止まります。

実装では Kaiming や一様分布を使う場合もあります。重要なのは特定の乱数分布ではなく、初期 BA=0BA=0BA=0 と学習可能な勾配経路の両立です。

対象モジュールが変更できる挙動を決める

LoRA は線形重みに追加でき、代表的な対象は次のとおりです。

対象 役割の直感 用途
q_proj、v_proj Q は注目先、V は取り出す内容を変える 小予算、元の LoRA に近い構成
q_proj、k_proj、v_proj、o_proj 対応付け、内容、出力混合を調整 Attention 全体の適応
MLP の gate_proj、up_proj、down_proj token ごとの非線形特徴変換 領域・能力適応、全重み微調整に近い容量
Embedding、lm_head 入力語表現、出力語分布 token 追加や語彙・出力層の変更が必要な場合

予算が小さければ Q/V または全 Attention 射影から試します。品質重視では Attention と MLP の線形層を含む all-linear もよく使われます。範囲を広げるほど学習状態とファイルが増えるため、タスクで検証します。

理由を「Attention のほうが知識を多く保存する」と説明するのは適切ではありません。Attention は文脈に応じて情報を選択・混合し、FFN は token ごとの非線形変換を担い、Key-Value Memory とする解釈もあります。知識は分散しており、Attention-only がよく使われるのは少ないパラメーターで相互作用を変えられるためです。大きな領域変化には MLP の追加が容量を増やします。

小予算は Attention、強い適応には all-linear、語彙変更が必要なら Embedding や lm_head も検討します。

QLoRA：量子化基盤と高精度アダプター

QLoRA は固定基盤を 4-bit で保存し、A/B は通常 BF16 や FP16 で学習します。

h=Dequant⁡(W4bit)x+αrBAx.h=\operatorname{Dequant}(W_{4\mathrm{bit}})x +\frac{\alpha}{r}BAx.h=Dequant(W4bit​)x+rα​BAx.

計算時は量子化ブロックを計算 dtype に逆量子化して行列積に使います。勾配は LoRA へ流れますが、固定した 4-bit 基盤は更新しません。全モデルを 4-bit 勾配で学ぶ方法でも、必ずアダプター自体を 4-bit にする方法でもありません。

元の QLoRA の三要素は次のとおりです。

  • NF4：ほぼ正規分布の事前学習重みに適した 4-bit 型で、単純な一様 INT4 より適することが多い方式。
  • Double Quantization：量子化スケールなどの定数も量子化し、付随情報のメモリを削減。
  • Paged Optimizer：ページングや統合メモリで一時的なメモリ急増を緩和し、長系列学習の OOM リスクを低減。
比較項目 LoRA QLoRA
基盤の一般的保存精度 FP16/BF16 4-bit、主に NF4
学習対象 A/B A/B
主な削減 勾配と最適化器状態 加えて基盤重みを圧縮
残るコスト 活性値と順・逆伝播 活性値、順・逆伝播、逆量子化

all-linear は対象層の方針であり、QLoRA の定義ではありません。配置時は量子化基盤とアダプターを保持するか、逆量子化してマージ後に再量子化できます。後者は追加誤差を生む可能性があります。

LoRA は学習状態を減らし、QLoRA は大きな固定基盤も 16-bit から 4-bit へ圧縮します。ただし活性値メモリは残ります。

AdaLoRA：全体予算の中で方向を配分する

通常の LoRA は各対象行列へ同じランク rrr を与えます。AdaLoRA は全体予算の下で重要な行列に多くの方向を残し、重要度の低い行列を剪定します。

更新は SVD に似た形式です。

ΔW=PΛQ⊤,Λ=diag⁡(λ1,…,λr).\Delta W=P\Lambda Q^\top, \qquad \Lambda=\operatorname{diag}(\lambda_1,\ldots,\lambda_r).ΔW=PΛQ⊤,Λ=diag(λ1​,…,λr​).

(pi,λi,qi)(p_i,\lambda_i,q_i)(pi​,λi​,qi​) がランク一つ分を構成します。大きな init_r で探索し、パラメーターと勾配から重要度を推定して低重要度の λi\lambda_iλi​ を定期的にマスク・剪定し、target_r に対応する総予算へ縮めます。最後は配分を固定して学習を続けます。直交正則化は方向の重複を減らし、分解を安定させます。

手法 主に解決する問題
LoRA 固定の低ランクで更新を表現
QLoRA 固定基盤を 4-bit に圧縮
AdaLoRA 行列間でランクを適応配分

小予算で一律ランクの無駄を減らせる一方、重要度追跡、剪定日程、正則化が必要です。init_r、target_r、warmup、剪定間隔、総ステップ数にも敏感です。QLoRA との併用は概念上可能ですが、実装が量子化、剪定、保存を正しく扱えるか確認します。

LoRA は通常同じランクを配り、AdaLoRA は多めに始めて学習中の重要度に応じて容量を配分します。

学習と配置で得られる利点

  • 特に Adam の一次・二次モーメントのメモリを削減。
  • 小さなアダプターで複数タスクを保存・切り替え。
  • ΔW を基盤へマージすれば推論の追加分岐を除去可能。
  • 分離したままならテナントやタスクを動的に切り替え可能。

パラメーター、活性値、挙動の限界

  • 固定した基盤にも順伝播と逆伝播の計算が必要です。
  • 学習パラメーターが少なくても活性値メモリは残ります。
  • 低すぎるランクは容量不足、高すぎるランクは効果が逓減し得ます。
  • 対象層、α、dropout、初期化、データ量が性能に影響します。
  • 複数アダプターの同時提供には重み配置、バッチ化、キャッシュが必要です。
  • 更新空間を制限しても、過学習や忘却は自動的には防げません。
