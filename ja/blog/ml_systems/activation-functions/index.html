活性化関数：関数の形から勾配と表現を理解する

活性化関数は線形変換の組み合わせに非線形性を与え、各層を通る勾配の尺度も変えます。

W韋 君豪読了目安 9 分

活性化関数は線形変換の組み合わせに非線形性を与え、各層を通る勾配の尺度も変えます。関数値と導関数を比べると、飽和、負側の切り捨て、滑らかなゲートの違いが見えます。置き換える際は初期化、残差経路、事前学習済み特徴の分布も考える必要があります。

図の構造を見る（原文）
flowchart LR
    X["线性输入 z"] --> F["激活函数 f"]
    F --> H["下一层表示 h"]
    H --> L["任务损失"]
    L -.-> G["上游梯度"]
    G -.-> D["乘以局部导数 f′(z)"]
    D -.-> X
    F --> C["检查饱和、负值与门控行为"]

順伝播は表現を変換し、逆伝播では局所導関数を掛けます。滑らかさや負側の非ゼロ勾配だけで、深いネットワークの安定性は保証できません。

隠れ層、出力変換、学習目標を分ける

図の構造を見る（原文）
flowchart LR
    X["线性变换 z=Wx+b"] --> A["隐藏层激活函数"]
    A --> H["中间表示 h"]
    H --> O["输出头产生 logits / prediction"]
    O --> L["损失函数与标签比较"]
    L --> G["反向传播梯度"]
  • 活性化関数は非線形性と局所的な勾配の形を決めます。
  • 出力変換は logits を確率や正数などへ写します。Sigmoid、Softmax、Softplus が例です。
  • 損失関数は予測と教師信号の差を測り、最適化目標を定めます。

同じ関数でも役割は異なります。Sigmoid は隠れ層にも二値確率出力にも使えますが、二値学習では明示的な Sigmoid の後に BCE を計算するより BCEWithLogitsLoss が数値的に安定です。

関数値と導関数

図では Sigmoid/Tanh の両端の飽和、ReLU の負側のゼロ勾配、GELU/SiLU が負側にも一部の勾配を残す様子を比較できます。

Sigmoid

σ(x)=11+e−x,σ′(x)=σ(x)(1−σ(x)).\sigma(x)=\frac{1}{1+e^{-x}}, \qquad \sigma'(x)=\sigma(x)\left(1-\sigma(x)\right).σ(x)=1+e−x1​,σ′(x)=σ(x)(1−σ(x)).

0<σ′(x)≤1/40<\sigma'(x)\leq1/40<σ′(x)≤1/4 で、大きな ∣x∣|x|∣x∣ ではゼロへ近づきます。深い層で掛け合わせると勾配が消失しやすくなります。

用途

  • 二値・マルチラベル分類の確率出力。
  • LSTM、GRU、GLU のゲート。
  • 値を (0,1)(0,1)(0,1) に制限する箇所。

注意点

  • 正負両端で勾配が小さくなります。
  • 出力がゼロ中心ではなく、隠れ層の最適化を妨げる場合があります。
  • 指数や log(sigmoid(x)) の直接計算は桁あふれ・桁落ちの原因になります。
  • 二値学習には logits ベースの安定な損失を使います。

Tanh

tanh⁡(x)=ex−e−xex+e−x,ddxtanh⁡(x)=1−tanh⁡2(x).\tanh(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}, \qquad \frac{d}{dx}\tanh(x)=1-\tanh^2(x).tanh(x)=ex+e−xex−e−x​,dxd​tanh(x)=1−tanh2(x).

出力はゼロ中心の (−1,1)(-1,1)(−1,1) ですが、正負の大入力では飽和します。循環状態や符号付きの有界出力に向きますが、ゼロ中心でも勾配消失は残ります。

ReLU

ReLU⁡(x)=max⁡(0,x),ReLU⁡′(x)={0,x<0,1,x>0.\operatorname{ReLU}(x)=\max(0,x), \qquad \operatorname{ReLU}'(x)= \begin{cases} 0,&x<0,\\ 1,&x>0. \end{cases}ReLU(x)=max(0,x),ReLU′(x)={0,1,​x<0,x>0.​

ゼロでは微分できませんが、実装で定めた劣勾配を使うことは通常、主要な問題にはなりません。

利点

  • 正側は飽和せず、勾配は 1。
  • 計算が単純。
  • 負側がゼロとなり疎な活性を作る。
  • He/Kaiming 初期化と合わせた CNN/MLP の基本構成。

Dying ReLU

あるニューロンが全入力で負側に入り続けると、勾配がゼロのままで更新できなくなる場合があります。大きすぎる学習率、強い負バイアス、不適切な初期化、入力分布の変化が原因になり得ます。

学習率と初期化の確認、Leaky ReLU/PReLU/ELU/GELU/SiLU の検討、適切な正規化と残差経路、各層のゼロ活性率の監視が対策です。総損失だけでは状態を把握できません。

正側は無界なので活性値や勾配が大きくなる可能性は残ります。正側の非飽和は勾配爆発の防止を意味しません。

Leaky ReLU と PReLU

f(x)={x,x≥0,αx,x<0.f(x)= \begin{cases} x,&x\geq 0,\\ \alpha x,&x<0. \end{cases}f(x)={x,αx,​x≥0,x<0.​

Leaky ReLU は小さな固定 α>0\alpha>0α>0 を使い、PReLU はそれを学習します。負側の勾配で死んだユニットを減らせますが、PReLU には追加パラメーターと必要に応じた制約・正則化が伴います。学習率、初期化、数値あふれを自動的に解決するものではありません。

ELU、SELU、Softplus

ELU は次式です。

ELU⁡(x)={x,x>0,α(ex−1),x≤0.\operatorname{ELU}(x)= \begin{cases} x,&x>0,\\ \alpha(e^x-1),&x\leq 0. \end{cases}ELU(x)={x,α(ex−1),​x>0,x≤0.​

負側は −α-\alpha−α へ飽和し、負の出力を許し、通常 ReLU より滑らかです。ただし指数計算が必要で、負の飽和域では勾配が小さくなります。

SELU の自己正規化には適切な初期化、構造、AlphaDropout などの条件があります。通常の ReLU ネットワークへ単に置き換えても、安定するとは限りません。

Softplus は ReLU の滑らかな近似です。

Softplus⁡(x)=log⁡(1+ex),Softplus⁡′(x)=σ(x).\operatorname{Softplus}(x)=\log(1+e^x), \qquad \operatorname{Softplus}'(x)=\sigma(x).Softplus(x)=log(1+ex),Softplus′(x)=σ(x).

全域で微分可能かつ正なので、標準偏差や率の表現に向きます。厳密なゼロは作らず、負側の勾配は小さくなり得ます。大入力を直接指数化せず、安定な softplus 実装を使います。

GELU と SiLU/Swish

GELU は次式です。

GELU⁡(x)=xΦ(x),\operatorname{GELU}(x)=x\Phi(x),GELU(x)=xΦ(x),

Φ(x)\Phi(x)Φ(x) は標準正規分布の累積分布関数です。よく使う近似は次のとおりです。

GELU⁡(x)≈x2[1+tanh⁡(2π(x+0.044715x3))].\operatorname{GELU}(x)\approx \frac{x}{2} \left[ 1+\tanh\left( \sqrt{\frac{2}{\pi}} \left(x+0.044715x^3\right) \right) \right].GELU(x)≈2x​[1+tanh(π2​​(x+0.044715x3))].

SiLU は、一般的なパラメーター 1 の Swish とも呼ばれます。

SiLU⁡(x)=xσ(x),\operatorname{SiLU}(x)=x\sigma(x),SiLU(x)=xσ(x), SiLU⁡′(x)=σ(x)+xσ(x)(1−σ(x)).\operatorname{SiLU}'(x) =\sigma(x)+x\sigma(x)(1-\sigma(x)).SiLU′(x)=σ(x)+xσ(x)(1−σ(x)).

両方とも滑らかで一部の負値を通し、全域で単調ではありません。ReLU と違って負の半軸全体の勾配がゼロにはなりません。GELU は Transformer、SiLU は LLM、視覚、拡散モデルでよく使われます。絶対的な優劣ではなく、事前学習構造と検証結果に従って選びます。

GLU と SwiGLU

一般的なゲート付き線形ユニットは次式です。

GLU⁡(x)=(xWv+bv)⊙g(xWg+bg),\operatorname{GLU}(x) =(xW_v+b_v)\odot g(xW_g+b_g),GLU(x)=(xWv​+bv​)⊙g(xWg​+bg​),

ggg に Sigmoid、GELU、SiLU などを使います。SwiGLU は SiLU ゲートです。

SwiGLU⁡(x)=SiLU⁡(xWg)⊙(xWv).\operatorname{SwiGLU}(x) =\operatorname{SiLU}(xW_g)\odot(xW_v).SwiGLU(x)=SiLU(xWg​)⊙(xWv​).

投影分岐が増えて表現力が上がる一方、パラメーター数、計算量、中間活性値を FFN 幅と合わせて比較する必要があります。

勾配伝播における三つの制約

Sigmoid の導関数は最大 1/41/41/4 で両端ではほぼゼロとなり、積を重ねると前段の勾配が弱まります。それでもゲートでは (0,1)(0,1)(0,1) の値が必要で、残差や状態経路が情報伝達を助けます。

ReLU の勾配は正側で 1、負側で 0 です。負側にとどまるユニットは死ぬ場合があります。解消するのは正の飽和であり、全勾配問題ではありません。

GELU と SiLU は負入力を滑らかに抑えながら一部の値と勾配を残します。経験的な性能は構造全体と学習設定によるもので、活性化だけには帰属できません。

初期化と活性化を合わせる

  • ReLU 系には通常 He/Kaiming 初期化を使います。
  • Tanh/Sigmoid には Xavier/Glorot を検討しますが、深い層の飽和は残ります。
  • Transformer では残差分岐、Norm の位置、深さに応じたスケール、warmup も考慮します。
  • 活性化の変更は分散と事前学習済み分布を変えるため、一設定の変更を等価とみなせません。
