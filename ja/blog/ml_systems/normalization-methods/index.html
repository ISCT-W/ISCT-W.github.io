正規化：統計を取る軸、残差内の位置、配置時の挙動

正規化の名前が似ていても、統計を取る軸は異なります。

W韋 君豪読了目安 11 分

正規化の名前が似ていても、統計を取る軸は異なります。どの要素が統計を共有し、推論では現在入力と移動平均のどちらを使うかを先に確認します。残差サブ層の前後どちらへ置くかは、方式とは独立した問題です。

図の構造を見る（原文）
flowchart TD
    X["输入张量与任务"] --> A["确定参与统计的元素集合"]
    A --> S["计算均值、方差或均方根"]
    S --> N["按方法中心化或仅缩放"]
    N --> F["可学习缩放与平移"]
    X --> P["确定残差子层中的放置位置"]
    F --> V["核对训练与推理行为"]
    P --> V
    V --> C["检查 micro-batch、并行、精度与部署"]

統計集合は取り除く尺度差を、残差内の位置は勾配経路を決めます。略称だけでなく Tensor 形状と実行条件に対応させます。

共通式と統計集合

mmm 個の値の集合 SSS に対する中心化と分散正規化は次式です。

μS=1m∑j∈Sxj,σS2=1m∑j∈S(xj−μS)2,\mu_S=\frac{1}{m}\sum_{j\in S}x_j, \qquad \sigma_S^2=\frac{1}{m}\sum_{j\in S}(x_j-\mu_S)^2,μS​=m1​j∈S∑​xj​,σS2​=m1​j∈S∑​(xj​−μS​)2, x^i=xi−μSσS2+ε,yi=γix^i+βi.\hat{x}_i=\frac{x_i-\mu_S}{\sqrt{\sigma_S^2+\varepsilon}}, \qquad y_i=\gamma_i\hat{x}_i+\beta_i.x^i​=σS2​+ε​xi​−μS​​,yi​=γi​x^i​+βi​.

ε\varepsilonε は極小分散への対処、γ,β\gamma,\betaγ,β は学習する尺度と移動です。違いの中心は集合 SSS と推論時の統計源です。

Norm、Normalization、Standardization

BN/LN の Norm はベクトルのノルムではなく正規化を指します。統計学では区間への変換とゼロ平均・単位分散への標準化を区別することがありますが、深層学習の名前は定着しています。式と軸を示すのが確実です。

Internal Covariate Shift の緩和は歴史的説明です。より慎重には、活性値の尺度と最適化条件を整え、初期化や学習率への敏感さを減らす、と説明できます。勾配消失・爆発の完全防止ではありません。

軸の概観

CNN の X∈RN×C×H×WX\in\mathbb R^{N\times C\times H\times W}X∈RN×C×H×W と Transformer の X∈RB×T×DX\in\mathbb R^{B\times T\times D}X∈RB×T×D を考えます。

図の構造を見る（原文）
flowchart TD
    A["需要归一化的激活"] --> B{"统计量是否跨样本？"}
    B -->|"是：同一通道跨 N,H,W"| BN["BatchNorm"]
    B -->|"否：每个样本独立"| C{"样本内沿哪些维度？"}
    C -->|"指定的全部特征；Transformer 常为 D"| LN["LayerNorm"]
    C -->|"与 LN 同轴，但不减均值"| RMS["RMSNorm"]
    C -->|"每个通道自己的 H,W"| IN["InstanceNorm"]
    C -->|"一组通道及其 H,W"| GN["GroupNorm"]

BN は他のサンプルに依存し、LN、RMSNorm、IN、GN は各サンプルで計算できます。

比較可能な要素で統計を共有する

BN は生徒間の同じ科目、LN は一人の生徒の各科目の全体尺度を比べるイメージです。前者は共通母集団、後者は一つの表現内の調整を想定します。

軸の選択は消してよい平均・尺度差の選択です。絶対強度が重要なら検証が必要で、学習する affine 項でも各サンプルの失った統計を復元できません。隠れ次元が実際に科目に対応するわけではなく、Transformer LN は通常 (b,t)(b,t)(b,t) ごとに DDD 軸で計算します。

BatchNorm：サンプル間のチャネル統計

式と軸

CNN ではチャネルごとに次を計算します。

μc=1NHW∑n,h,wxnchw,\mu_c=\frac{1}{NHW}\sum_{n,h,w}x_{nchw},μc​=NHW1​n,h,w∑​xnchw​, σc2=1NHW∑n,h,w(xnchw−μc)2,\sigma_c^2=\frac{1}{NHW}\sum_{n,h,w}(x_{nchw}-\mu_c)^2,σc2​=NHW1​n,h,w∑​(xnchw​−μc​)2, ynchw=γcxnchw−μcσc2+ε+βc.y_{nchw}=\gamma_c \frac{x_{nchw}-\mu_c}{\sqrt{\sigma_c^2+\varepsilon}} +\beta_c.ynchw​=γc​σc2​+ε​xnchw​−μc​​+βc​.

全結合では Batch 軸、CNN では Batch と空間軸をまとめます。

学習と推論の違い

学習は現在の mini-batch 統計を使い、移動平均を更新します。推論は通常その running statistics を使うため、eval() の忘れで挙動が変わります。勾配蓄積は更新単位を増やしても、BN が見る micro-batch は増やしません。

利点

十分大きくほぼ独立な Batch ではチャネル尺度を安定させ、CNN で有効で、確率的な正則化効果もあります。推論統計は固定なので前段へ折り込めます。

z=Wx+b,y=γz−μσ2+ε+β,z=Wx+b, \qquad y=\gamma\frac{z-\mu}{\sqrt{\sigma^2+\varepsilon}}+\beta,z=Wx+b,y=γσ2+ε​z−μ​+β,

折り込み後は次式です。

W′=γσ2+εW,b′=γ(b−μ)σ2+ε+β.W'=\frac{\gamma}{\sqrt{\sigma^2+\varepsilon}}W, \qquad b'=\frac{\gamma(b-\mu)}{\sqrt{\sigma^2+\varepsilon}}+\beta.W′=σ2+ε​γ​W,b′=σ2+ε​γ(b−μ)​+β.

よくある問題

小 Batch の推定ノイズ、デバイスごとの統計差、領域変化、Padding 混入、隣接動画フレームなど相関サンプルによる偏りがあります。SyncBN は統計を同期しますが通信が増えます。

標本ノイズと小 Batch

同じサンプルでも Batch の相手で結果が変わり、ノイズを加える効果がありますが、Dropout の完全代替ではありません。高解像度処理の小さな per-device Batch では現在統計と移動統計の双方が不安定になり得ます。

LayerNorm：表現ごとに独立に調整する

式と軸

Transformer では token ごとの特徴次元を正規化します。

μbt=1D∑d=1Dxbtd,\mu_{bt}=\frac{1}{D}\sum_{d=1}^{D}x_{btd},μbt​=D1​d=1∑D​xbtd​, σbt2=1D∑d=1D(xbtd−μbt)2,\sigma_{bt}^2=\frac{1}{D}\sum_{d=1}^{D}(x_{btd}-\mu_{bt})^2,σbt2​=D1​d=1∑D​(xbtd​−μbt​)2, ybtd=γdxbtd−μbtσbt2+ε+βd.y_{btd}=\gamma_d \frac{x_{btd}-\mu_{bt}}{\sqrt{\sigma_{bt}^2+\varepsilon}} +\beta_d.ybtd​=γd​σbt2​+ε​xbtd​−μbt​​+βd​.

Transformer に合う理由

サンプルや時刻を混ぜる BN は構成、長さ、Padding、位置分布に影響されます。LN は現在 token 内で完結し、学習・推論で同じ計算を使います。可変長、小 Batch、勾配蓄積、逐次 Decode に対応し、移動統計やサンプル間同期が不要です。

注意点

normalized_shape が末尾の対象軸を決め、「常に Channel」ではありません。平均と分散を変え、計算・メモリ負荷もあります。混合精度では FP32 で統計を累積する実装が一般的です。

自己回帰実行での統計整合

LN は学習母集団の統計を必要としません。系列で BN が数学的に不可能なのではなく、長さ、Padding、小 Batch、学習と推論の差で複雑になるため、token 単位の LN/RMSNorm が条件に合います。

RMSNorm：中心化せず RMS で調整する

LN と似た特徴軸で次を計算します。

RMS⁡(x)=1D∑d=1Dxd2+ε,\operatorname{RMS}(x)= \sqrt{\frac{1}{D}\sum_{d=1}^{D}x_d^2+\varepsilon},RMS(x)=D1​d=1∑D​xd2​+ε​, yd=γdxdRMS⁡(x).y_d=\gamma_d\frac{x_d}{\operatorname{RMS}(x)}.yd​=γd​RMS(x)xd​​.

bias の有無は実装によります。

LayerNorm との違い

項目 LayerNorm RMSNorm
平均を引く はい いいえ
尺度調整 はい はい
一般的な学習項 γ,β\gamma,\betaγ,β γ\gammaγ
Batch 依存 なし なし
学習・推論の計算 同じ 同じ
用途 Transformer、系列 一部 LLaMA 系などの LLM

中心化を省いて計算を簡単にしますが、全体速度は Kernel、融合、メモリ転送、ハードウェアに依存します。

InstanceNorm と GroupNorm：サンプル内の空間統計

Instance Normalization

各サンプル・チャネルの H,WH,WH,W だけで計算します。

μnc=1HW∑h,wxnchw,σnc2=1HW∑h,w(xnchw−μnc)2.\mu_{nc}=\frac{1}{HW}\sum_{h,w}x_{nchw}, \qquad \sigma_{nc}^2=\frac{1}{HW}\sum_{h,w}(x_{nchw}-\mu_{nc})^2.μnc​=HW1​h,w∑​xnchw​,σnc2​=HW1​h,w∑​(xnchw​−μnc​)2.

画像ごとのコントラストやスタイルを弱め、スタイル変換などに向きますが、有用な強度情報も消す可能性があります。

Group Normalization

CCC を GGG 組に分け、一サンプル内の組チャネルと空間をまとめます。

μng=1(C/G)HW∑c∈g,h,wxnchw.\mu_{ng}=\frac{1}{(C/G)HW} \sum_{c\in g,h,w}x_{nchw}.μng​=(C/G)HW1​c∈g,h,w∑​xnchw​.

分散と affine は共通式に従います。小 Batch の検出、分割、拡散に向きます。G=1G=1G=1 は全チャネル・空間の LN、G=CG=CG=C は IN に近づきますが、affine の形や軸により完全等価とは限りません。

組数を検証する

チャネル数を割り切る組数または組内チャネル数を選びます。少数組は全体 LN、多数組は IN に近づき、最適値は幅とタスク次第です。

比較と関連概念

混同しやすい三つの概念

L2 正規化は Embedding を単位球へ写します。

x^=x∥x∥2+ε.\hat{x}=\frac{x}{\lVert x\rVert_2+\varepsilon}.x^=∥x∥2​+εx​.

中心化や Batch 統計はなく、検索で内積をコサイン類似度にします。

Weight Normalization は活性値ではなく重みの再パラメーター化です。

w=gv∥v∥2.w=g\frac{v}{\lVert v\rVert_2}.w=g∥v∥2​v​.

方向 vvv と尺度 ggg を分離します。

AdaLN は通常の LN 後に、時刻やテキスト条件から affine を作ります。

y=(1+s(c))⊙LN⁡(x)+b(c).y=\left(1+s(c)\right)\odot\operatorname{LN}(x)+b(c).y=(1+s(c))⊙LN(x)+b(c).

変わるのはパラメーター源で、統計軸とは限りません。残差ゲートも調整する実装があります。

残差経路の Pre-Norm と Post-Norm

サブ層 FFF と入力 xlx_lxl​ に対し、Pre-Norm は次式です。

xl+1=xl+F(Norm⁡(xl)).x_{l+1}=x_l+F(\operatorname{Norm}(x_l)).xl+1​=xl​+F(Norm(xl​)).

Post-Norm は次式です。

xl+1=Norm⁡(xl+F(xl)).x_{l+1}=\operatorname{Norm}\left(x_l+F(x_l)\right).xl+1​=Norm(xl​+F(xl​)).
図の構造を見る（原文）
flowchart LR
    subgraph PRE["Pre-Norm"]
        P1["x_l"] --> P2["Norm"] --> P3["Attention / FFN"] --> P4["+"]
        P1 --> P4
        P4 --> P5["x_{l+1}"]
    end
    subgraph POST["Post-Norm"]
        O1["x_l"] --> O2["Attention / FFN"] --> O3["+"] --> O4["Norm"] --> O5["x_{l+1}"]

    end

Pre-Norm は恒等経路が直接的で深い最適化を助けやすく、Post-Norm は残差加算後に正規化するため初期化、warmup、尺度に敏感です。LN/RMSNorm は方式、Pre/Post は位置です。Sandwich、末端、QK Norm などは個別に検討します。

Micro-batch、並列化、配置の詳細

Batch と勾配蓄積

蓄積しても BN 統計は micro-batch 間で共有されません。SyncBN、事前学習統計の固定、再学習・検証を伴う GN、代表的なサンプリングを検討します。

分散学習

BN は通常ローカル、SyncBN は通信で統合します。LN/RMSNorm/GN/IN でも正規化軸を Tensor 並列で割れば reduction が必要です。Batch 非依存は無通信ではありません。

混合精度

分散には桁落ちやあふれがあるため、安定な計算と FP32 累積を使います。大きすぎる ε\varepsilonε は小分散特徴の尺度を変えるため、単純に増やせばよいものではありません。

Padding と Mask

token 単位の LN/RMSNorm は他 token の統計へ Padding を混ぜませんが、Attention と Loss の Mask は必要です。時間・空間をまたぐ独自 Norm は明示的に除外を確認します。

配置と融合

BN の固定統計は前段へ折り込めます。入力依存の LN/RMSNorm は同様にはできませんが、Norm と残差の融合 Kernel でメモリ転送を減らせます。

統計の固定とパラメーターの固定

running 統計の固定と γ,β\gamma,\betaγ,β の固定は別です。どちらを行うか明示します。

正規化だけで安定性は完成しない

残差、初期化、学習率、最適化器、活性化、系列長、混合精度、異常データは引き続き不安定化の原因になります。
