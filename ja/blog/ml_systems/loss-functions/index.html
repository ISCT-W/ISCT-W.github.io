損失関数：ラベル構造、勾配への寄与、タスク指標

損失関数はタスクを数値目標にしますが、必要な効果と自動的に一致するわけではありません。

W韋 君豪読了目安 11 分

損失関数はタスクを数値目標にしますが、必要な効果と自動的に一致するわけではありません。排他的分類、独立属性、連続値、領域関係で基本形が変わり、重み、Mask、集約、数値実装が更新を支配する例を決めます。

図の構造を見る（原文）
flowchart TD
    T["任务、标签与失败代价"] --> O["选择基本损失形式"]
    O --> W["设置样本、类别与多任务权重"]
    W --> M["检查 Mask 与归约分母"]
    M --> N["使用数值稳定的实现"]
    N --> G["观察损失与梯度贡献"]
    G --> V["验证任务指标、校准与失败切片"]
    V --> T

損失で最適化し、検証指標で目的への適合を判断します。平均損失の低下だけで選ばず、結果をラベル、サンプリング、重みの設計へ戻します。

分類：ラベル構造から始める

Binary Cross-Entropy

確率 ppp と y∈{0,1}y\in\{0,1\}y∈{0,1} では次式です。

LBCE=−[ylog⁡p+(1−y)log⁡(1−p)].\mathcal{L}_{\mathrm{BCE}} =-\left[y\log p+(1-y)\log(1-p)\right].LBCE​=−[ylogp+(1−y)log(1−p)].

logit zzz を使う安定形は次のとおりです。

L(z,y)=max⁡(z,0)−zy+log⁡(1+e−∣z∣).\mathcal{L}(z,y) =\max(z,0)-zy+\log\left(1+e^{-|z|}\right).L(z,y)=max(z,0)−zy+log(1+e−∣z∣).

用途

二値分類とマルチラベル分類です。後者はクラスごとに独立した Sigmoid/BCE を使い、確率和を 1 にする必要はありません。

注意点

logits 用損失には先に Sigmoid をかけません。pos_weight は正例項の重みで、サンプル全体の重みとは異なります。不均衡では閾値と Precision/Recall/PR-AUC も確認します。マルチラベルはクラス別の二値・軟ラベルを使い、一つの class index では表せません。

Softmax Cross-Entropy

排他的な KKK 分類の正解 yyy に対して定義します。

LCE=−log⁡ezy∑j=1Kezj=−zy+log⁡∑j=1Kezj.\mathcal{L}_{\mathrm{CE}} =-\log\frac{e^{z_y}}{\sum_{j=1}^{K}e^{z_j}} =-z_y+\log\sum_{j=1}^{K}e^{z_j}.LCE​=−log∑j=1K​ezj​ezy​​=−zy​+logj=1∑K​ezj​.

軟ラベル qqq なら次式です。

LCE(q,p)=−∑k=1Kqklog⁡pk.\mathcal{L}_{\mathrm{CE}}(q,p) =-\sum_{k=1}^{K}q_k\log p_k.LCE​(q,p)=−k=1∑K​qk​logpk​.

注意点

独立したマルチラベルには BCE を使います。生 logits と LogSumExp を使い、ignore、Padding、分母を確認します。クラス重みは目標を変えるため層別評価が必要です。Label Smoothing は過信を抑え得ますが、校正、希少クラス、精密なラベル学習に影響します。

Focal Loss

代表的な二値形です。

Lfocal=−αt(1−pt)γlog⁡pt,\mathcal{L}_{\mathrm{focal}} =-\alpha_t(1-p_t)^\gamma\log p_t,Lfocal​=−αt​(1−pt​)γlogpt​,

ptp_tpt​ は正解確率、γ≥0\gamma\geq0γ≥0 で、ゼロなら重み付き交差エントロピーです。

使う理由

大量の容易な負例の寄与を (1−pt)γ(1-p_t)^\gamma(1−pt​)γ で下げ、難しい例を重視します。

注意点

γ,α\gamma,\alphaγ,α は大きいほど良いのではなく検証が必要です。誤ラベルも難例に見えてノイズを増幅します。校正と閾値も再評価し、小確率の対数ではなく安定な logits 実装を使います。

KL Divergence と蒸留

DKL(P∥Q)=∑iPilog⁡PiQi.D_{\mathrm{KL}}(P\Vert Q) =\sum_i P_i\log\frac{P_i}{Q_i}.DKL​(P∥Q)=i∑​Pi​logQi​Pi​​.

KL は非対称です。蒸留では通常 Student QQQ を Teacher PPP に合わせます。

LKD=T2DKL(softmax⁡(zt/T)∥softmax⁡(zs/T)).\mathcal{L}_{\mathrm{KD}} =T^2D_{\mathrm{KL}} \left( \operatorname{softmax}(z_t/T) \Vert \operatorname{softmax}(z_s/T) \right).LKD​=T2DKL​(softmax(zt​/T)∥softmax(zs​/T)).

T2T^2T2 は温度による勾配尺度変化を補います。API が確率と対数確率のどちらを受けるか、batchmean と mean の分母を確認します。

確率式と安定な計算

Sigmoid 後の BCE は数学的には正しくても、極端な logits が 0/1 に丸められると対数が無限になります。統合損失で回避します。

Softmax CE と Sigmoid BCE はクラス数ではなく排他性で選びます。Focal は容易・困難の寄与を変えるだけで、標本偏り、誤ラベル、閾値を自動修正しません。

回帰：誤差と外れ値の費用

e=y^−ye=\hat y-ye=y^​−y とします。

MSE / L2

LMSE=1n∑i=1nei2.\mathcal{L}_{\mathrm{MSE}}=\frac{1}{n}\sum_{i=1}^{n}e_i^2.LMSE​=n1​i=1∑n​ei2​.

誤差へ二次罰則を与え、勾配は誤差に比例します。外れ値に敏感で、ガウス雑音の最尤推定に対応します。尺度変更で損失は二次、誤差勾配は一次に変わるため、対象の尺度を扱う必要があります。

MAE / L1

LMAE=1n∑i=1n∣ei∣.\mathcal{L}_{\mathrm{MAE}}=\frac{1}{n}\sum_{i=1}^{n}|e_i|.LMAE​=n1​i=1∑n​∣ei​∣.

外れ値に比較的強く、Laplace 雑音に対応します。ゼロでは劣勾配、それ以外はほぼ一定の勾配となり、最適値付近は MSE ほど滑らかではありません。

Huber / Smooth L1

Lδ(e)={12e2,∣e∣≤δ,δ(∣e∣−12δ),∣e∣>δ.\mathcal{L}_{\delta}(e)= \begin{cases} \frac{1}{2}e^2,&|e|\leq\delta,\\ \delta\left(|e|-\frac{1}{2}\delta\right),&|e|>\delta. \end{cases}Lδ​(e)={21​e2,δ(∣e∣−21​δ),​∣e∣≤δ,∣e∣>δ.​

小誤差は二次、大誤差は一次で、滑らかさと頑健性を両立します。δ\deltaδ はラベル尺度に合わせ、実装のスケール規約も確認します。

Quantile / Pinball

分位 τ∈(0,1)\tau\in(0,1)τ∈(0,1) に対する損失です。

ρτ(e)={τe,e≥0,(τ−1)e,e<0.\rho_\tau(e)= \begin{cases} \tau e,&e\geq 0,\\ (\tau-1)e,&e<0. \end{cases}ρτ​(e)={τe,(τ−1)e,​e≥0,e<0.​

条件付き分位と非対称リスクを推定します。τ=0.9\tau=0.9τ=0.9 は平均ではなく上側分位です。複数分位では順序の交差を確認します。

回帰損失の選択

条件 出発点 理由
ガウスに近い雑音、大誤差を重視 MSE 大誤差への強い勾配
外れ値が多い MAE 一次罰則
局所の滑らかさと頑健性 Huber 二次・一次の折衷
分位・不確実性区間 Quantile 分位を直接推定

数値の小ささだけでなく、外れ値と非対称誤差の業務上の扱いで選びます。

領域の重なりとボックスの幾何

Dice Loss

Soft Dice の代表形です。

Dice⁡(p,y)=2∑ipiyi+ε∑ipi+∑iyi+ε,LDice=1−Dice⁡(p,y).\operatorname{Dice}(p,y) =\frac{2\sum_i p_i y_i+\varepsilon} {\sum_i p_i+\sum_i y_i+\varepsilon}, \qquad \mathcal{L}_{\mathrm{Dice}}=1-\operatorname{Dice}(p,y).Dice(p,y)=∑i​pi​+∑i​yi​+ε2∑i​pi​yi​+ε​,LDice​=1−Dice(p,y).

利点

重なりを直接目標にし、小前景を平均画素 CE より重視しやすい損失です。

注意点

空 Mask と勾配を明示的に扱います。画像別、クラス別、全 Batch では重みが違います。BCE/CE と補完関係があり、小物体では ε\varepsilonε の位置と大きさも影響します。

IoU/Jaccard と Tversky

IoU⁡(p,y)=∑ipiyi+ε∑ipi+∑iyi−∑ipiyi+ε.\operatorname{IoU}(p,y) =\frac{\sum_i p_i y_i+\varepsilon} {\sum_i p_i+\sum_i y_i-\sum_i p_i y_i+\varepsilon}.IoU(p,y)=∑i​pi​+∑i​yi​−∑i​pi​yi​+ε∑i​pi​yi​+ε​.

Tversky は FP と FN を別の重みで扱います。

TI⁡=TP+εTP+αFP+βFN+ε.\operatorname{TI} =\frac{TP+\varepsilon} {TP+\alpha FP+\beta FN+\varepsilon}.TI=TP+αFP+βFN+εTP+ε​.

見逃し費用が高ければ FN 重みを増やせますが、実装の定義を確認します。Focal Tversky は低重複例を強調する一方、ノイズと設定に敏感です。

境界ボックス回帰

L1/Smooth L1 は座標尺度と表現に依存します。IoU は重複を直接測りますが非交差では情報が限定的です。GIoU、DIoU、CIoU は包囲領域、中心距離、縦横比を加えます。検出には分類、objectness、対応付け、Mask などもあり、重みが勾配寄与を決めます。

領域と画素の監督を組み合わせる

Dice は全体の重なり、BCE/CE は局所確率を学びます。併用では重みと空 Mask の挙動を検証します。

相対関係で表現空間を形作る

Triplet Loss

Ltriplet=max⁡(0,d(a,p)−d(a,n)+m),\mathcal{L}_{\mathrm{triplet}} =\max\left(0, d(a,p)-d(a,n)+m \right),Ltriplet​=max(0,d(a,p)−d(a,n)+m),

a,p,na,p,na,p,n は anchor、positive、negative、mmm は margin です。容易な負例ばかりでは損失がゼロになり、最難例だけでは誤ラベルを拾い得ます。mining、距離、L2 正規化、margin を合わせます。

InfoNCE

候補内の一正例に対して定義します。

LInfoNCE=−log⁡exp⁡(s(q,k+)/τ)∑jexp⁡(s(q,kj)/τ).\mathcal{L}_{\mathrm{InfoNCE}} =-\log \frac{\exp\left(s(q,k^+)/\tau\right)} {\sum_j\exp\left(s(q,k_j)/\tau\right)}.LInfoNCE​=−log∑j​exp(s(q,kj​)/τ)exp(s(q,k+)/τ)​.

sss は内積やコサイン類似度、τ\tauτ は温度です。

注意点

温度は鋭さと勾配尺度を変えます。大 Batch は負例とともにメモリ・通信を増やし、意味的な false negative もあり得ます。コサインなら通常 L2 正規化し、デバイス間の候補収集と勾配を確認します。召回改善だけで校正や閾値の良さは示せません。

温度と難しい負例

低温度は難例を強調し、ノイズと勾配も増幅し得ます。高温度は滑らかにします。正規化、候補数、ノイズと合わせて調整します。

生成モデルの目標

自己回帰言語モデリング

LNLL=−∑t=1Tlog⁡pθ(xt∣x<t).\mathcal{L}_{\mathrm{NLL}} =-\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).LNLL​=−t=1∑T​logpθ​(xt​∣x<t​).

通常 Token CE で実装し、入力・ラベルを正しくずらし、Padding、Prompt、監督しない位置を Mask します。Token 平均と系列平均は長さの重みを変えます。PPL は通常次式です。

PPL⁡=exp⁡(1TLNLL).\operatorname{PPL}=\exp\left(\frac{1}{T}\mathcal{L}_{\mathrm{NLL}}\right).PPL=exp(T1​LNLL​).

Tokenizer、前処理、Mask が違う PPL は直接比較しません。

Diffusion のノイズ予測

ε\varepsilonε 予測の例です。

Ldiff=Ex0,ε,t[w(t)∥ε−εθ(xt,t,c)∥22].\mathcal{L}_{\mathrm{diff}} =\mathbb{E}_{x_0,\varepsilon,t} \left[ w(t) \left\| \varepsilon-\varepsilon_\theta(x_t,t,c) \right\|_2^2 \right].Ldiff​=Ex0​,ε,t​[w(t)∥ε−εθ​(xt​,t,c)∥22​].

x0x_0x0​ や vvv を予測する場合もあり、サンプラーとの整合が必要です。時刻サンプリングと SNR 重みが学習領域を変えます。MSE 低下は知覚品質や文との一致を保証せず、潜在尺度、VAE、条件 Dropout も影響します。

VAE の ELBO

LVAE=Lrecon+βDKL(qϕ(z∣x)∥p(z)).\mathcal{L}_{\mathrm{VAE}} =\mathcal{L}_{\mathrm{recon}} +\beta D_{\mathrm{KL}} \left(q_\phi(z\mid x)\Vert p(z)\right).LVAE​=Lrecon​+βDKL​(qϕ​(z∣x)∥p(z)).

再構成は忠実度、KL は潜在分布を制御します。強すぎる KL は posterior collapse、弱すぎる KL は構造不足を招き得ます。annealing、free bits、デコーダー容量調整を検討します。

ラベルは排他的か独立か連続か構造か、FP/FN の費用は対称か、クラス・サイズ・長さが偏るか、出力は logits・確率・座標・Embedding のどれか、配置指標と整合するかを確認します。

実装が実際の最適化を決める

Logits と数値安定性

CE/BCEWithLogits へ生 logits を渡し、LogSumExp、log_softmax、stable softplus を使います。混合精度の Scale、あふれ、集約精度も確認します。

Reduction と Mask

sum、サンプル平均、Token 平均、系列平均は異なります。Mask 付き平均は次式です。

L=∑imiℓi∑imi,\mathcal{L} =\frac{\sum_i m_i\ell_i}{\sum_i m_i},L=∑i​mi​∑i​mi​ℓi​​,

mi∈{0,1}m_i\in\{0,1\}mi​∈{0,1} は有効位置です。Padding を分母に入れると重みが変わります。各 GPU の平均をさらに平均する方法と、全有効 Token の加重平均は、個数が違うと一致しません。

クラス不均衡

再サンプリングは分布、クラス重みは勾配、Focal は容易・困難の寄与、閾値は学習後の判断を変えます。クラス別または Precision/Recall/PR-AUC を報告し、組み合わせを評価します。

複数損失の尺度

Ltotal=∑k=1KλkLk.\mathcal{L}_{\mathrm{total}} =\sum_{k=1}^{K}\lambda_k\mathcal{L}_k.Ltotal​=k=1∑K​λk​Lk​.

λk\lambda_kλk​ は損失値だけでなく、勾配方向・ノルムとタスク結果で選びます。各項と重要勾配を記録し、一つが他を圧倒しないよう確認します。

誤ラベルと難例

高損失は難しさだけでなく破損、誤ラベル、分布外を示す場合があります。Focal と mining はそれを増幅するため、先に品質を確認します。

損失と指標の不一致

最低 CE が最高 F1、最低 MSE が最低業務費用、Dice 向上が境界改善、Diffusion MSE 低下が画質改善とは限りません。検証指標、校正、失敗の内訳で選びます。

学習損失から運用性能へ

低損失でも運用が悪い場合は、目標の不一致、クラス・長さ重み、漏えい、領域差、閾値、校正、平均に隠れた少数例を確認します。内訳と判断経路全体を調べる必要があります。
