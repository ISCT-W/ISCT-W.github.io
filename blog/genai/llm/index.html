语言模型基础：从 Attention 到预训练的计算分配

从自回归概率、Transformer、Mask 和初始化出发，理解预训练目标、KV Cache 与 Scaling Law 的成本边界。

W韦君豪约 11 分钟

语言模型把一段文本转成 token 序列，并学习在已有上下文下预测下一个 token。词汇知识、局部语法和跨句关系都要通过同一个条件分布表达。Transformer 的作用是构造上下文表示，预训练目标决定表示被怎样学习，而参数规模与数据量决定模型在有限计算预算内能学到多少。

自回归建模与 Transformer 层

对序列 x=(x1,…,xT)x=(x_1,\ldots,x_T)x=(x1​,…,xT​)，概率链式法则给出：

pθ(x)=∏t=1Tpθ(xt∣x<t),Lpretrain=−∑t=1Tlog⁡pθ(xt∣x<t).p_\theta(x)=\prod_{t=1}^{T}p_\theta(x_t\mid x_{<t}), \qquad \mathcal L_{\mathrm{pretrain}} =-\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).pθ​(x)=t=1∏T​pθ​(xt​∣x<t​),Lpretrain​=−t=1∑T​logpθ​(xt​∣x<t​).

训练时，完整序列已经存在，可以同时计算所有位置的损失；因果 Mask 负责阻止某个位置偷看未来。推理时，后续 token 尚未产生，只能把刚采样出的 token 接回上下文，再计算下一步。这解释了自回归模型“训练可并行、生成逐步进行”的差别。

典型的 decoder-only Transformer 交替使用 Self-Attention 和逐位置的前馈网络。Attention 让不同位置交换信息，FFN 对每个位置的表示执行非线性变换；残差连接保留信息与梯度路径，归一化控制输入子层的尺度。下面采用常见的 Pre-Norm 层作为示意，具体模型的 Norm、激活函数与残差位置可能不同。Transformer 原论文提供了 Attention 和多头结构的基础定义。

Attention 的尺度与梯度

单个 Head 的未缩放 Attention logit 为：

s=q⊤k=∑i=1dkqiki.s=q^\top k=\sum_{i=1}^{d_k}q_i k_i.s=q⊤k=i=1∑dk​​qi​ki​.

若粗略假设各维独立、均值为 0、方差为 1，则：

E[s]=0,Var⁡(s)=dk,Std⁡(s)=dk.\mathbb{E}[s]=0, \qquad \operatorname{Var}(s)=d_k, \qquad \operatorname{Std}(s)=\sqrt{d_k}.E[s]=0,Var(s)=dk​,Std(s)=dk​​.

因此：

Var⁡(q⊤kdk)≈1.\operatorname{Var}\left(\frac{q^\top k}{\sqrt{d_k}}\right)\approx 1.Var(dk​​q⊤k​)≈1.

除以 dk\sqrt{d_k}dk​​ 是为了消除 Head Dimension 增大带来的 logit 尺度增长，使 Softmax 不容易过早饱和，梯度也更稳定。这里的“标准差约为 1”依赖独立同分布等近似假设，不是对训练后 Q/K 的严格保证。

不同缩放对应的效果：

  • 不缩放：标准差随 dk\sqrt{d_k}dk​​ 增大，Softmax 容易接近 One-hot，非最大项梯度变小；
  • 除以 dkd_kdk​：标准差约为 1/dk1/\sqrt{d_k}1/dk​​，维度越大 logits 越接近 0，Softmax 容易过于均匀；
  • 除以 dk\sqrt{d_k}dk​​：恰好抵消求和带来的标准差增长，使不同 dkd_kdk​ 下的 logit 尺度大致一致；
  • 其他常数或 Learned Temperature 也可以使用，但若目的是抵消维度增长，量纲上自然得到 dk\sqrt{d_k}dk​​。QK-Norm 等变体还会先归一化 Q/K，再控制温度。

从方差的角度看，dkd_kdk​ 个近似独立项相加，方差加成 dkd_kdk​，标准差因此是 dk\sqrt{d_k}dk​​；Attention 除的是标准差，不是方差。

多头 Attention 与表示分工

Multi-Head Attention（MHA）把隐藏表示投影到 hhh 组不同的 Q/K/V 子空间，并行计算多个 Attention Head：

head⁡j=Attention⁡(XWjQ,XWjK,XWjV),\operatorname{head}_j = \operatorname{Attention} \left( XW_j^Q, XW_j^K, XW_j^V \right),headj​=Attention(XWjQ​,XWjK​,XWjV​), MHA⁡(X)=Concat⁡(head⁡1,…,head⁡h)WO.\operatorname{MHA}(X) = \operatorname{Concat} \left( \operatorname{head}_1,\ldots, \operatorname{head}_h \right)W^O.MHA(X)=Concat(head1​,…,headh​)WO.

不同 Head 可以学习不同的表示子空间和关系，例如局部依赖、长距离依赖、语法关系或指代关系；这是模型能够学出的分工，不是架构提前指定的语义。

通常令：

dk=dv=dmodelh.d_k=d_v=\frac{d_{\text{model}}}{h}.dk​=dv​=hdmodel​​.

因此在 dmodeld_{\text{model}}dmodel​ 固定时，增加 Head 数主要是把总通道拆成多个子空间，并不意味着 Q/K/V 投影参数量和主 Attention 计算量直接乘以 hhh。

随机初始化如何打破头之间的对称性

如果所有 Head 的 Q/K/V 参数、对应的输出投影路径以及其他运算都完全对称，那么它们前向输出相同、接收到的梯度也相同，之后的参数更新仍然相同：

W1(0)=W2(0),∇W1(t)=∇W2(t)⟹W1(t+1)=W2(t+1).W_1^{(0)}=W_2^{(0)}, \quad \nabla W_1^{(t)}=\nabla W_2^{(t)} \Longrightarrow W_1^{(t+1)}=W_2^{(t+1)}.W1(0)​=W2(0)​,∇W1(t)​=∇W2(t)​⟹W1(t+1)​=W2(t+1)​.

这时多个 Head 会退化成同一个 Head 的重复副本，无法产生分工。这与神经网络中多个神经元不能全部用相同权重初始化是同一个“对称性破缺”问题。

但“Q/K/V 初值相同”不一定足够让这种对称永远保持：如果 WOW^OWO 中连接不同 Head 的分块不同，它们反向收到的梯度就可能不同，从第一步更新后打破对称。严格结论应表述为：

在整个 Head-specific 计算与梯度路径都完全对称时，相同初始化会使各 Head 一直学成一样；实际训练通过独立随机初始化主动打破这种对称性。

初始化与信号传播

两者都希望避免网络加深后激活或梯度的方差逐层爆炸、消失，但针对的非线性假设不同。

Xavier / Glorot

常见正态形式为：

Var⁡(W)≈2fanin+fanout.\operatorname{Var}(W) \approx \frac{2}{\mathrm{fan}_{\mathrm{in}}+\mathrm{fan}_{\mathrm{out}}}.Var(W)≈fanin​+fanout​2​.

它同时兼顾前向和反向的方差，适合线性层以及 Tanh 一类近似对称的激活。Transformer 中包含线性投影、Attention、残差连接和 LayerNorm/RMSNorm。Xavier 可以作为部分线性矩阵的初始化起点，但是否合适还取决于激活函数、网络深度与残差缩放，不能仅凭模型名称判断。

Kaiming / He

对 ReLU，常见正态形式为：

Var⁡(W)≈2fanin.\operatorname{Var}(W) \approx \frac{2}{\mathrm{fan}_{\mathrm{in}}}.Var(W)≈fanin​2​.

在输入近似对称时，ReLU 会把约一半负激活置零，使二阶矩大约损失一半；Kaiming 中的系数 2 用来补偿这种方差损失。这个系数调整的是剩余激活和梯度的整体尺度，无法恢复 ReLU 已截断的单个负激活梯度。经典 CNN 大量使用 ReLU，所以通常搭配 Kaiming 初始化。

初始化必须与真实架构匹配

这两类初始化可以从各自的尺度假设理解：

  • Xavier：兼顾 fan_in 和 fan_out，适合线性/近似对称激活；
  • Kaiming：重点补偿 ReLU 截断带来的方差损失；
  • Transformer：大量线性投影、残差与 Norm，常用 GELU、SiLU/SwiGLU，因此常见 Xavier 或模型专用初始化；
  • 经典 CNN：卷积后常接 ReLU，因此常见 Kaiming。

但这不是“Transformer 与 CNN”本身决定的硬规则，关键是激活函数、残差结构和归一化方式。现代 Transformer 往往还会采用截断正态分布、Residual Branch Depth Scaling、较小输出投影初始化等专用策略；使用 ReLU 的 Transformer 或使用 GELU 的 CNN 也应按真实架构选择初始化，不能机械套用。

Mask 决定信息能流向哪里

Attention 的通用形式为：

Attention⁡(Q,K,V)=softmax⁡(QK⊤dk+M)V.\operatorname{Attention}(Q,K,V) =\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V.Attention(Q,K,V)=softmax(dk​​QK⊤​+M)V.

以四个 token 的因果 Mask 为例：

M=[0−∞−∞−∞00−∞−∞000−∞0000].M=\begin{bmatrix} 0&-\infty&-\infty&-\infty\\ 0&0&-\infty&-\infty\\ 0&0&0&-\infty\\ 0&0&0&0 \end{bmatrix}.M=​0000​−∞000​−∞−∞00​−∞−∞−∞0​​.

第 iii 行只允许访问不晚于 iii 的 token；Softmax 把被屏蔽位置的权重变为零。Padding Mask 则负责阻止填充位置参与有效信息聚合，这与因果约束是两个不同目的。

双向 Encoder 允许一个 token 同时使用左右上下文，适合表征学习、分类和抽取。BERT 通过遮蔽部分输入并预测被遮蔽内容来训练，不能直接把未遮蔽的完整句子作为输入，再把同位置 token 预测准确视为生成能力。Encoder–Decoder 系统可以先用双向 Encoder 理解输入，再由带因果 Mask 的 Decoder 生成输出，因此双向表征与生成任务并不矛盾。BERT 原论文

Prefix LM 允许前缀内部双向可见，后续生成部分只能访问完整前缀和已经生成的内容。Sequence-to-Sequence 模型则通过 Cross-Attention 读取编码端表示。两种安排都需要守住同一个条件：预测某个输出 token 时，不能读取尚未生成的目标信息。Decoder-only 架构把任务统一成文本续写，因而便于用同一目标训练和使用；这种接口上的简洁不意味着其他架构在所有任务上都处于劣势。

Attention 的计算成本与 KV Cache

标准全量 Self-Attention 要形成长度为 LLL 的位置两两关系，其核心矩阵计算量约为 O(L2d)O(L^2d)O(L2d)。直接保存全部 Attention 权重需要 O(L2)O(L^2)O(L2) 的空间。高效 Attention 内核可以减少中间矩阵的显存驻留和数据搬运，但精确全注意力的所有位置交互仍然存在，不能把节省显存等同于把计算复杂度改成线性。

自回归生成时，历史 token 的 K/V 不需要在每步重复投影，可以缓存下来；新 Query 与历史 K 做匹配，再聚合历史 V。KV Cache 减少重复计算，却会随着序列长度、层数和 KV Head 数增长。MHA 中每个 Query Head 有对应的 K/V Head；MQA 让多个 Query Head 共享一组 K/V，GQA 则按组共享。这些结构主要减少 KV Cache 和访存需求，实际速度仍取决于批量、序列长度和运行实现。GQA 原论文

预训练数据、损失与能力边界

预训练以大规模文本的 next-token 似然为主要目标，损失低说明模型更擅长预测评价语料中的 token。它没有直接把“事实正确”“遵循用户意图”或“引用可靠”写进目标函数。模型可能学到有用的世界规律，也可能记住过时事实、重复文本与来源偏差；这些问题需要相应任务的评测才能区分。

通用的带 Mask 负对数似然可以写成：

LNLL=−∑tmtlog⁡πθ(yt∣x,y<t).\mathcal L_{\mathrm{NLL}}=-\sum_t m_t\log\pi_\theta(y_t\mid x,y_{<t}).LNLL​=−t∑​mt​logπθ​(yt​∣x,y<t​).

预训练中，mtm_tmt​ 常用于屏蔽 Padding 或其他无效位置；SFT 中还可能屏蔽用户输入，只监督 Assistant 回答。两者的数学形式相近，差别主要来自数据分布、输入条件和监督范围。SFT 通常接在预训练之后，是为了利用已经形成的语言表示，用较少的高质量示范塑造任务行为。

数据处理会改变模型实际看到的分布。重复文档使某些样本被过度加权，评价数据混入训练集会夸大泛化效果，不同语言和领域比例会改变能力分配。训练过程中应把预训练损失、下游任务能力和数据质量共同观察，单一平均损失不足以说明每个领域都在改善。

Scaling Law 与有限预算下的选择

Chinchilla 研究固定训练计算量 CCC 下，参数量 NNN 和训练 token 数 DDD 如何分配。对稠密 Transformer，一个常见的粗略关系是：

C∝ND.C\propto ND.C∝ND.

模型过大却训练不足，会把预算花在没有充分利用的容量上；模型很小而训练很久，则可能受到容量限制。经验 Scaling Law 可以用类似下面的形式描述损失：

L(N,D)=E+ANα+BDγ,A,B,α,γ>0.L(N,D)=E+\frac{A}{N^{\alpha}}+\frac{B}{D^{\gamma}}, \qquad A,B,\alpha,\gamma>0.L(N,D)=E+NαA​+DγB​,A,B,α,γ>0.

EEE 表示拟合中的不可约项，另外两项分别描述容量与数据不足造成的误差。在计算约束下对这个关系求最优分配，可以为模型规模与训练长度提供候选配置，但指数与系数需要从目标数据和模型族拟合。Chinchilla 论文在其设定内得到参数和数据大致同比例增长、约 20 个训练 token/参数的经验结果。

“20 token/参数”不适合当作普遍上限。若模型部署后被调用极多次，总成本还包含推理成本：一个更小、训练更充分的模型可能降低整个生命周期的开销。数据质量、训练目标、上下文长度和稀疏架构也会改变最优点；MoE 的总参数量与每 token 激活参数量尤其不能混用。

例如，在只考虑 NDNDND 的粗略预算时，把参数翻倍而 token 数减半，乘积没有变化，但最终损失未必一样。两种误差项的相对大小决定哪种分配更合理。Scaling Law 提供的是实验方向，仍需小规模训练、留出集评估和成本测量来检验它是否适用于当前条件。
