激活函数：从函数形状理解梯度与表示

比较 Sigmoid、Tanh、ReLU 家族、GELU、SiLU 与门控函数，保留公式和曲线，说明梯度饱和、初始化及输出层选择。

W韦君豪约 8 分钟

激活函数让线性变换能够组成非线性模型，也改变了梯度经过每一层时的尺度。比较函数值与导数，可以看清饱和、负半轴截断和平滑门控的差异；真正替换一个激活函数时，还要同时考虑初始化、残差路径与预训练权重的分布。

前向路径关注函数怎样改变表示，反向路径还要乘以局部导数。函数更平滑或负区间保留梯度，都不能单独保证整个深层网络训练稳定。

先区分隐藏层、输出头与训练目标

查看图示的文字结构
flowchart LR
    X["线性变换 z=Wx+b"] --> A["隐藏层激活函数"]
    A --> H["中间表示 h"]
    H --> O["输出头产生 logits / prediction"]
    O --> L["损失函数与标签比较"]
    L --> G["反向传播梯度"]
  • 激活函数给网络引入非线性，并决定不同输入区间的梯度形态；
  • 输出变换把 logits 转成概率、正数或其他受约束的量，例如 Sigmoid、Softmax、Softplus；
  • 损失函数衡量预测与监督信号的差异，产生优化目标。

同一个函数可能出现在不同位置。例如 Sigmoid 可以是隐藏层激活，也可以把二分类 logit 映射为概率；但数值稳定的二分类训练通常使用 BCEWithLogitsLoss，而不是先显式 Sigmoid 再计算 BCE。

函数值与导数

下图同时画出函数值与导数。可以直接看到：Sigmoid/Tanh 在两端趋于饱和，ReLU 在负半轴梯度为 0，而 GELU/SiLU 在负区间仍保留一段非零梯度。

Sigmoid

σ(x)=11+e−x,σ′(x)=σ(x)(1−σ(x)).\sigma(x)=\frac{1}{1+e^{-x}}, \qquad \sigma'(x)=\sigma(x)\left(1-\sigma(x)\right).σ(x)=1+e−x1​,σ′(x)=σ(x)(1−σ(x)).

因为 0<σ′(x)≤1/40<\sigma'(x)\leq 1/40<σ′(x)≤1/4，且当 ∣x∣|x|∣x∣ 很大时导数接近 0，深层网络连续相乘后容易梯度消失。

适用场景

  • 二分类或多标签分类的概率输出；
  • LSTM、GRU、GLU 等门控结构；
  • 需要把值限制在 (0,1)(0,1)(0,1) 的位置。

注意点

  • 正负饱和区梯度都接近 0；
  • 输出不是零中心，作为深层隐藏层激活时可能降低优化效率；
  • 直接计算 e−xe^{-x}e−x 或 log(sigmoid(x)) 容易溢出/下溢；
  • 二分类训练优先使用基于 logits 的稳定损失。

Tanh

tanh⁡(x)=ex−e−xex+e−x,ddxtanh⁡(x)=1−tanh⁡2(x).\tanh(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}, \qquad \frac{d}{dx}\tanh(x)=1-\tanh^2(x).tanh(x)=ex+e−xex−e−x​,dxd​tanh(x)=1−tanh2(x).

Tanh 输出位于 (−1,1)(-1,1)(−1,1) 且以 0 为中心，但大正数和大负数处仍会饱和并导致梯度消失。它常用于循环网络状态或需要有界、带符号输出的结构，不是“零中心就没有梯度问题”。

ReLU

ReLU⁡(x)=max⁡(0,x),ReLU⁡′(x)={0,x<0,1,x>0.\operatorname{ReLU}(x)=\max(0,x), \qquad \operatorname{ReLU}'(x)= \begin{cases} 0,&x<0,\\ 1,&x>0. \end{cases}ReLU(x)=max(0,x),ReLU′(x)={0,1,​x<0,x>0.​

x=0x=0x=0 处不可导，工程实现使用约定的次梯度，通常不构成主要问题。

优点

  • 正区间不饱和，梯度为 1；
  • 计算简单；
  • 负区间输出为 0，可产生稀疏激活；
  • 配合 He/Kaiming 初始化，是 CNN/MLP 的经典基线。

Dying ReLU

如果某个神经元对所有输入都落入负区间，它的梯度长期为 0，参数可能无法再更新，这就是 Dying ReLU。常见诱因包括学习率过大、偏置被推到很负、初始化不合适或输入分布漂移。

缓解方法包括：

  • 降低学习率并检查初始化；
  • 使用 Leaky ReLU、PReLU、ELU、GELU 或 SiLU；
  • 配合合适的归一化和残差结构；
  • 监控各层激活为零的比例，而不是只看总 Loss。

ReLU 的正区间无上界，因此仍可能出现激活或梯度过大；“正区间不饱和”不等于“不会梯度爆炸”。

Leaky ReLU 与 PReLU

f(x)={x,x≥0,αx,x<0.f(x)= \begin{cases} x,&x\geq 0,\\ \alpha x,&x<0. \end{cases}f(x)={x,αx,​x≥0,x<0.​
  • Leaky ReLU 使用固定的小 α>0\alpha>0α>0；
  • PReLU 将 α\alphaα 设为可学习参数。

负区间保留梯度，可以减轻 Dying ReLU。但 PReLU 增加参数，并可能需要正则化或约束；Leaky ReLU 也不能自动解决学习率、初始化和数值溢出问题。

ELU、SELU 与 Softplus

ELU 定义为：

ELU⁡(x)={x,x>0,α(ex−1),x≤0.\operatorname{ELU}(x)= \begin{cases} x,&x>0,\\ \alpha(e^x-1),&x\leq 0. \end{cases}ELU(x)={x,α(ex−1),​x>0,x≤0.​

ELU 在负区间饱和到 −α-\alpha−α，输出可为负，通常比 ReLU 平滑，但指数计算更贵，负饱和区仍可能梯度很小。

SELU 通过特定的缩放参数实现“自归一化”性质，但依赖较强条件，例如合适初始化、网络结构与 AlphaDropout。不能把普通 ReLU 网络中的激活直接换成 SELU 就期待自动稳定。

Softplus 是 ReLU 的平滑近似：

Softplus⁡(x)=log⁡(1+ex),Softplus⁡′(x)=σ(x).\operatorname{Softplus}(x)=\log(1+e^x), \qquad \operatorname{Softplus}'(x)=\sigma(x).Softplus(x)=log(1+ex),Softplus′(x)=σ(x).

它处处可导并保证输出为正，适合参数化标准差、速率等正数；但不会产生严格的零激活，负区间仍可能梯度很小。实现时应使用稳定的 softplus，避免直接计算大 xxx 的指数。

GELU 与 SiLU/Swish

GELU：

GELU⁡(x)=xΦ(x),\operatorname{GELU}(x)=x\Phi(x),GELU(x)=xΦ(x),

其中 Φ(x)\Phi(x)Φ(x) 是标准正态分布的累积分布函数。常见近似为：

GELU⁡(x)≈x2[1+tanh⁡(2π(x+0.044715x3))].\operatorname{GELU}(x)\approx \frac{x}{2} \left[ 1+\tanh\left( \sqrt{\frac{2}{\pi}} \left(x+0.044715x^3\right) \right) \right].GELU(x)≈2x​[1+tanh(π2​​(x+0.044715x3))].

SiLU，也称 Swish（参数固定为 1 的常见形式）：

SiLU⁡(x)=xσ(x),\operatorname{SiLU}(x)=x\sigma(x),SiLU(x)=xσ(x), SiLU⁡′(x)=σ(x)+xσ(x)(1−σ(x)).\operatorname{SiLU}'(x) =\sigma(x)+x\sigma(x)(1-\sigma(x)).SiLU′(x)=σ(x)+xσ(x)(1−σ(x)).

二者都平滑，并允许一部分负值通过；它们不是处处单调，也不像 ReLU 那样在整个负半轴梯度恒为 0。GELU 常见于 Transformer，SiLU 常见于现代 LLM、视觉模型和扩散模型。实际选择通常遵循预训练架构与验证结果，而不是脱离模型直接比较谁“绝对更好”。

GLU 与 SwiGLU

门控线性单元的一般形式可写为：

GLU⁡(x)=(xWv+bv)⊙g(xWg+bg),\operatorname{GLU}(x) =(xW_v+b_v)\odot g(xW_g+b_g),GLU(x)=(xWv​+bv​)⊙g(xWg​+bg​),

其中 ggg 可以是 Sigmoid、GELU 或 SiLU。SwiGLU 使用 SiLU 门：

SwiGLU⁡(x)=SiLU⁡(xWg)⊙(xWv).\operatorname{SwiGLU}(x) =\operatorname{SiLU}(xW_g)\odot(xW_v).SwiGLU(x)=SiLU(xWg​)⊙(xWv​).

它比单一逐点激活多一条投影分支，表达力更强，但参数量、计算量和中间激活也需要按 FFN 宽度一起比较。

Softmax

数值稳定实现先减去最大 logit：

pi=ezi−zmax⁡∑jezj−zmax⁡.p_i= \frac{e^{z_i-z_{\max}}} {\sum_j e^{z_j-z_{\max}}}.pi​=∑j​ezj​−zmax​ezi​−zmax​​.

Softmax 用于互斥多分类或 Attention 权重。训练多分类模型时应把原始 logits 交给 Cross-Entropy，让框架在一次稳定运算中完成 log_softmax + NLL，不要先手动 Softmax。

梯度传播中的三种限制

它的导数最大只有 1/41/41/4，在大正/大负输入处接近 0。深层链式求导时多个小导数相乘，前层梯度迅速衰减。门控结构仍使用 Sigmoid，是因为它需要 (0,1)(0,1)(0,1) 的门值，并由残差或状态路径帮助传递信息。

ReLU 在正区间导数为 1，但负区间导数为 0。若神经元长期落在负区间，就会成为 Dying ReLU。它缓解的是正饱和问题，不是消灭所有梯度问题。

它们平滑地抑制负输入，并保留一部分负值和梯度；与 Transformer/现代视觉架构的经验效果较好。但性能来自整套架构和训练配置，不能脱离预训练结构只归因于激活函数。

初始化与激活要匹配

  • ReLU 系通常配合 He/Kaiming 初始化；
  • Tanh/Sigmoid 常考虑 Xavier/Glorot 初始化，但深层饱和问题仍然存在；
  • Transformer 还要同时考虑残差分支、Norm 位置、深度缩放和 Warmup；
  • 替换激活函数会改变输出方差和预训练权重分布，不能只改一个配置项就默认等价。
