损失函数：标签结构、梯度贡献与任务指标

完整展开分类、回归、分割、对比学习和生成模型的损失，结合数值稳定性、掩码、归约与梯度尺度判断训练目标。

W韦君豪约 12 分钟

损失函数把任务变成可优化的数值目标，但这个目标不天然等同于最终需要的效果。标签是互斥类别、独立属性、连续值还是区域关系，决定了损失的基本形式；权重、掩码、归约方式和数值实现，又决定哪些样本真正主导参数更新。

分类损失：先确定标签结构

Binary Cross-Entropy（BCE）

对二分类概率 ppp 和标签 y∈{0,1}y\in\{0,1\}y∈{0,1}：

LBCE=−[ylog⁡p+(1−y)log⁡(1−p)].\mathcal{L}_{\mathrm{BCE}} =-\left[y\log p+(1-y)\log(1-p)\right].LBCE​=−[ylogp+(1−y)log(1−p)].

若模型输出 logit zzz，稳定的 BCE with logits 可写成：

L(z,y)=max⁡(z,0)−zy+log⁡(1+e−∣z∣).\mathcal{L}(z,y) =\max(z,0)-zy+\log\left(1+e^{-|z|}\right).L(z,y)=max(z,0)−zy+log(1+e−∣z∣).

适用场景

  • 二分类；
  • 多标签分类：每个类别独立做 Sigmoid+BCE，不要求类别概率和为 1。

注意点

  • 训练时传 logits，不要先 Sigmoid；
  • pos_weight 调整正样本项，与对整个样本 Loss 加权的含义不同；
  • 类别极不平衡时，除加权外还要调决策阈值并看 PR-AUC、Recall、Precision；
  • 多标签任务的标签应是每类独立的 0/1 或软标签，不能误用单个 class index。

Softmax Cross-Entropy

对互斥 KKK 分类、真实类别 yyy：

LCE=−log⁡ezy∑j=1Kezj=−zy+log⁡∑j=1Kezj.\mathcal{L}_{\mathrm{CE}} =-\log\frac{e^{z_y}}{\sum_{j=1}^{K}e^{z_j}} =-z_y+\log\sum_{j=1}^{K}e^{z_j}.LCE​=−log∑j=1K​ezj​ezy​​=−zy​+logj=1∑K​ezj​.

带软标签 qqq 时：

LCE(q,p)=−∑k=1Kqklog⁡pk.\mathcal{L}_{\mathrm{CE}}(q,p) =-\sum_{k=1}^{K}q_k\log p_k.LCE​(q,p)=−k=1∑K​qk​logpk​.

注意点

  • 适用于互斥单标签分类；多标签任务应使用 BCE；
  • 输入应为 logits，稳定实现内部使用 LogSumExp；
  • ignore_index、Padding mask 和 reduction 分母必须正确；
  • 类别权重会改变优化目标，不能只汇报未分组的 Accuracy；
  • Label Smoothing 可降低过度自信，但可能影响概率校准、稀有类和精确标签学习。

Focal Loss

二分类形式常写为：

Lfocal=−αt(1−pt)γlog⁡pt,\mathcal{L}_{\mathrm{focal}} =-\alpha_t(1-p_t)^\gamma\log p_t,Lfocal​=−αt​(1−pt​)γlogpt​,

其中 ptp_tpt​ 是模型分给真实类别的概率，γ≥0\gamma\geq 0γ≥0。当 γ=0\gamma=0γ=0 时退化为加权交叉熵。

为什么使用

大量易分类负样本可能主导梯度；(1−pt)γ(1-p_t)^\gamma(1−pt​)γ 会降低易样本权重，把训练重点放到难样本。

注意点

  • γ\gammaγ 和 α\alphaα 需要验证，不是越大越好；
  • 错标样本也会被视为“难样本”，因此对标签噪声可能更敏感；
  • 可能改变概率校准，部署时仍需验证阈值；
  • 实现应基于 logits 的稳定 BCE/CE，而不是先计算接近 0 的概率再取对数。

KL Divergence 与蒸馏

DKL(P∥Q)=∑iPilog⁡PiQi.D_{\mathrm{KL}}(P\Vert Q) =\sum_i P_i\log\frac{P_i}{Q_i}.DKL​(P∥Q)=i∑​Pi​logQi​Pi​​.

KL 不对称：DKL(P∥Q)D_{\mathrm{KL}}(P\Vert Q)DKL​(P∥Q) 与 DKL(Q∥P)D_{\mathrm{KL}}(Q\Vert P)DKL​(Q∥P) 的行为不同。蒸馏中常让 Student 分布 QQQ 拟合 Teacher 分布 PPP：

LKD=T2DKL(softmax⁡(zt/T)∥softmax⁡(zs/T)).\mathcal{L}_{\mathrm{KD}} =T^2D_{\mathrm{KL}} \left( \operatorname{softmax}(z_t/T) \Vert \operatorname{softmax}(z_s/T) \right).LKD​=T2DKL​(softmax(zt​/T)∥softmax(zs​/T)).

T2T^2T2 用于补偿温度升高带来的梯度尺度变化。使用框架 KL API 时要确认参数到底接受 probability 还是 log-probability，以及 batchmean、mean 等 reduction 的含义。

概率形式与稳定实现

数学上可以，数值上不稳。极端 logit 会让概率舍入到 0 或 1，随后取对数可能得到 Inf。BCEWithLogits 使用稳定形式把两步合并。

互斥单标签分类用 Softmax Cross-Entropy；每个类别可以独立为真的多标签任务用 Sigmoid BCE。关键是标签结构，而不是类别数量。

回归损失：误差与离群点的代价

令误差 e=y^−ye=\hat{y}-ye=y^​−y。

MSE / L2 Loss

LMSE=1n∑i=1nei2.\mathcal{L}_{\mathrm{MSE}}=\frac{1}{n}\sum_{i=1}^{n}e_i^2.LMSE​=n1​i=1∑n​ei2​.
  • 对大误差惩罚强，梯度随误差线性增大；
  • 对离群点敏感；
  • 对应高斯噪声下的最大似然假设；
  • 目标尺度变大时 Loss 和梯度都会平方级变化，通常要做尺度处理。

MAE / L1 Loss

LMAE=1n∑i=1n∣ei∣.\mathcal{L}_{\mathrm{MAE}}=\frac{1}{n}\sum_{i=1}^{n}|e_i|.LMAE​=n1​i=1∑n​∣ei​∣.
  • 对离群点比 MSE 鲁棒；
  • 在 e=0e=0e=0 处不可导，框架使用次梯度；
  • 非零误差处梯度幅值近似恒定，靠近最优点时可能不如 MSE 平滑；
  • 对应 Laplace 噪声假设。

Huber Loss / Smooth L1

Lδ(e)={12e2,∣e∣≤δ,δ(∣e∣−12δ),∣e∣>δ.\mathcal{L}_{\delta}(e)= \begin{cases} \frac{1}{2}e^2,&|e|\leq\delta,\\ \delta\left(|e|-\frac{1}{2}\delta\right),&|e|>\delta. \end{cases}Lδ​(e)={21​e2,δ(∣e∣−21​δ),​∣e∣≤δ,∣e∣>δ.​

小误差区像 MSE 一样平滑，大误差区像 MAE 一样降低离群点影响。δ\deltaδ 必须结合标签尺度选择；不同框架中 Huber 与 Smooth L1 的缩放约定可能不同。

Quantile / Pinball Loss

对目标分位数 τ∈(0,1)\tau\in(0,1)τ∈(0,1)：

ρτ(e)={τe,e≥0,(τ−1)e,e<0.\rho_\tau(e)= \begin{cases} \tau e,&e\geq 0,\\ (\tau-1)e,&e<0. \end{cases}ρτ​(e)={τe,(τ−1)e,​e≥0,e<0.​

它用于预测条件分位数和不对称风险。例如 τ=0.9\tau=0.9τ=0.9 关注较高分位，而不只是条件均值。训练多个分位数时要检查 quantile crossing。

回归损失选择

数据条件 常用起点 原因
近似高斯噪声、重视大误差 MSE 大误差梯度更强
离群点较多 MAE 对离群点较鲁棒
既要局部平滑又要抗离群 Huber 二次区与线性区折中
需要不确定性区间/分位数 Quantile 直接估计条件分位数

MAE 更抗离群点，因为误差只线性增长；MSE 对大误差平方惩罚。Huber 在小误差区使用二次项、大误差区使用线性项，是常见折中。

区域重叠与边界框几何

Dice Loss

Soft Dice 常写成：

Dice⁡(p,y)=2∑ipiyi+ε∑ipi+∑iyi+ε,LDice=1−Dice⁡(p,y).\operatorname{Dice}(p,y) =\frac{2\sum_i p_i y_i+\varepsilon} {\sum_i p_i+\sum_i y_i+\varepsilon}, \qquad \mathcal{L}_{\mathrm{Dice}}=1-\operatorname{Dice}(p,y).Dice(p,y)=∑i​pi​+∑i​yi​+ε2∑i​pi​yi​+ε​,LDice​=1−Dice(p,y).

优点

  • 直接优化区域重叠；
  • 前景很小时通常比逐像素平均 CE 更关注前景。

注意点

  • 空 mask 时分子分母和梯度要特别处理；
  • 按 image、class 还是整个 batch 计算，会产生不同权重；
  • Dice 关注整体重叠，但像素级概率学习可与 BCE/CE 互补，因此常组合使用；
  • ε\varepsilonε 的放置和大小会影响小目标。

IoU/Jaccard 与 Tversky

IoU⁡(p,y)=∑ipiyi+ε∑ipi+∑iyi−∑ipiyi+ε.\operatorname{IoU}(p,y) =\frac{\sum_i p_i y_i+\varepsilon} {\sum_i p_i+\sum_i y_i-\sum_i p_i y_i+\varepsilon}.IoU(p,y)=∑i​pi​+∑i​yi​−∑i​pi​yi​+ε∑i​pi​yi​+ε​.

Tversky Index 通过不同权重控制 FP 和 FN：

TI⁡=TP+εTP+αFP+βFN+ε.\operatorname{TI} =\frac{TP+\varepsilon} {TP+\alpha FP+\beta FN+\varepsilon}.TI=TP+αFP+βFN+εTP+ε​.

当漏检成本高时可以提高 FNFNFN 对应权重，但参数含义要以具体实现为准。Focal Tversky 会进一步强调低重叠样本，也会更敏感于噪声和超参数。

边界框回归

  • L1/Smooth L1 直接回归坐标，但对目标尺度和参数化敏感；
  • IoU Loss 直接优化重叠，但无交集时普通 IoU 提供的信息有限；
  • GIoU、DIoU、CIoU 分别进一步考虑最小包围区域、中心距离和长宽比等几何因素；
  • 检测总损失通常还包含分类、objectness、匹配和 mask 等项，各项权重决定实际梯度贡献。

组合区域与像素监督

Dice 直接关注整体区域重叠，对小前景友好；BCE/CE 提供逐像素分类监督。组合后可兼顾全局重叠与局部概率学习，但必须验证两项权重与空 mask 行为。

用相对关系塑造表示空间

Triplet Loss

Ltriplet=max⁡(0,d(a,p)−d(a,n)+m),\mathcal{L}_{\mathrm{triplet}} =\max\left(0, d(a,p)-d(a,n)+m \right),Ltriplet​=max(0,d(a,p)−d(a,n)+m),

其中 a,p,na,p,na,p,n 分别为 anchor、positive、negative，mmm 为 margin。

主要注意点：

  • 随机负样本太容易时，大量 triplet 的 Loss 为 0；
  • 只选最难负样本可能选到错标或异常值；
  • 需要设计 online/offline mining；
  • 距离度量、embedding 是否 L2 归一化和 margin 必须匹配。

InfoNCE

对一个正样本和一组候选：

LInfoNCE=−log⁡exp⁡(s(q,k+)/τ)∑jexp⁡(s(q,kj)/τ).\mathcal{L}_{\mathrm{InfoNCE}} =-\log \frac{\exp\left(s(q,k^+)/\tau\right)} {\sum_j\exp\left(s(q,k_j)/\tau\right)}.LInfoNCE​=−log∑j​exp(s(q,kj​)/τ)exp(s(q,k+)/τ)​.

sss 常为点积或余弦相似度，τ\tauτ 为温度。

注意点

  • 温度控制分布尖锐程度和梯度尺度；
  • Batch 越大通常负样本越多，但显存和跨卡通信也增加；
  • Batch 中可能存在语义相同的 false negatives；
  • 使用余弦相似度时通常先做 L2 归一化；
  • 分布式训练要确认是否跨卡收集 negatives，以及梯度是否正确回传；
  • 只提高检索 Recall 不代表 embedding 已校准，仍需看下游阈值与 hard cases。

温度与难负样本

较小温度让相似度分布更尖锐、强调难负样本，同时可能放大噪声和梯度；较大温度使分布更平滑。温度与 embedding 归一化、Batch negatives 和数据噪声要联合调节。

生成式模型的训练目标

LLM 的自回归语言建模损失

LNLL=−∑t=1Tlog⁡pθ(xt∣x<t).\mathcal{L}_{\mathrm{NLL}} =-\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).LNLL​=−t=1∑T​logpθ​(xt​∣x<t​).

工程上通常是 token-level Cross-Entropy。注意：

  • 输入与 label 要正确右移一位；
  • Padding、Prompt 区域或不参与训练的 token 要设 mask；
  • 按 token 平均与按 sequence 平均会改变长短样本权重；
  • Perplexity 通常为平均 token NLL 的指数：
PPL⁡=exp⁡(1TLNLL).\operatorname{PPL}=\exp\left(\frac{1}{T}\mathcal{L}_{\mathrm{NLL}}\right).PPL=exp(T1​LNLL​).

跨不同 tokenizer、不同数据清洗和不同 token mask 的 PPL 不宜直接横向比较。

Diffusion 的噪声预测损失

以 ε\varepsilonε-prediction 为例：

Ldiff=Ex0,ε,t[w(t)∥ε−εθ(xt,t,c)∥22].\mathcal{L}_{\mathrm{diff}} =\mathbb{E}_{x_0,\varepsilon,t} \left[ w(t) \left\| \varepsilon-\varepsilon_\theta(x_t,t,c) \right\|_2^2 \right].Ldiff​=Ex0​,ε,t​[w(t)∥ε−εθ​(xt​,t,c)∥22​].

注意点：

  • 训练目标可能是 ε\varepsilonε、x0x_0x0​ 或 vvv，公式与采样器要一致；
  • 时间步采样和 w(t)w(t)w(t) / SNR weighting 会改变模型关注的噪声区间；
  • 简单 MSE 下降不一定与感知质量、文本一致性同步；
  • Latent scaling、VAE 编解码和条件 Dropout 也会改变实际训练行为。

VAE 的 ELBO

LVAE=Lrecon+βDKL(qϕ(z∣x)∥p(z)).\mathcal{L}_{\mathrm{VAE}} =\mathcal{L}_{\mathrm{recon}} +\beta D_{\mathrm{KL}} \left(q_\phi(z\mid x)\Vert p(z)\right).LVAE​=Lrecon​+βDKL​(qϕ​(z∣x)∥p(z)).

重建项控制还原质量，KL 项约束潜变量分布。KL 权重过强可能导致 posterior collapse，过弱则潜空间缺乏结构。常见策略包括 KL annealing、free bits 和调整解码器容量。

实现细节决定实际优化的问题

Logits、概率与数值稳定性

  • Cross-Entropy 直接接 logits，不要先 Softmax；
  • BCEWithLogits 直接接 logits，不要先 Sigmoid；
  • 使用 LogSumExp、log_softmax、stable softplus，避免对极小概率直接取对数；
  • 混合精度下要检查 Loss Scale、溢出和归约精度。

Reduction 与 Mask

mean、sum、按 token 平均、按样本平均并不等价。变长序列中常用：

L=∑imiℓi∑imi,\mathcal{L} =\frac{\sum_i m_i\ell_i}{\sum_i m_i},L=∑i​mi​∑i​mi​ℓi​​,

其中 mi∈{0,1}m_i\in\{0,1\}mi​∈{0,1} 是有效位置 mask。若错误地除以包含 Padding 的总长度，短样本和长样本的权重都会变化。

分布式训练还要确认是“各卡先 mean 再平均”，还是“全局有效 token 的加权 mean”；每卡有效 token 数不同，两者并不相等。

类别不平衡

常见手段包括重采样、类别权重、Focal Loss、阈值调节和 hard example mining。它们改变的位置不同：

  • 重采样改变训练数据分布；
  • 类别权重改变梯度贡献；
  • Focal 改变易/难样本贡献；
  • 阈值调节不改变训练，只改变决策；
  • 指标应至少分类别或同时报告 Precision/Recall/PR-AUC。

多个 Loss 的尺度

Ltotal=∑k=1KλkLk.\mathcal{L}_{\mathrm{total}} =\sum_{k=1}^{K}\lambda_k\mathcal{L}_k.Ltotal​=k=1∑K​λk​Lk​.

λk\lambda_kλk​ 不能只根据各项 Loss 数值大小设置，因为真正影响参数更新的是梯度方向和梯度范数。应记录各项 Loss、关键梯度和最终任务指标，避免某一项长期压制其他目标。

标签噪声与难例

“高 Loss 样本”可能是真难例，也可能是错标、数据损坏或分布外样本。Focal Loss 和 hard mining 会进一步放大这些样本，使用前要先检查数据质量。

Loss 与指标不一致

  • 训练 CE 最低的模型不一定 F1 最高；
  • MSE 最低不一定业务成本最低；
  • Dice 提升不一定意味着边界质量提升；
  • Diffusion MSE 下降不一定意味着生成质量更好。

因此要用 Loss 做优化，用验证集任务指标、校准指标和错误切片做选择。

从训练损失回到线上表现

可能存在训练目标与业务指标不一致、类别/长度加权错误、数据泄漏或域偏移、概率阈值未调、校准变差，或平均指标掩盖长尾失败。应检查切片指标和端到端决策链路。
