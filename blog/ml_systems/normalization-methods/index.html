归一化方法：统计集合、残差位置与部署行为

完整比较 BN、LN、RMSNorm、IN 与 GN 的公式、统计维度与部署差异，连接残差位置、微批量、跨卡通信和混合精度。

W韦君豪约 14 分钟

归一化的名称相似，实际计算可能沿完全不同的维度展开。先确定哪些元素共享统计量，再确定训练与推理时使用哪一组统计量，才能理解它对表示、梯度和部署的影响。另一个独立问题是归一化位于残差子层之前还是之后；方法类型与放置位置需要分别判断。

统计集合决定哪些尺度差异会被消去，残差位置决定梯度经过怎样的路径。两者都必须与具体张量形状和部署方式对应，不能只凭缩写选择实现。

统一公式与统计集合

设某个归一化集合为 SSS，其中共有 mmm 个标量。标准的中心化与方差归一化写成：

μS=1m∑j∈Sxj,σS2=1m∑j∈S(xj−μS)2,\mu_S=\frac{1}{m}\sum_{j\in S}x_j, \qquad \sigma_S^2=\frac{1}{m}\sum_{j\in S}(x_j-\mu_S)^2,μS​=m1​j∈S∑​xj​,σS2​=m1​j∈S∑​(xj​−μS​)2, x^i=xi−μSσS2+ε,yi=γix^i+βi.\hat{x}_i=\frac{x_i-\mu_S}{\sqrt{\sigma_S^2+\varepsilon}}, \qquad y_i=\gamma_i\hat{x}_i+\beta_i.x^i​=σS2​+ε​xi​−μS​​,yi​=γi​x^i​+βi​.

ε\varepsilonε 防止方差过小时除零，γ\gammaγ 和 β\betaβ 是可学习的缩放与平移。不同 Norm 的核心差别不是这条公式，而是集合 SSS 如何选择，以及推理时统计量来自当前输入还是历史滑动平均。

术语提醒：Norm、Normalization 与 Standardization

BatchNorm、LayerNorm 中的 Norm 指 Normalization，不是“向量范数”。传统统计教材有时把缩放到 [0,1][0,1][0,1] 称为 Normalization，把变换到零均值、单位方差称为 Standardization；但深度学习组件的名称已经固定，BatchNorm 和 LayerNorm 实际都包含“减均值、除标准差，再做可学习仿射变换”。描述系统时说明具体公式和统计轴即可，不必纠结中文译名。

历史上常用“缓解 Internal Covariate Shift”解释归一化的作用。更稳妥的工程表述是：它控制中间激活的尺度、改善优化条件，并降低深层网络对初始化和学习率的敏感性；它不能单独保证不会出现梯度消失或爆炸。

快速直觉：只让“可比”的元素共享统计量

可以用课堂成绩作类比，理解统计范围的差别：

方法 统计对象 类比 隐含假设
BatchNorm 同一特征/通道在不同样本中的取值；CNN 中通常还包含空间位置 比较不同学生的同一科成绩 这些值属于相对稳定的同一总体，可以共享 Batch 统计量
LayerNorm 当前样本或当前 token 的整条特征向量 看同一个学生各科成绩的整体尺度 只需校准当前表示的内部尺度，不依赖其他样本

更一般地说，选择归一化轴，就是选择“哪些均值和尺度差异可以被消去”。如果某个轴上的绝对均值或尺度本身承载重要信息，就不应未经验证地沿该轴归一化。γ,β\gamma,\betaγ,β 能恢复可学习的整体缩放和平移能力，但不能逐样本还原已经被归一化去掉的统计量。

这个类比只用于帮助记忆统计轴：Transformer 的隐藏维并不真的对应语义明确的“不同科目”。更准确的实现结论仍然是，对 X∈RB×T×DX\in\mathbb{R}^{B\times T\times D}X∈RB×T×D，LayerNorm 通常分别为每个 (b,t)(b,t)(b,t) 沿 DDD 维计算统计量，而不是把一条序列或整个 Batch 混在一起。

BatchNorm：跨样本估计通道尺度

公式与统计维度

对 X∈RN×C×H×WX\in\mathbb{R}^{N\times C\times H\times W}X∈RN×C×H×W，BN 为每个通道 ccc 计算统计量：

μc=1NHW∑n,h,wxnchw,\mu_c=\frac{1}{NHW}\sum_{n,h,w}x_{nchw},μc​=NHW1​n,h,w∑​xnchw​, σc2=1NHW∑n,h,w(xnchw−μc)2,\sigma_c^2=\frac{1}{NHW}\sum_{n,h,w}(x_{nchw}-\mu_c)^2,σc2​=NHW1​n,h,w∑​(xnchw​−μc​)2, ynchw=γcxnchw−μcσc2+ε+βc.y_{nchw}=\gamma_c \frac{x_{nchw}-\mu_c}{\sqrt{\sigma_c^2+\varepsilon}} +\beta_c.ynchw​=γc​σc2​+ε​xnchw​−μc​​+βc​.

全连接层的 BN 通常对每个特征跨 Batch 求统计量；CNN 中则常同时跨 Batch 和空间维度求统计量。

训练与推理的区别

  • 训练时使用当前 mini-batch 的均值和方差，并更新 running mean、running variance；
  • 推理时通常使用训练阶段累计的 running statistics；
  • 因而 BN 的训练态和推理态行为不同，遗漏 eval() 会导致结果漂移；
  • 优化器看到的“有效 Batch Size”可能很大，但 BN 只看到当前 micro-batch。梯度累积不会自动扩大 BN 的统计样本数。

优点

  • 在 Batch 足够大且样本近似独立同分布时，能稳定通道尺度；
  • 对经典 CNN 训练通常有效，也常带来一定随机正则化效果；
  • 推理时统计量固定，计算可与卷积/线性层融合。

卷积后接 BN：

z=Wx+b,y=γz−μσ2+ε+β,z=Wx+b, \qquad y=\gamma\frac{z-\mu}{\sqrt{\sigma^2+\varepsilon}}+\beta,z=Wx+b,y=γσ2+ε​z−μ​+β,

可在推理部署前折叠为：

W′=γσ2+εW,b′=γ(b−μ)σ2+ε+β.W'=\frac{\gamma}{\sqrt{\sigma^2+\varepsilon}}W, \qquad b'=\frac{\gamma(b-\mu)}{\sqrt{\sigma^2+\varepsilon}}+\beta.W′=σ2+ε​γ​W,b′=σ2+ε​γ(b−μ)​+β.

常见问题

  • 小 Batch 不稳定：均值和方差噪声大；检测、分割等高分辨率任务尤其常见；
  • 分布式统计量不一致：普通 BN 常按每张卡分别统计，SyncBatchNorm 才会跨卡同步，但会增加通信；
  • 域偏移：训练 running statistics 与线上数据分布不同时，推理结果可能退化；
  • Padding 污染：变长序列若直接使用 BN，Padding 可能进入统计量；
  • 非独立样本：视频相邻帧或强相关样本组成 Batch 时，统计量可能偏斜。

Batch 统计带来的噪声与小样本效应

训练时 mini-batch 统计量随采样变化，同一样本的归一化结果会受到同 Batch 其他样本影响，相当于引入噪声。但这只是常见解释，不能把 BN 当作 Dropout 的完全替代。

每个通道的均值和方差估计方差变大，训练统计与最终 running statistics 也可能不稳定。高分辨率视觉任务常因显存限制只能使用很小的 per-device Batch。

LayerNorm：独立校准每个表示

公式与统计维度

对 Transformer 隐状态 X∈RB×T×DX\in\mathbb{R}^{B\times T\times D}X∈RB×T×D，LN 通常对每个 token 的 DDD 个隐藏维度独立计算：

μbt=1D∑d=1Dxbtd,\mu_{bt}=\frac{1}{D}\sum_{d=1}^{D}x_{btd},μbt​=D1​d=1∑D​xbtd​, σbt2=1D∑d=1D(xbtd−μbt)2,\sigma_{bt}^2=\frac{1}{D}\sum_{d=1}^{D}(x_{btd}-\mu_{bt})^2,σbt2​=D1​d=1∑D​(xbtd​−μbt​)2, ybtd=γdxbtd−μbtσbt2+ε+βd.y_{btd}=\gamma_d \frac{x_{btd}-\mu_{bt}}{\sqrt{\sigma_{bt}^2+\varepsilon}} +\beta_d.ybtd​=γd​σbt2​+ε​xbtd​−μbt​​+βd​.

为什么适合 Transformer

  • 从“统计量是否可比”的角度看，BN 若跨样本和 token 统计，会受到 Batch 组成、序列长度、Padding 与位置分布影响；LN 只校准当前 token 的表示尺度；
  • 每个 token 独立归一化，不依赖同一 Batch 中的其他序列；
  • 训练与推理都使用当前 token 的统计量，行为一致；
  • 支持变长序列、小 Batch、梯度累积和自回归逐 token 推理；
  • 不需要维护 running statistics，也不要求跨设备同步统计量。

注意点

  • normalized_shape 决定具体沿哪些尾部维度归一化，不能机械地说“LN 永远对 Channel”；
  • LN 会同时去均值和缩放方差，改变特征整体偏置与尺度；
  • LN 不依赖 Batch，但并不意味着它没有计算和访存成本；在大模型中 Norm、残差和线性层融合仍是常见优化点；
  • 混合精度下常用 FP32 累加均值/方差，再转换回目标 dtype，以降低数值误差。

自回归执行中的统计一致性

LN 在每个样本或每个 token 内直接计算当前特征的统计量，不依赖训练数据总体分布，因此训练和推理可以使用同一种计算。

不是数学上不能，而是通常不合适：序列长度变化、Padding、自回归推理、小 Batch，以及训练/推理统计差异都会增加复杂度。LN/RMSNorm 对每个 token 独立，更符合这些执行条件。

RMSNorm：保留均值，仅缩放均方根

RMSNorm 与 LN 常沿相同的特征维度计算，但不减均值，只按均方根缩放：

RMS⁡(x)=1D∑d=1Dxd2+ε,\operatorname{RMS}(x)= \sqrt{\frac{1}{D}\sum_{d=1}^{D}x_d^2+\varepsilon},RMS(x)=D1​d=1∑D​xd2​+ε​, yd=γdxdRMS⁡(x).y_d=\gamma_d\frac{x_d}{\operatorname{RMS}(x)}.yd​=γd​RMS(x)xd​​.

有些实现带 bias，有些不带；使用时应以具体模型实现为准。

对比项 LayerNorm RMSNorm
是否减均值 是 否

RMSNorm 省去了均值中心化，形式更简单；但不能仅凭公式断言端到端一定更快，实际速度还取决于 Kernel 融合、访存和硬件实现。

它省去减均值步骤，计算图更简单。但模型端到端是否更快取决于硬件、Kernel 融合和整体访存，不能只按少一次求和就断言性能收益。

InstanceNorm 与 GroupNorm：样本内的空间统计

Instance Normalization（IN）

对每个样本 nnn、每个通道 ccc，只在空间维度 H,WH,WH,W 上计算：

μnc=1HW∑h,wxnchw,σnc2=1HW∑h,w(xnchw−μnc)2.\mu_{nc}=\frac{1}{HW}\sum_{h,w}x_{nchw}, \qquad \sigma_{nc}^2=\frac{1}{HW}\sum_{h,w}(x_{nchw}-\mu_{nc})^2.μnc​=HW1​h,w∑​xnchw​,σnc2​=HW1​h,w∑​(xnchw​−μnc​)2.

IN 会弱化每张图像每个通道的整体对比度/风格统计，因此常见于风格迁移和部分图像生成任务。代价是它可能移除对任务有用的实例级强度信息。

Group Normalization（GN）

将 CCC 个通道分成 GGG 组。每个样本内部，对同一组的 C/GC/GC/G 个通道及其空间位置共同计算统计量：

μng=1(C/G)HW∑c∈g,h,wxnchw.\mu_{ng}=\frac{1}{(C/G)HW} \sum_{c\in g,h,w}x_{nchw}.μng​=(C/G)HW1​c∈g,h,w∑​xnchw​.

方差和仿射变换与通用公式相同。GN 不依赖 Batch Size，因此常用于检测、分割、扩散模型等单卡 Batch 很小的视觉任务。

两个边界关系有助于记忆：

  • G=1G=1G=1 时，GN 在每个样本内联合归一化全部通道和空间位置，形式接近特定轴配置下的 LN；
  • G=CG=CG=C 时，每组只有一个通道，形式接近 IN。

“接近”而非始终“完全等价”，因为框架中的仿射参数形状和实际归一化轴配置可能不同。

组数是需要验证的超参数

常见做法是固定组数或固定每组通道数，同时要求能整除通道数。组太少更接近整体 LN，组太多更接近 IN；最优值与通道数和任务有关，需要验证。

方法 典型输入下的统计范围 依赖 Batch 训练/推理是否使用同类统计量 典型场景 主要风险

容易与上述方法混淆的三个概念

L2 Normalization 常用于检索或对比学习中的 embedding：

x^=x∥x∥2+ε.\hat{x}=\frac{x}{\lVert x\rVert_2+\varepsilon}.x^=∥x∥2​+εx​.

它把向量投到单位球面，不减均值、没有 Batch statistics，目的通常是让点积等价于余弦相似度，而不是稳定每层激活分布。

Weight Normalization 重参数化的是权重而不是激活：

w=gv∥v∥2.w=g\frac{v}{\lVert v\rVert_2}.w=g∥v∥2​v​.

它把权重方向 vvv 与尺度 ggg 分离，不属于 BN/LN 这类基于输入统计量的归一化。

Adaptive LayerNorm（AdaLN） 常在条件生成和 DiT 类结构中使用。它仍先做 LN，再由时间步、文本或其他条件 ccc 产生缩放和平移：

y=(1+s(c))⊙LN⁡(x)+b(c).y=\left(1+s(c)\right)\odot\operatorname{LN}(x)+b(c).y=(1+s(c))⊙LN(x)+b(c).

AdaLN 改变的是仿射参数来源，不代表它采用了新的统计维度；具体实现还可能同时调制残差门控。

  • 还有 Sandwich Norm、额外末端 Norm、QK-Norm 等变体，应按具体架构分析。

微批量、并行与部署中的实现细节

Batch Size 与梯度累积

梯度累积扩大的是一次参数更新聚合的样本数，不会让不同 micro-batch 共享 BN 均值和方差。若每卡 micro-batch 很小，可考虑：

  • SyncBatchNorm；
  • 冻结预训练 BN 的 running statistics；
  • 改用 GN，但从预训练 BN 直接替换为 GN 往往需要重新训练或微调验证；
  • 调整采样，让单个 Batch 的分布更有代表性。

分布式训练

  • 普通 BN 通常使用本卡统计量；SyncBN 通过通信聚合统计量；
  • LN、RMSNorm、GN、IN 不跨样本，但张量并行切分到归一化轴时仍可能需要跨卡归约；
  • “不依赖 Batch”不等于“分布式时完全没有通信”。

混合精度

方差计算存在消减误差和溢出风险。常见实现会使用稳定算法并以 FP32 累加统计量。ε\varepsilonε 也不是越大越稳定：过大会明显改变小方差特征的缩放。

Padding 与 Mask

Transformer 的 LN/RMSNorm 对每个 token 的隐藏维独立计算，Padding token 不会进入其他 token 的统计量，但 Padding 位置本身仍要在 Attention 和 Loss 中正确 Mask。若使用跨时间或空间统计的自定义 Norm，则需确认 Padding 是否被排除。

部署与融合

  • BN 在推理时统计量固定，可折叠进前一层；
  • LN/RMSNorm 的统计量依赖当前输入，不能像 BN 一样简单静态折叠；
  • 但可以通过 Fused LayerNorm/RMSNorm、残差融合等 Kernel 优化减少读写开销。

冻结统计量与冻结参数

通常指推理式地使用已有 running mean/variance，并可能同时冻结 γ,β\gamma,\betaγ,β。两种操作不是同一件事，实现与代码审查时应说明到底冻结统计量、仿射参数，还是两者都冻结。

归一化不能替代完整的稳定性设计

不能。Norm 只控制部分激活尺度。残差结构、初始化、学习率、优化器、激活函数、序列长度、混合精度和异常数据仍会导致训练不稳定。
