训练稳定性与知识蒸馏：先定位数值问题，再验证能力迁移

分析残差、归一化、精度与数据引起的训练不稳定，展开不同蒸馏信号及目标函数，并检查教师偏差和学生能力退化。

W韦君豪约 4 分钟

训练损失出现异常与模型能力迁移失败，可能在表面上都表现为指标退化，但需要不同的诊断路径。前者要回到具体批次、激活、梯度和优化器状态；后者要检查教师信号、学生容量与数据覆盖。本文把数值稳定性和蒸馏分别展开，再用分层评估连接两者。

两条链路对应不同问题：数值异常要求找出最先失真的计算或状态；蒸馏则要确认学生学到的内容以及遗漏的能力，不能只用训练损失或平均分数判断。

训练稳定性需要逐层定位

训练不稳定通常来自残差路径的激活/梯度尺度、初始化、归一化位置、学习率、混合精度溢出、异常数据或分布式通信。解决时应先定位 NaN/Inf 或 Loss Spike 出现在哪一层和哪一步，再从归一化、初始化、优化器、精度和数据逐层排查。

关键机制

  1. Pre-LN 与 Post-LN
    Pre-LN 将归一化放在 Attention/FFN 之前，残差主干更接近恒等映射，深层梯度通常更容易传播。Post-LN 可能获得不同表示性质，但对初始化和 Warmup 更敏感。

  2. Norm 类型与位置是两个维度
    RMSNorm 是 LayerNorm 的替代形式，只使用均方根缩放；Pre-LN/Post-LN 描述归一化放在子层前还是后。不能把 RMSNorm 直接当作 Pre-LN 的同义词。

  3. 初始化与残差缩放
    权重过大会造成激活方差逐层积累。可以使用与深度相关的初始化、残差分支缩放、DeepNorm 或类似方案。

  4. 学习率与优化器
    Warmup 让优化器状态和表示在训练早期平稳建立；峰值学习率、Adam 的 β/ε、权重衰减和梯度裁剪也会影响稳定性。

  5. 数值精度
    FP16 指数范围较小，容易 overflow；BF16 通常更稳但尾数更短。需要监控 loss scale、梯度范数、激活最大值和非有限数。

  6. 数据与分布式因素
    异常长样本、极端 token 分布、错误 label、重复/污染数据，以及 All-Reduce 或 Checkpoint 恢复错误，都可能表现为 Loss Spike。

排查顺序

复现具体 step
→ 检查 batch/token/label
→ 记录各层 activation 与 gradient norm
→ 检查 AMP scale、NaN/Inf 和 optimizer state
→ 降低学习率并验证 gradient clipping
→ 对比单卡/小模型/FP32 基线
→ 再排查并行通信与恢复逻辑

从教师信号到学生模型

蒸馏让 Student 学习 Teacher 的输出分布、中间表示或生成结果，而不是只学习硬标签。Teacher 的 soft target 包含类别间或 token 间的相对关系，可以把大模型能力压缩到更小模型中。

常见形式

  1. Logit Distillation
LKD=T2 DKL(softmax⁡(zt/T)∥softmax⁡(zs/T))\mathcal L_{KD}=T^2\,D_{KL} \left( \operatorname{softmax}(z_t/T) \Vert \operatorname{softmax}(z_s/T) \right)LKD​=T2DKL​(softmax(zt​/T)∥softmax(zs​/T))

温度 (T) 越高，分布越平滑，Student 可以看到非最大类别之间的关系。

  1. Feature Distillation
    对齐 Attention map、Hidden State 或特定中间层表示。

  2. Sequence-level Distillation
    Teacher 生成回答或推理轨迹，Student 用 SFT 学习；LLM 中常见 synthetic data distillation。

  3. Preference/Behavior Distillation
    Student 学习 Teacher 的风格、拒答、安全或工具选择行为。

风险与评估

  • Teacher 的偏差和幻觉会进入训练数据；
  • Student 容量不足时会优先丢失长尾能力；
  • 合成数据缺乏多样性可能造成模式坍缩；
  • 只测平均 Benchmark 可能掩盖安全、校准和鲁棒性退化；
  • 使用闭源 Teacher 时还需考虑输出条款和数据授权。
