链表：让每次指针修改都有明确边界

通过反转链表、环入口、分组翻转与 LRU 缓存，解释后继保存、快慢指针、递归承诺和哈希表与双向链表的一致性。

反转链表时，先保存还没有处理的部分

查看图示的文字结构
flowchart TD
 A["prev = 空，curr = 原链表头"] --> B{"curr 非空？"}
 B -->|否| Z["返回 prev：反转后的头"]
 B -->|是| C["先保存 nxt = curr.next"]
 C --> D["令 curr.next 指向 prev"]
 D --> E["prev 移到 curr，curr 移到 nxt"]
 E --> B

修改指针前先保存原后继，是避免丢失剩余链表的关键。每次循环结束后，prev 指向完成部分，curr 指向尚未处理部分。

先识别问题的结构

目标 采用的思路及依据
反转、删除或重排节点 局部修改 next 即可重连；需要提前保存尚未处理的后继节点
判断环、找环入口 快慢指针在环内会因速度差相遇；无环时快指针先走到空节点
K 个一组翻转 可拆成“完整的一组 + 剩余链表”；先确认足够 K 个，再翻转并连接递归结果
LRU 要求按键查找和调整使用顺序均为 O(1) 哈希表定位节点，双向链表提供已知节点的常数时间删除/插入；单链表不能直接找到前驱

把状态和不变量想清楚

  • 画出指针变化再写代码，重点确认“断链前是否保存了后继节点”。
  • 需要修改头节点时，可考虑虚拟头节点；判断环或中点时，优先考虑快慢指针。
  • 递归处理链表时，先明确函数承诺：它接收什么范围，返回哪两个端点，下一段由谁连接。

教学骨架

下面是各模式的伪代码；中文步骤需要按题意实现，不能将它们合成同一个指针循环。

迭代反转：
    pre = None，cur = head
    while cur 非空：
        next_node = cur.next       # 保存未处理部分
        cur.next = pre             # 接入已反转部分
        pre = cur，cur = next_node
    return pre

本篇递归反转 rev(cur, pre)：
    if cur 为空：return pre
    new_head = rev(cur.next, cur)
    cur.next = pre                 # 回溯时连向原前驱
    return new_head

环入口：
    slow = fast = head
    while fast 和 fast.next 非空：
        slow 前进一步，fast 前进两步
        若相遇：一个指针回到 head，两者同步前进一步直到相遇，返回该节点
    return None

K 个一组翻转：
    从 head 找满 K 个节点；不足则 return head
    保存 next_group，翻转本组，得到 new_head 和 new_tail
    new_tail.next = 递归处理(next_group, K)
    return new_head

LRU：
    初始化 key→节点 的字典及双向链表头尾哨兵
    get：未命中返回 -1；命中则移到最前并返回值
    put：已有键更新并移到最前；新键加入字典和链表最前
         若超容量，同时删除链表最后的实际节点及其字典条目

反转过程中，pre 指向已处理部分、cur 指向待处理部分；递归版则由回溯逐步完成改向。LRU 的不变量是“字典与链表包含同一批实际节点，最前是最近使用、最后是最久未用”。

例题一：反转链表

题目链接：LeetCode 206. 反转链表

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # pre = None
        # cur = head
        # while cur:
        #     tmp = cur.next
        #     cur.next = pre
        #     pre = cur
        #     cur = tmp
        # return pre
        
        pre = None
        def rev(cur, pre):
            if not cur: return pre
            res = rev(cur.next, cur)
            cur.next = pre
            return res
        revd = rev(head, pre)
        return revd

实现细节：注释部分是迭代写法；当前实际执行的是递归写法。rev(cur, pre) 表示“把从 cur 开始的链表反转，并让 cur 最终指向 pre”。递归先携带新的前驱进入下一节点，回溯时再执行 cur.next = pre。

递归例子：对 1 -> 2 -> 3 -> None 调用 rev(1, None)：

rev(1, None)
  -> rev(2, 1)
       -> rev(3, 2)
            -> rev(None, 3)，返回节点 3

回溯时依次设置 3.next = 2、2.next = 1、1.next = None，最终返回新头节点 3。

例题二：环形链表 II

题目链接：LeetCode 142. 环形链表 II

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        s, l = head, head

        while True:
            if not l or not l.next: return None
            s = s.next
            l = l.next.next
            if s == l: break
        l = head
        while l != s:
            l, s = l.next, s.next
        return l

实现细节：快指针每次走两步，慢指针走一步。第一次相遇后，把一个指针放回头节点；两者再各走一步，下一次相遇点就是环入口。

为什么：设头到入口为 a，入口到首次相遇点为 b，环长为 c。相遇时快指针比慢指针多走整圈，可推出 a 与“相遇点继续走到入口”的距离相差整圈，所以同步前进会在入口相遇。

例题三：K 个一组翻转链表（困难）

题目链接：LeetCode 25. K 个一组翻转链表

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        def reverse(head, tail):
            pre = tail.next
            cur = head
            while pre != tail: # 关键循环，建议自己画链子 - 先保存旧 next，然后pre接上新next，然后往后 - 其实是链表很通用的过程
                suc = cur.next
                cur.next = pre
                pre = cur
                cur = suc
            return tail, head

        if not head or not head.next: return head
        tail = head
        for _ in range(k - 1): # 找到当前的tail以进入当前修改
            tail = tail.next
            if not tail: return head
        suc = tail.next # 记录下一组的开头
        new_head, _  = reverse(head, tail) # 反转这一组
        head.next = self.reverseKGroup(suc, k) # 递归处理剩余部分
        return new_head

分组与递归到底在做什么

reverseKGroup(head, k) 的承诺是：处理从 head 开始的整条链表，并返回处理后的新头节点。

  1. 先向后走 k - 1 步找到本组 tail；若凑不够 k 个节点，原样返回。
  2. reverse(head, tail) 只翻转闭区间 [head, tail]，返回本组的新头 tail 和新尾 head。
  3. suc = tail.next 保存下一组起点。
  4. head.next = self.reverseKGroup(suc, k) 递归处理后续链表，并把本组新尾接过去。

例子：1 -> 2 -> 3 -> 4 -> 5，k = 2。

  • 第一组 [1, 2] 翻转成 2 -> 1，此时 1 是新尾；
  • 递归处理 3 -> 4 -> 5，得到 4 -> 3 -> 5；
  • 让 1.next 指向递归结果，最终为 2 -> 1 -> 4 -> 3 -> 5。

reverse 中令 pre = tail.next，可以让本组最后翻转出的旧头暂时直接连向下一段；之后递归返回的新头会覆盖这个连接。

例题四：LRU 缓存

题目链接：LeetCode 146. LRU 缓存

class Node:
    def __init__(self, key=0, value=0): # 按照使用顺序排序
        self.key = key
        self.value = value
        self.prev = None
        self.next = None


class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache = {} # O(1)查找

        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _add_front(self, node):
        node.next = self.head.next
        node.prev = self.head

        self.head.next.prev = node
        self.head.next = node

    def get(self, key: int) -> int:
        if key not in self.cache: return -1
        
        node = self.cache.get(key)

        # 刚访问放在一开始
        self._remove(node)
        self._add_front(node)
        return node.value

    def put(self, key: int, value: int) -> None:
        # 1. 已经有只需要更新；
        if key in self.cache:
            node = self.cache.get(key)
            node.value = value

            # 更新位置到一开始
            self._remove(node)
            self._add_front(node)

        # 2.新加入则新建节点；期间如果超过长度则remove tail.prev
        else:
            node = Node(key, value)
            self.cache[key] = node
            self._add_front(node)

            if len(self.cache) > self.capacity:
                old = self.tail.prev
                self._remove(old)
                del self.cache[old.key]

# Your LRUCache object will be instantiated and called as such:
# obj = LRUCache(capacity)
# param_1 = obj.get(key)
# obj.put(key,value)

实现细节：哈希表负责 O(1) 找节点，双向链表负责 O(1) 删除和移动。靠近 head 表示最近使用，tail.prev 表示最久未使用；get 和更新已有键都会把节点移到最前面。
