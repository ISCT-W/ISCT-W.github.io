堆与动态中位数：维护两半的交界

从动态候选的最小值与最大值需求出发，解释优先队列和双堆中位数，重点维护两半数据的大小关系与数量平衡。

W韦君豪约 3 分钟

用两半数据的边界维护中位数

查看图示的文字结构
flowchart LR
 A["新元素"] --> B["按大小关系放入一侧"]
 B --> L["较小一半：最大堆"]
 B --> R["较大一半：最小堆"]
 L <--> S["重新平衡数量"]
 S <--> R
 L --> M["奇数取较多侧堆顶；偶数取两堆顶均值"]
 R --> M

两个堆分别维护较小一半的最大值和较大一半的最小值。除了数量差不超过一，还要始终保证左侧元素不大于右侧元素。

先识别问题的结构

当候选不断加入或移除，并且每次只需要当前最小／最大元素时，堆能避免反复完整排序。若需要动态中位数，则把数据分成较小、较大两半，分别用堆维护两半交界处的元素。堆只保证堆顶最优，内部数组并不整体有序。

核心思路

堆适合反复取得当前最小值或最大值。Python 的 heapq 是小顶堆；需要大顶堆时存负数。

教学骨架

普通优先队列先定义“优先级”，再反复取堆顶。下面是伪代码，“处理候选”等步骤需按题意补全；存储状态对象时可保存 (priority, unique_id, state)，用唯一编号避免相同优先级时比较不可排序的状态对象。

把初始候选按优先级放入堆
while 堆非空:
    取出当前优先级最优的候选
    若采用了保留旧条目的更新策略，先检查它是否过期
    处理候选；若产生新候选，按优先级入堆

双堆中位数单独维护两个不变量：较小半边的所有值 ≤ 较大半边的所有值；较小半边的数量等于另一边或多一个。

插入 x:
    x 先进入较小半边的大顶堆
    把大顶堆最大值移到较大半边的小顶堆，恢复两边大小关系
    若小顶堆数量更多，把其最小值移回大顶堆
查询中位数（至少已有一个数）:
    数量为奇数：取大顶堆堆顶
    数量为偶数：取两堆堆顶的平均值

例题：数据流的中位数（困难）

题目链接：LeetCode 295. 数据流的中位数

import heapq

class MedianFinder:
    # 维护一个最小堆和一个最大堆，保证，最大堆的所有值比最小堆的小且两边堆数量不差超过1，那pop出来的就是中位数
    def __init__(self):
        self.min_heap = []
        heapq.heapify(self.min_heap)
        self.max_heap = []
        heapq.heapify(self.max_heap)

    def addNum(self, num: int) -> None:
        heapq.heappush(self.max_heap, -num) # 先放到大顶堆 - 可以保证大顶堆一定不少于小顶堆，方便维护
        # 数字丢到小顶堆，保证大顶所有数都比小顶小
        heapq.heappush(self.min_heap, -heapq.heappop(self.max_heap))
        # 平衡数量
        if len(self.min_heap) > len(self.max_heap):
            heapq.heappush(self.max_heap, -heapq.heappop(self.min_heap))

    def findMedian(self) -> float:
        # 奇数 则max_heap多一个
        if len(self.max_heap) > len(self.min_heap):
            return -self.max_heap[0]
        
        # 偶数 则每个堆一个
        return (-self.max_heap[0] + self.min_heap[0]) / 2

# obj = MedianFinder()
# obj.addNum(num)
# param_2 = obj.findMedian()

题目思路：大顶堆保存较小的一半，小顶堆保存较大的一半，并维持两个不变量：大顶堆所有值不大于小顶堆所有值；大顶堆数量等于小顶堆或多一个。插入时先经过两个堆完成排序，再做数量平衡。奇数个元素取大顶堆堆顶，偶数个元素取两个堆顶平均值。
