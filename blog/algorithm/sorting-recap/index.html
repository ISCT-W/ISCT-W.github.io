笔试后的排序 recap：六段 Python 代码

笔试遇到排序，才发现自己忘得七七八八了。用六段 Python 代码回顾冒泡、插入、快速、归并、选择和计数排序。

W韦君豪约 3 分钟

笔试里遇到了这些排序算法，才发现自己已经忘得七七八八了。于是把这六段 Python 实现放在一起，简单记一下每种排序在做什么，方便之后回顾。

冒泡排序

def bubble_sort(nums):
    n = len(nums)
    for i in range(n):
        for j in range(n - 1 - i):
            if nums[j] > nums[j + 1]:
                nums[j], nums[j + 1] = nums[j + 1], nums[j]
    return nums

相邻两个数逆序就交换，每轮把当前最大的数推到右边。右侧已经排好的部分不用再看，所以内层循环是 n - 1 - i；这份代码没有提前退出，时间复杂度始终是 O(n2)O(n^2)O(n2)。

插入排序

def insertion_sort(nums):
    for i in range(1, len(nums)):
        x = nums[i]
        j = i - 1
        while j >= 0 and nums[j] > x:
            nums[j + 1] = nums[j]
            j -= 1
        nums[j + 1] = x
    return nums

把左侧看成已经排好的部分，取出当前元素 x，将比它大的数依次右移，再把它插进空位。最坏时间复杂度是 O(n2)O(n^2)O(n2)；如果数组已经有序，则只需 O(n)O(n)O(n)。

快速排序

def quick_sort(nums):
    if len(nums) <= 1:
        return nums

    pivot = nums[len(nums) // 2]
    left = [x for x in nums if x < pivot]
    mid = [x for x in nums if x == pivot]
    right = [x for x in nums if x > pivot]

    return quick_sort(left) + mid + quick_sort(right)

取中间位置的元素作为 pivot，分成小于、等于、大于它的三组，再递归排序左右两组。平均时间复杂度是 O(nlog⁡n)O(n\log n)O(nlogn)，最坏是 O(n2)O(n^2)O(n2)；这里取的是中间位置，不一定是中位数，而且这份实现会新建列表，并非原地排序。

归并排序

def merge_sort(nums):
    if len(nums) <= 1:
        return nums

    mid = len(nums) // 2
    left = merge_sort(nums[:mid])
    right = merge_sort(nums[mid:])

    res = []
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            res.append(left[i])
            i += 1
        else:
            res.append(right[j])
            j += 1

    return res + left[i:] + right[j:]

先把数组不断分成两半，再用两个指针把排好序的左右两边合起来。时间复杂度是 O(nlog⁡n)O(n\log n)O(nlogn)；<= 让相等元素优先从左边取出，最后再接上尚未处理完的一侧。

选择排序

def selection_sort(nums):
    n = len(nums)

    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if nums[j] < nums[min_idx]:
                min_idx = j
        nums[i], nums[min_idx] = nums[min_idx], nums[i]

    return nums

每轮从尚未排序的部分找出最小值，再交换到位置 i。它和冒泡排序的区别是先找最小值、再做一次交换；这份实现的时间复杂度是 O(n2)O(n^2)O(n2)。

计数排序

def counting_sort(nums):
    if not nums:
        return nums

    mn, mx = min(nums), max(nums)
    count = [0] * (mx - mn + 1)

    for x in nums:
        count[x - mn] += 1

    res = []
    for i, c in enumerate(count):
        res.extend([i + mn] * c)

    return res

先统计每个整数出现的次数，再按数值从小到大还原数组；用 x - mn 作为下标，因此也支持负整数。设数值范围 k=max⁡(nums)−min⁡(nums)+1k = \max(nums)-\min(nums)+1k=max(nums)−min(nums)+1，时间复杂度为 O(n+k)O(n+k)O(n+k)；范围很大时，计数数组会占用很多空间。
