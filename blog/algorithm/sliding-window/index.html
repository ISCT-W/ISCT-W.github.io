滑动窗口：扩张、收缩与候选淘汰

通过窗口最大值和最小覆盖子串，区分单调队列与变长覆盖窗口，并说明边界单向移动和候选删除成立的前提。

最小覆盖窗口中的扩张与收缩

查看图示的文字结构
flowchart TD
 Q{"右端还有字符？"} -->|否| Z["返回已记录的最短窗口"]

覆盖满足后继续收缩，直到再少一个字符就不合法。这个过程依赖覆盖条件的单调性；遇到不具备这种结构的问题，不能直接套用双指针。

问题结构与状态设计

  • 要求连续子数组或子串，且移入、移出元素能增量维护窗口信息。定长窗口直接跟随右边界移动；变长窗口还需要证明左右边界能单向移动而不遗漏答案。
  • 最小覆盖子串的依据：扩张不会破坏已经满足的覆盖条件；一旦覆盖，可以不断收缩寻找当前最短解。求最长合法窗口则通常在“不合法时收缩”，更新答案的时机不同。
  • 滑动窗口最大值的依据：新元素更大且位置更靠右时，旧的小元素更早过期，以后不可能成为窗口最大值，可以从候选队尾删除。
  • 仅有“连续区间”还不够：含负数时，扩大窗口不一定增大区间和，“和为 K”不能直接套按大小收缩的窗口，通常改用前缀和。

教学骨架

以下是伪代码，中文操作需替换为具体计数、条件和答案更新。

最短覆盖窗口：
    left = 0，初始化窗口统计
    for right 从左到右：
        加入 s[right]
        while 窗口覆盖全部需求：
            用 [left, right] 更新最短答案
            移出 s[left]
            left += 1

固定长度 k 的最大值：
    初始化双端队列 q（存下标，数值非递增）
    for right 从左到右：
        删除队尾所有比 nums[right] 小的候选
        right 入队尾
        删除队首所有小于 right-k+1 的过期下标
        if right >= k-1：记录 nums[q[0]]

例题一：滑动窗口最大值（困难）

题目链接：LeetCode 239. 滑动窗口最大值

from collections import deque

class Solution:
    def maxSlidingWindow(self, nums, k):
        q = deque()
        ans = []

        # 把窗口内最大数放在queue头，出窗口则pop掉即可
        for r in range(len(nums)):
            while q and nums[q[-1]] < nums[r]:  # 删除比当前小的原素
                q.pop()
            # 已经没有比当前小的原素，因此可以把index加入表
            q.append(r)
            # 检查left是不是在，不在则删除出窗口内容
            if q[0] < r - k + 1:
                q.popleft()
            # 更新
            if r >= k - 1:
                ans.append(nums[q[0]])
        
        return ans

实现细节：q 保存下标，且对应数值从队首到队尾递减。新元素进入时，队尾所有更小元素以后都不可能成为最大值，可以删除；队首若越过窗口左边界也要删除。最终队首始终是当前窗口最大值。每个下标最多进出队一次，时间复杂度为 O(n)。

例题二：最小覆盖子串（困难）

题目链接：LeetCode 76. 最小覆盖子串

from collections import Counter, defaultdict

# 请选择 Python3 提交代码，而不是 Python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        cs = Counter()
        ct = Counter(t)
        ans_l, ans_r = -1, len(s)
        l = 0
        for r, ch in enumerate(s):
            cs[ch] += 1
            # 涵盖则挪左边
            while cs >= ct:
                if r - l < ans_r - ans_l:
                    ans_r, ans_l = r, l
                # 挪动l使得到下一个循环
                cs[s[l]] -= 1
                l += 1
        return "" if ans_l < 0 else s[ans_l: ans_r + 1]

题目思路：右指针先扩大窗口，直到 cs >= ct 表示窗口覆盖了 t 的全部字符及次数；随后不断右移左指针，寻找仍然合法的最短窗口。一旦移除关键字符导致条件不满足，再继续扩大右边界。核心是“先得到可行解，再尽量缩小”。
