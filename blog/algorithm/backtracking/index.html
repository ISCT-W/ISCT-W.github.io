回溯：在选择与撤销之间枚举答案

用回文分割与 N 皇后理解决策树、合法性检查和剪枝，并区分传递新路径与原地修改共享状态时不同的恢复方式。

W韦君豪约 4 分钟

选择、递归与撤销

查看图示的文字结构
flowchart TD
 A["进入当前递归层"] --> B{"已构成完整答案？"}
 B -->|是| C["保存路径副本并返回"]
 B -->|否| H{"还有未尝试的候选？"}
 H -->|否| R["返回上一层"]
 H -->|是| D["取一个候选并检查合法性"]
 D --> V{"合法？"}
 V -->|否| H
 V -->|是| E["修改共享路径 / 棋盘状态"]
 E --> F["递归探索下一层"]
 F --> G["撤销本层修改"]
 G --> H

原地修改共享状态时，递归返回后必须撤销本层操作；如果传递的是新路径副本，则由对象隔离承担这一步。

先识别问题的结构

当题目要求列举所有合法方案，且答案可以逐步选择、每一步有多个候选时，可以把选择过程画成决策树。回文分割的一层决定“下一段在哪里结束”，N 皇后的一层决定“这一行放在哪一列”；不合法的部分方案无法补救时，立即剪枝。

做题顺序

  1. 明确一层做什么，以及哪些状态足以决定下一步候选。
  2. 确定成功结束条件，再枚举候选、检查合法性、递归。
  3. 若原地修改共享路径或棋盘，返回后必须撤销；若每次传新副本，则无需撤销。保存共享路径时也要保存副本。

通用模板

回溯就是在决策树上做深度优先搜索：选择一个候选，递归进入下一层，然后撤销选择。写题时先确定路径 path、下一层起点、合法候选和结束条件。

下面是教学伪代码，中文表示需要按题目补全的步骤；不合法的候选应在递归前跳过。

def backtrack(state):
    if 满足结束条件:
        保存答案
        return

    for choice in 当前可选项:
        做选择
        backtrack(下一状态)
        撤销选择

例题一：分割回文串

题目链接：LeetCode 131. 分割回文串

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        ans = []

        def backtracing(idx, cur):
            if idx >= len(s): 
                ans.append(cur)
                return
            
            for i in range(idx, len(s)):
                candidate = s[idx: i+1]
                if candidate == candidate[::-1]:
                    backtracing(i+1, cur + [candidate])
        
        backtracing(0, [])
        return ans

实现细节：idx 是下一段的起点，循环枚举本段终点 i。只有当前切片是回文串时才递归；cur + [candidate] 创建新路径，因此不需要显式撤销。

例题二：N 皇后（困难）

题目链接：LeetCode 51. N 皇后

class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        # 还是经典回溯，每次放一行直到放到最后一行；放的时候检查同列，左上与右上即可
        board = [['.'] * n for _ in range(n)]
        res = []

        def backtracing(row):
            if row == n: # 走完就是一种成功情况
                tmp = [''.join(i) for i in board]
                res.append(tmp)
                return
            for col in range(n): # 验证是否在这个位置可以放，可以就放并且回溯
                if not self.isValid(board, row, col): continue
                board[row][col] = 'Q'
                backtracing(row + 1)
                board[row][col] = '.'

        backtracing(0)
        return res

    def isValid(self, board, row, col):
        n = len(board)
        
        # 检查同col上方是否有
        for i in range(row):
            if board[i][col] == 'Q': return False

        # 检查右上对角线
        for i, j in zip(range(row - 1, -1, -1), range(col + 1, n, 1)):
            if board[i][j] == 'Q': return False
        
        # 检查左上对角线
        for i, j in zip(range(row - 1, -1, -1), range(col - 1, -1, -1)):
            if board[i][j] == 'Q': return False
    
        return True

题目思路：一行只能放一个皇后，所以递归层数直接表示行号。对当前行枚举每一列，只检查已经放过皇后的上方同列、左上和右上；合法则放置，递归下一行，返回后恢复为 '.'。当 row == n 时说明每行都成功放置，记录棋盘副本。
