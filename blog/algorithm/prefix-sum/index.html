前缀和：把区间问题转成历史状态

用子数组计数、最大子数组和与排除自身乘积，解释应保存次数、最小前缀还是前后缀积，以及更新顺序为何影响正确性。

W韦君豪约 4 分钟

固定右端点后，查找一个历史前缀

查看图示的文字结构
flowchart TD
 I["初始化：历史计数 count[0] = 1"] --> Q{"还有元素？"}
 Q -->|否| Z["返回答案"]
 Q -->|是| A["读入下一个元素，更新前缀和 S"]
 A --> B["查询历史 S-k 的出现次数"]
 B --> C["把次数累加到答案"]
 C --> D["最后再记录当前 S"]
 D --> Q

区间和等于两个前缀之差。先查询、后记录可排除当前前缀和自身配对；初始前缀 0 的一次出现则对应从数组开头开始的区间。

问题结构与状态设计

需要反复计算连续区间的和，或统计满足某种区间和条件的子数组时，考虑前缀和。令 P[i] 表示前 i 个元素之和、P[0] = 0，则半开区间 [l, r) 的和为 P[r] - P[l]；这个恒等式对负数也成立。

题目目标 判断依据 保存什么历史状态
和为 K 的子数组个数 P[r] - P[l] = K，即寻找历史 P[r] - K 各前缀和的出现次数
最大子数组和 固定右端点后，减去最小的历史前缀即可最大化差值 最小前缀和
除了自身以外数组的乘积 排除位置 i 后，剩余元素恰好分成左、右两段 不含自身的前缀积、后缀积

前两种都要先用“此前的前缀”计算答案，再加入当前前缀，避免把空区间算进去。第三种属于前后缀积，不能照搬前缀和相减，也不需要除法，因此可以处理零。

教学骨架

以下是伪代码，中文描述和数学区间表示需按题意实现；最大子数组和默认输入非空。

统计和为 K 的非空子数组：
    prefix = 0，count = {0: 1}，ans = 0
    for x in nums：
        prefix += x
        ans += count.get(prefix-K, 0)
        count[prefix] = count.get(prefix, 0) + 1

求非空子数组最大和：
    prefix = 0，min_prefix = 0，ans = -∞
    for x in nums：
        prefix += x
        ans = max(ans, prefix-min_prefix)
        min_prefix = min(min_prefix, prefix)

排除自身的乘积：
    n = len(nums)，left 和 right 均初始化为 n 个 1
    从左往右：left[i] = left[i-1] * nums[i-1]（i 从 1 开始）
    从右往左：right[i] = right[i+1] * nums[i+1]（i 从 n-2 开始）
    ans[i] = left[i] * right[i]

例题一：和为 K 的子数组

题目链接：LeetCode 560. 和为 K 的子数组

class Solution:
    def subarraySum(self, nums, k):
        # 从左到右扫描，维护当前前缀和 prefix，同时用 count 记录“之前每个前缀和出现过几次”。
        ans = 0
        prefix = 0
        count = {0: 1}

        for num in nums:
            prefix += num

            if prefix - k in count:
                ans += count[prefix - k]

            count[prefix] = count.get(prefix, 0) + 1

        return ans

实现细节：若当前前缀和为 prefix，只要之前出现过 prefix - k，两者之间的子数组和就是 k。{0: 1} 用来覆盖“从数组开头开始的子数组”。

例题二：最大子数组和

题目链接：LeetCode 53. 最大子数组和

class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        max_s = -10000
        min_prefix = 0
        sum_s = 0

        for num in nums:
            sum_s += num # 统计所有
            max_s = max(max_s, sum_s - min_prefix, sum_s)
            min_prefix  = min(min_prefix, sum_s)

        return max_s

实现细节：以当前位置结尾的最大子数组和，等于当前前缀和减去此前最小前缀和。min_prefix 必须在计算答案之后更新，避免错误地选择当前前缀作为区间起点。

例题三：除了自身以外数组的乘积

题目链接：LeetCode 238. 除了自身以外数组的乘积

class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        prefix, suffix = [1] * len(nums), [1] * len(nums)
        res = [0] * len(nums)
        # prefix[0], suffix[-1] = nums[0], nums[-1]
        for i in range(1, len(nums)):
            prefix[i] = nums[i - 1] * prefix[i - 1]
        for j in range(len(nums) - 2, -1, -1):
            suffix[j] = nums[j + 1] * suffix[j + 1]

        for k in range(len(nums)):
            res[k] = prefix[k] * suffix[k]
        return res

实现细节：prefix[i] 是 i 左边所有数的乘积，suffix[i] 是右边所有数的乘积，两者相乘便自然排除了 nums[i]。
