动态规划：状态、依赖与遍历顺序

用两类背包和双序列问题理解状态定义、初始化及转移，重点比较一维压缩后倒序与正序更新如何决定物品能否重复使用。

W韦君豪约 6 分钟

一维背包中，遍历方向决定读取哪一轮状态

查看图示的文字结构
flowchart TD
 A["状态：容量 j 的最优值或可达性"] --> B{"物品可重复使用？"}
 B -->|每件一次| C["j 从大到小"]
 C --> D["读取上一轮的 dp[j-w]"]
 B -->|可以重复| E["j 从小到大"]
 E --> F["允许读取本轮的 dp[j-w]"]

倒序更新避免同一件物品在本轮被重复使用；正序更新则允许刚更新的状态继续参与转移。这是两类背包最容易写错的差别。

先识别问题的结构

将问题拆成状态后，如果不同选择会反复到达相同状态，而且该状态已经包含决定后续结果所需的信息，就可以存下结果避免重复计算。求最优值时还要确认：大问题的最优解能从这些子问题的最优解转移得到。

题目结构 状态与模式 关键依据
每个数最多选一次，问能否凑出目标和 0/1 背包：dp[j] 表示能否凑出 j 只关心可达总和；本轮不能重复使用同一物品
若干面值可反复使用，问凑数所需最少数量 完全背包：dp[j] 表示凑出 j 的最少数量 取一个值后，剩余目标仍是同类子问题
两个字符串的匹配、删除、插入、替换 双序列 DP：dp[i][j] 表示两个前缀的答案 比较末尾字符后，可转向更短前缀

把状态和不变量想清楚

动态规划的四个问题：dp 表示什么、初始值是什么、如何从已知状态转移、按什么顺序遍历才能保证依赖已经计算。

算法骨架

以下按三种模式分别写；目标、物品、转移 等均需按题意定义。压缩成一维数组后，遍历方向决定读到的是上一轮还是本轮状态。

# 0/1 背包：每个物品只能取一次；这里演示可达性
dp[0] = True，其余为 False
for 数值 x in 物品:
    for j 从目标倒序到 x:
        dp[j] = dp[j] or dp[j - x]

# 完全背包：每种物品可以反复取；这里演示最少数量
dp[0] = 0，其余为无穷大
for 数值 x in 物品:
    for j 从 x 正序到目标:
        dp[j] = min(dp[j], dp[j - x] + 1)

# 双序列 DP：dp[i][j] 对应 A[:i] 和 B[:j]
建立 (len(A) + 1) × (len(B) + 1) 的表
按题意初始化空前缀对应的第一行、第一列
for i 从 1 到 len(A):
    for j 从 1 到 len(B):
        比较 A[i - 1] 与 B[j - 1]
        从 dp[i - 1][j]、dp[i][j - 1]、dp[i - 1][j - 1]
        中选择题意允许的转移，写入 dp[i][j]
返回目标状态

例如最长公共子序列的空前缀答案为 0；编辑距离的空前缀答案为另一前缀长度。二维状态不一定能只保留一行，需先确认所有依赖如何保留。

一维动态规划

例题一：分割等和子集

题目链接：LeetCode 416. 分割等和子集

class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        summ = sum(nums)
        nums.sort(key=lambda x: -x)
        if summ % 2 or nums[0] > summ // 2: return False
        dp = [0 for _ in range(summ + 1)]
        dp[0] = 1

        for n in nums:
            for i in range(len(dp) - 1, 0, -1):
                if i >= n:
                    dp[i] = dp[i] or dp[i - n]
        return dp[summ // 2] == 1

实现细节：问题等价于能否从数组中选出若干数，使其和为总和的一半。dp[i] 表示能否凑出和 i；每个数只能使用一次，所以容量必须从大到小更新，避免同一轮重复使用当前数。

        # 背包问题：把东西往背包放（外层东西，内层背包）
        # 背包外圈循环物品，内圈循环背包容量；零一背包遵循内圈从大往小循环，完全背包遵循内圈从小往大循环。
            # 0/1 背包倒序：避免当前物品在同一轮被重复使用。
            # 完全背包正序：允许当前物品在同一轮被重复使用。
            
        dp = [100000] * (n + 1)
        dp[0] = 0
        sqaures = [i * i for i in range(1, int(math.sqrt(n)) + 1)]
        for s in sqaures:
            for j in range(s, n + 1): # 放背包
                dp[j] = min(dp[j], dp[j - s] + 1)
        return dp[n]

实现细节：把每个完全平方数视为可以无限使用的物品，dp[j] 表示组成 j 所需的最少数量。完全背包的容量从小到大更新，因此本轮刚更新的 dp[j-s] 可以继续使用同一个平方数。

二维动态规划

例题三：最长公共子序列

题目链接：LeetCode 1143. 最长公共子序列

class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        # 再长也超不过短的字符串长度
        dp = [[0 for _ in range(len(text1) + 1)] for _ in range(len(text2) + 1)]
        
        for i in range(1, len(dp)): 
            for j in range(1, len(dp[0])):
                if text2[i - 1] == text1[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else: dp[i][j] = max(dp[i][j - 1], dp[i - 1][j])
        return dp[-1][-1]

实现细节：dp[i][j] 表示 text2 前 i 个字符与 text1 前 j 个字符的最长公共子序列长度。末尾字符相同就接在 dp[i-1][j-1] 后面；不同就分别舍弃一个末尾字符并取较大值。

例题四：编辑距离

题目链接：LeetCode 72. 编辑距离

class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        dp = [[i for i in range(len(word1) + 1)] for _ in range(len(word2) + 1)] # 一边长n一边长0的编辑距离一定为n 同理要修轴向
        for i in range(len(dp)):
            dp[i][0] = i
        dp[0][0] = 0 # 用来防止边界问题

        for i in range(1, len(dp)):
            for j in range(1, len(dp[0])):
                if word1[j-1] == word2[i-1]: # 这位一样那么和去掉这位的编辑距离一样
                    dp[i][j] = dp[i-1][j-1]
                else: # 这位不一样就从三种最近可能里取最小再加一即可
                    dp[i][j] = min(dp[i][j-1], dp[i-1][j], dp[i-1][j-1]) + 1
        return dp[-1][-1]

实现细节：dp[i][j] 表示把 word1[:j] 变成 word2[:i] 的最少操作数。字符相同无需操作，取左上角；不同则从删除、插入、替换三个前置状态中取最小值再加一。第一行和第一列表示空字符串与非空前缀之间只能连续插入或删除。

0/1 背包与完全背包的循环方向

  • 0/1 背包：每件物品最多用一次，容量倒序更新。
  • 完全背包：每件物品可以重复使用，容量正序更新。
