二叉树：定义递归返回值与路径边界

通过遍历序列建树、路径总和和最大路径和，区分子树分治、固定起点的向下路径，以及只能返回给父节点的单边贡献。

W韦君豪约 5 分钟

最大路径和中的两种信息

查看图示的文字结构
flowchart TD
 L["L = max(0, 左子树返回值)"] --> N["当前节点"]
 R["R = max(0, 右子树返回值)"] --> N
 N --> A["value + L + R：更新全局答案"]
 N --> P["value + max(L, R)：返回父节点"]

完整路径可以在当前节点连接左右两侧；返回给父节点的路径只能选择一侧，否则会分叉。负贡献可舍弃，但全局答案必须允许所有节点均为负数。

先识别问题的结构

  • 当前问题能拆成左右子树上的同类问题，并可由子树结果合成时，考虑递归分治。先确定函数处理的范围和返回值，才能决定何时访问根节点。
  • 根据遍历序列建树：前序首元素确定根，中序根的位置确定左右子树边界；本题节点值互不相同，才能唯一定位根并递归划分。
  • 统计任意起点、向下延伸的路径：将“选起点”和“从固定起点延伸”分开，保证每条路径只由它自己的起点统计一次。
  • 路径可同时经过左右子树时：当前节点可以组合两侧贡献更新答案，但返回给父节点的只能是一条可继续延伸的分支，否则会产生分叉。

把状态和不变量想清楚

递归前先确定函数返回值的含义。常见两类：返回“以当前节点为端点的单边信息”，或直接返回“当前子树的完整答案”。需要同时使用左右子树的路径时，通常用全局变量记录最终答案。

教学骨架

以下为三类递归的伪代码；中文的划分、构造等操作需按节点类型和区间表示实现。

构造二叉树 build(前序, 中序)：
    if 区间为空：return None
    用前序首元素建立根，在中序中定位根
    按中序左右长度，同步划分两种遍历的左右子树区间
    root.left = build(左前序, 左中序)
    root.right = build(右前序, 右中序)
    return root

统计向下路径：
    extend(node, remain)：          # 必须从 node 开始
        if node 为空：return 0
        return (node.val == remain) + extend(node.left, remain-node.val)
                                   + extend(node.right, remain-node.val)
    all_paths(node, target)：       # 枚举起点
        if node 为空：return 0
        return extend(node, target) + all_paths(node.left, target)
                                    + all_paths(node.right, target)

最大路径和（非空树）：
    ans = -∞
    gain(node)：                   # 返回以 node 为端点的最大单边贡献
        if node 为空：return 0
        left = max(0, gain(node.left))
        right = max(0, gain(node.right))
        ans = max(ans, node.val+left+right)
        return node.val + max(left, right)
    gain(root)，返回 ans

固定起点的路径即使已达到目标和也要继续向下，因为后续可能含零或负数。本篇双层递归最坏为 O(n²)；若需优化，可用 DFS 配合当前根到节点路径上的前缀和计数，并在回溯时撤销计数。

例题一：从前序与中序遍历序列构造二叉树

题目链接：LeetCode 105. 从前序与中序遍历序列构造二叉树

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        if len(inorder) == 0: return
        root = TreeNode(preorder[0])
        mid = inorder.index(preorder[0])

        # 构建子树
        root.left = self.buildTree(preorder[1:mid+1], inorder[:mid])
        root.right = self.buildTree(preorder[mid+1:], inorder[mid+1:])

        return root

实现细节：前序遍历第一个元素一定是根；它在中序遍历中的位置把数组切成左右子树。再按左右子树长度同步切分前序数组并递归构造。

例题二：路径总和 III

题目链接：LeetCode 437. 路径总和 III

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        # 对于单个递归不能够混合带/不带当前节点，因为会导致单个情况被遍历多次！
        def calc_ans(node, remain):
            if not node: return 0
            ans = 0
            if node.val == remain:
                ans += 1
            ans += calc_ans(node.left, remain-node.val)
            ans += calc_ans(node.right, remain-node.val)
            return ans
        
        if not root: return 0
        # 计算包含当前节点的结果
        ans = calc_ans(root, targetSum)

        # 计算不包含当前节点的结果
        ans += self.pathSum(root.left, targetSum)
        ans += self.pathSum(root.right, targetSum)
        return ans

实现细节：calc_ans 统计“必须从当前节点开始”的路径；外层 pathSum 再分别把左右子节点作为新起点，覆盖所有可能起点。

例题三：二叉树中的最大路径和（困难）

题目链接：LeetCode 124. 二叉树中的最大路径和

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        # 和求最大直径基本一样，唯独注意这里的最大值不一定是一整条路径，所以更新最大值的时候计算 max(l + r, l, r, 0) + root.val!
        self.ans = -1000000
        def depth(root):
            if not root: return 0
            l = depth(root.left)
            r = depth(root.right)
            root_val = root.val + max(l, 0) + max(r, 0)
            self.ans = max(self.ans, root_val)
            return max(l, r, 0) + root.val
        depth(root)
        return self.ans

两种路径必须分清

  • depth(root) 的返回值要交给父节点继续连接，因此只能选择左、右中的一条：root.val + max(l, r, 0)。
  • 以当前节点为最高点的完整路径可以同时连接左右两边：root.val + max(l, 0) + max(r, 0)，它只用于更新全局答案，不能返回给父节点，否则路径会分叉。
  • 子树贡献为负时直接取 0，表示不走该分支；但全局答案从很小的数开始，因此全负树仍会选择值最大的单个节点。
