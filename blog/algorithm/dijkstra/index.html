Dijkstra：从最短路到最小体力路径

借助最小体力消耗路径，说明状态、距离、过期堆记录和松弛操作，并解释路径代价从求和改为最大边权时的适用条件。

最小体力路径用 max(当前代价, 新边高度差) 计算候选值。它与求和最短路共享松弛框架，但代价定义不同。

问题结构与状态设计

  • 要求从起点到各状态或终点的最优路径，且到达同一状态后，更差的代价不会使后续转移更有利，可以只保留 dist[state]。
  • 关键依据是：延长路径不会降低已有代价，且同一转移保持代价的优劣顺序。非负边权最短路用 cost + weight；本题的最小瓶颈路径用 max(cost, weight)，两者都满足。普通含负权边的最短路不能直接套用。
  • 每次从最小堆取出当前代价最小的状态，跳过过期记录，再尝试更新邻居。有效状态出堆时，其最优代价已确定，因此目标状态可以在此时提前返回。
  • 若后续选择还依赖剩余次数、钥匙等信息，应把这些信息加入状态，不能只按位置记录距离。

通用模板

以下是流程骨架，其中中文步骤需要按题意实现；核心变化通常在“状态是什么”和“如何计算 new_cost”。

"""
Dijkstra 通用模版：
1. 建图 / 定义状态空间
2. 初始化 dist
3. 起点状态入堆

while heap 非空:
    取出当前 cost 最优的状态

    如果这是过期状态:
        continue

    for 每一个可以转移到的下一状态:
        计算 new_cost

        if new_cost 优于 dist[next_state]:
            更新 dist
            next_state 入堆
"""

例题：最小体力消耗路径

题目链接：LeetCode 1631. 最小体力消耗路径

class Solution:
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
        """
        Dijkstra 通用模版：
        1. 建图 / 定义状态空间
        2. 初始化 dist
        3. 起点状态入堆

        while heap 非空:
            取出当前 cost 最优的状态

            如果这是过期状态:
                continue

            for 每一个可以转移到的下一状态:
                计算 new_cost

                if new_cost 优于 dist[next_state]:
                    更新 dist
                    next_state 入堆
        """
        m, n = len(heights), len(heights[0])
        dists = [[float('inf')] * n for _ in range(m)]
        dists[0][0] = 0

        import heapq
        pq = [(0, 0, 0)] # cost, r, c
        directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]
        while pq:
            cost, r, c = heapq.heappop(pq)
            if cost > dists[r][c]: continue
            if r == m - 1 and c == n - 1: return cost
            for dr, dc in directions:
                nr, nc = r + dr, c + dc 
                if 0 <= nr < m and 0 <= nc < n:
                    edge_cost = abs(heights[nr][nc] - heights[r][c])
                    new_cost = max(cost, edge_cost)
                    if new_cost < dists[nr][nc]:
                        dists[nr][nc] = new_cost
                        heapq.heappush(pq, (new_cost, nr, nc))

        return dists[-1][-1]

代码与模板的对应

  • 状态空间：每个格子 (r, c) 是一个节点，上下左右移动是边。
  • dist：dists[r][c] 表示从起点到该格子的最小体力消耗。
  • 起点入堆：(0, 0, 0) 表示起点当前代价为 0。
  • 过期状态：若 cost > dists[r][c]，说明已有更优路径，直接跳过。
  • 状态转移：边代价是相邻高度差；整条路径的体力为最大边代价，所以 new_cost = max(cost, edge_cost)。
  • 松弛与入堆：当 new_cost 更小时，更新 dists 并把新状态加入最小堆。
