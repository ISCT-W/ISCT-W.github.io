二分查找：证明答案只可能在一侧

从旋转数组最小值和双有序数组中位数出发，解释单调条件、区间含义和边界更新，让每次缩小搜索范围都有明确依据。

W韦君豪约 7 分钟

二分保留的是可能包含答案的区间

查看图示的文字结构
flowchart TD
 A["搜索第一个真：半开区间 [l, r)"] --> B{"l 小于 r？"}
 B -->|否| Z["返回 l；等于 n 表示不存在"]
 B -->|是| M["mid = l + (r-l) // 2"]
 M --> C{"条件在 mid 成立？"}
 C -->|是| D["r = mid，保留最左的真"]
 C -->|否| E["l = mid + 1，排除左侧假值"]
 D --> B
 E --> B

图中使用“寻找第一个满足条件的位置”这一约定。换成其他二分问题时，需要重新定义条件与区间边界，不能直接照搬更新方式。

先识别问题的结构

能够给候选答案排序，并且一次检查就能证明答案只可能在某一侧，才适合二分。常见依据是“条件从不满足到满足只变一次”，或“当前候选太大／太小，所有更大／更小的候选也都不合法”。

  • 旋转数组最小值：无重复元素时，nums[i] <= nums[-1] 在小值段成立、大值段不成立，寻找第一个成立的位置；未旋转时全部成立。
  • 两个有序数组的中位数：二分的是较短数组的分割位置。左侧取太少就右移，取太多就左移，依据是两个数组内部已有序。

把状态和不变量想清楚

二分的核心不是“找中间值”，而是找到一个能排除一半搜索空间的单调条件。循环前先明确搜索区间含义；更新边界时判断 mid 是否仍可能是答案，从而决定保留 mid 还是排除它。

教学骨架

第一种寻找“第一个满足单调条件的位置”。check(i) 需要按题目实现，要求结果形如 False, ..., False, True, ..., True；返回 n 表示没有满足条件的位置。

left, right = 0, n  # 答案在 [left, right]，n 是未找到的哨兵
while left < right:
    mid = (left + right) // 2
    if check(mid):
        right = mid  # mid 仍可能是第一个成立的位置
    else:
        left = mid + 1
answer = left

第二种寻找“满足约束的分割点”，下面是伪代码：

在较短数组的所有分割位置 [0, m] 中搜索
while left <= right:
    i = 中间分割位置
    j = 要求的左半总长度 - i
    if i 太小: left = i + 1
    elif i 太大: right = i - 1
    else: 根据分割两侧的边界值计算答案并返回

边界更新要和搜索目标配套；先写清楚为什么排除一侧，再选择 mid 或 mid ± 1。

例题一：寻找旋转排序数组中的最小值

题目链接：LeetCode 153. 寻找旋转排序数组中的最小值

class Solution:
    def findMin(self, nums: List[int]) -> int:
        # 旋转后的数组是两段升序数组[A, B]构成，其中A的所有元素都大于B的任何元素（注意，如果没旋转则只有一段）；
        # 因此，最小值一定是B的第一个元素（如果没旋转则是A的第一个）
        # 所以用二分查找去找到分界点即可！
            # mid > nums[-1]：m还在A，最小在右半； mid < nums[-1]：m在B，最小在左半；不停缩小最小区间即可
        l, r = 0, len(nums) - 1

        while l < r:
            m = (l + r) // 2
            if nums[m] > nums[-1]:
                l = m + 1
            else: r = m # 为什么保留m而不是m-1？因为m自己可能就是最小值
        return nums[l]

实现细节：用最后一个元素判断 mid 位于旋转前的大值段还是旋转后的小值段。nums[m] > nums[-1] 时最小值一定在右侧；否则 m 自己可能是最小值，因此令 r = m。

例题二：寻找两个正序数组的中位数（困难）

题目链接：LeetCode 4. 寻找两个正序数组的中位数

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        # 核心思想很简单，对两个数组找分界线，使得分界线满足下面要求，然后这两分界线的位置刚好对应中位即可。
        # merged = nums1 + nums2
        # merged.sort()

        # mid = (len(merged) - 1) // 2
        # return merged[mid] if len(merged) % 2 else (merged[mid] + merged[mid + 1]) / 2
    
        """
        问题理解:
        首先，我们需要明确什么是中位数：对于一个有序数组，如果长度是奇数，中位数就是中间那个数；如果是偶数，中位数是中间两个数的平均值。
        对于两个有序数组，我们需要找到合并后的有序数组的中位数。直接合并再找中位数的时间复杂度是O(m+n)，不符合题目要求。我们需要更高效的O(log(min(m,n)))的解法。

        核心思路：二分查找分割线
        我们可以将问题转化为在两个数组中寻找合适的分割线，使得分割线左边的所有元素都小于等于右边的所有元素，并且左右两边的元素数量相等或左边多一个。
        具体来说：
        我们需要在较短的数组上进行二分查找（为了优化时间复杂度）
        对于每个可能的分割位置，计算另一个数组的对应分割位置（见下）
        检查分割线是否满足条件（左边最大值 ≤ 右边最小值）
        根据比较结果调整二分查找的范围

        详细步骤:
        确保第一个数组是较短的：这样我们可以将时间复杂度优化到O(log(min(m,n)))
        定义分割线：分割线将数组分为左右两部分
        对于数组A，分割线在i的位置，左边有i个元素，右边有m-i个元素
        对于数组B，分割线在j的位置，左边有j个元素，右边有n-j个元素

        理想分割条件：
        i + j = (m + n + 1) / 2（确保左边元素数量足够）
        A[i-1] ≤ B[j] 且 B[j-1] ≤ A[i]（左边最大值 ≤ 右边最小值）

        二分查找过程：
        初始化二分查找范围：iMin = 0, iMax = m
        计算i = (iMin + iMax) / 2
        计算j = (m + n + 1) / 2 - i
        根据比较结果调整iMin或iMax
        """
        # 确保nums1是较短的数组
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
        
        m, n = len(nums1), len(nums2)
        imin, imax, half_len = 0, m, (m + n + 1) // 2
        
        while imin <= imax:
            i = (imin + imax) // 2
            j = half_len - i
            
            # 处理边界情况
            if i < m and nums2[j-1] > nums1[i]:
                # i太小，需要增大
                imin = i + 1
            elif i > 0 and nums1[i-1] > nums2[j]:
                # i太大，需要减小
                imax = i - 1
            else:
                # 找到合适的分割线，处理中位数计算
                
                # 计算左半部分最大值
                if i == 0:
                    max_of_left = nums2[j-1]
                elif j == 0:
                    max_of_left = nums1[i-1]
                else:
                    max_of_left = max(nums1[i-1], nums2[j-1])
                
                # 如果总数是奇数，直接返回左半部分最大值
                if (m + n) % 2 == 1:
                    return max_of_left
                
                # 计算右半部分最小值
                if i == m:
                    min_of_right = nums2[j]
                elif j == n:
                    min_of_right = nums1[i]
                else:
                    min_of_right = min(nums1[i], nums2[j])
                
                # 如果是偶数，返回平均值
                return (max_of_left + min_of_right) / 2.0

题目思路

不要真的合并数组，而是在两个数组中各切一刀。目标是让左半部分元素数量等于右半部分，或只多一个，并同时满足：

nums1[i - 1] <= nums2[j]
nums2[j - 1] <= nums1[i]

只在较短数组上二分 i，另一条分割线 j = half_len - i 随之确定：

  • nums2[j - 1] > nums1[i]：i 太小，需要右移；
  • nums1[i - 1] > nums2[j]：i 太大，需要左移；
  • 两者都不成立：分割正确。奇数长度取左半最大值；偶数长度取左半最大值与右半最小值的平均数。

边界分割可能落在数组两端，所以代码分别处理 i == 0、j == 0、i == m 和 j == n。
