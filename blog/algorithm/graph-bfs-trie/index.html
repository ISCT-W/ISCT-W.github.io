图论、BFS 与 Trie：三种不同的问题结构

以腐烂的橘子、课程表和前缀树区分同步扩散、有向依赖与字符串索引，理解队列分层、入度和字符路径各自维护的不变量。

W韦君豪约 6 分钟

这三题在 Hot 100 中同属“图论”分组，但模式不同：腐烂的橘子是多源 BFS，课程表是拓扑排序，Trie 是树形数据结构。

节点相似，维护的状态不同

选择数据结构前先确定状态含义。队列可以出现在不同算法中，但队列里的元素与出队时机并不相同。

问题结构与状态设计

题目提供的依据 选择的模式 必须维护的含义
相邻状态每次转移耗时相同，求最少步数或同步扩散时间；多个起点同时出发 多源 BFS 队列按距离分层；节点首次入队就标记，避免重复传播
有“先完成 A 才能做 B”的有向依赖，问是否能完成或合法顺序 拓扑排序 入度表示尚未满足的依赖数，只有入度为 0 才能处理
反复插入字符串、查完整词和查前缀，可共享相同前缀 Trie 从根走到当前节点的路径表示一个前缀；完整词还需结束标记或额外集合

BFS 的最少步数结论依赖等权转移；拓扑排序的核心是依赖是否满足；Trie 的查询是沿字符路径查找。这三者不能仅因为都出现“节点”就套同一模板。

算法骨架

# 多源 BFS：每一层对应同一时刻
将所有起点标记并入队
时间 = 0
while 队列非空且仍有待到达的目标:
    当前层数量 = len(队列)
    重复当前层数量次:
        取出节点 u
        for u 的每个合法且未访问的邻居 v:
            标记 v，更新剩余目标数，将 v 入队
    时间 += 1
根据剩余目标是否为 0 判断是否全部到达

# Kahn 拓扑排序：建边 A -> B，表示 A 是 B 的前置条件
建立邻接表和入度，将所有入度为 0 的节点入队
已处理数量 = 0
while 队列非空:
    取出节点 u，已处理数量 += 1
    for u 指向的每个节点 v:
        入度[v] -= 1
        if 入度[v] == 0: 将 v 入队
已处理数量 == 节点总数，才说明无环且能全部完成

# Trie：插入和查询都从根开始，每次消耗一个字符
插入(word):
    node = 根
    for 字符 ch in word:
        若 ch 对应的子节点不存在，则创建
        node = node 的 ch 子节点
    标记 node 为单词结尾（或将 word 放入完整词集合）
查询(text, 是否要求完整词):
    从根逐字符向下，任一边不存在就返回 False
    若查前缀，路径走完就返回 True
    若查完整词，还要验证结束标记（或完整词集合）

例题一：腐烂的橘子

题目链接：LeetCode 994. 腐烂的橘子

from collections import deque

class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        # 先找到所有的新鲜橘子记录个数为fresh，并找到所有腐烂橘子在deque进行多源BFS即可。
        fresh = 0
        directions = [[-1, 0], [1, 0], [0, -1], [0, 1]]
        m, n = len(grid), len(grid[0])
        rots = deque()

        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    fresh += 1
                if grid[i][j] == 2:
                    rots.append([i, j])
        minutes = 0
        while rots and fresh:  # 继续条件：有fresh并且还能继续rot
            for _ in range(len(rots)):
                u, v = rots.popleft()
                for d in directions:
                    if 0 <= u + d[0] <= m - 1 and 0 <= v + d[1] <= n - 1 and grid[u + d[0]][v + d[1]] == 1:
                        grid[u + d[0]][v + d[1]] = 2
                        rots.append([u + d[0], v + d[1]])
                        fresh -= 1
            minutes += 1
        return minutes if not fresh else -1

实现细节：把所有腐烂橘子同时加入队列，形成多源 BFS。每轮只处理当时队列中的节点，代表一分钟；新腐烂的橘子留到下一轮传播。最后仍有 fresh 就说明不可达。

例题二：课程表

题目链接：LeetCode 207. 课程表

from collections import defaultdict

class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        # 拓扑排序：
        # 入度为 0 的课，说明它没有先修课，可以直接学。
        # 每次把入度为 0 的课“修掉”，
        # 它指向的下一门课入度 -1。
        # 如果最后所有课都能修完，说明无环。
        
        # 邻接表：graph[b]存所有以b为前置课的课
        graph = [ [] for _ in range(numCourses) ]

        # 入度数组： in_degree[i] 表示i还有多少门前置课没修
        in_degree = [0] * numCourses

        # 建图：[ a, b ] 表示先修b才能修a
        for a , b in prerequisites:
            graph[b].append(a)
            in_degree[a] += 1
        
        # 初始入队所有入度为0的课(没有前置可直接修)
        queue = deque( i for i in range(numCourses) if in_degree[i] == 0 )
        finished = 0

        # 每弹出一门课，代表修完它，把它指向的课入度-1
        while queue:
            x = queue.popleft()
            finished += 1

            for y in graph[x]:
                in_degree[y] -= 1
                if in_degree[y] == 0:
                    queue.append(y)

        # 如果修完的课数等于总课数，说明无环
        return finished == numCourses

实现细节：这是 Kahn 拓扑排序。不断移除入度为 0 的课程；若最终处理数小于课程总数，说明图中有环。剩余节点可能在环上，也可能是被环阻塞的下游节点。

原提交代码按原样保留，但独立运行时还需加入 from collections import deque；defaultdict 在当前实现中没有使用。

例题三：实现 Trie（前缀树）

题目链接：LeetCode 208. 实现 Trie（前缀树）

class Node:
    def __init__(self, val=0):
        self.val = val
        self.next = {}

class Trie:
    def __init__(self):
        self.root = Node()  # 服务于startwith
        self.contents = set()  # 服务于search

    def insert(self, word: str) -> None:
        self.contents.add(word)
        head = word[0]
        if head not in self.root.next.keys():
            new_node = Node(head)
            self.root.next[head] = new_node
        
        head = self.root.next.get(word[0])        
        for i in range(1, len(word)):
            if word[i] in head.next:
                cur_node = head.next[word[i]]
            else:
                cur_node = Node(word[i])
                head.next[word[i]] = cur_node
            head = cur_node
        return

    def search(self, word: str) -> bool:
        return True if word in self.contents else False

    def startsWith(self, prefix: str) -> bool:
        head = self.root
        for i in range(len(prefix)):
            if prefix[i] not in head.next.keys():
                return False
            head = head.next.get(prefix[i])
        return True
    

# Your Trie object will be instantiated and called as such:
# obj = Trie()
# obj.insert(word)
# param_2 = obj.search(word)
# param_3 = obj.startsWith(prefix)

实现细节：每个节点的 next 保存“字符到子节点”的映射。插入时逐字符建路径；startsWith 只需确认路径存在。本文实现另外用 contents 集合完成完整单词查询。
