单调栈：在弹出时确定答案

从每日温度、接雨水到矩阵最大矩形，追踪下标、单调方向和结算时机，解释当前元素怎样确定历史候选的边界。

W韦君豪约 4 分钟

当前元素让历史候选得到答案

查看图示的文字结构
flowchart LR
 A["新的温度 T[i]"] --> B{"比栈顶温度高？"}
 B -->|是| C["弹出下标 j，答案为 i-j"]
 C --> B
 B -->|否或栈空| D["把 i 入栈"]
 D --> E["等待下一个元素"]

每日温度的栈保留尚未找到更暖日子的下标。每个下标最多入栈、出栈各一次，因此总处理量为线性。

先识别问题的结构

  • 要找每个位置左/右侧第一个更大或更小元素，或要用两侧边界计算宽度、面积时，考虑单调栈。
  • 判断能否弹栈，要问：当前元素是否已经确定了栈顶的答案，或让栈顶不再需要保留？例如更高温度确定“右侧第一个更大”；更矮柱子确定矩形不能继续向右延伸。
  • 栈通常保存尚未结算的下标；下标有序，数值按所需方向单调。每个下标最多入栈、出栈一次，因此总时间为 O(n)。
  • 比较符号由“严格更大/更小”决定；相等元素是否弹出要与边界定义一致。本篇温度和接雨水保留相等高度，栈为非递增；矩形保留相等高度，栈为非递减。

核心思路

单调栈维护一个单调递增或递减的序列。当新元素破坏单调性时，持续弹栈，并在弹栈时计算答案。

以下为教学伪代码，中文条件和结算步骤是待按题意替换的占位。

"""
单调栈通用模版：
1. 栈中通常保存下标，方便同时获得元素值、距离和区间宽度
2. 遍历每个元素
3. 当前元素破坏单调性时，不断弹栈并结算答案
4. 当前下标入栈
5. 必要时用哨兵处理栈内剩余元素
"""

stack = []
for i, value in enumerate(nums):
    while stack and 当前元素破坏单调性:
        j = stack.pop()
        根据 i、j 和新的栈顶计算答案
    stack.append(i)

例题一：每日温度（下一个更高温度）

题目链接：LeetCode 739. 每日温度

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        ans = [0] * len(temperatures)
        stack = []  # 尚未找到更高温度的下标；对应温度单调递减

        for i, temperature in enumerate(temperatures):
            while stack and temperature > temperatures[stack[-1]]:
                j = stack.pop()
                ans[j] = i - j
            stack.append(i)

        return ans

对应思路：栈中保存还没找到答案的日期。当前温度更高时，弹出的日期第一次遇到更高温度，距离就是 i - j。

例题二：接雨水

题目链接：LeetCode 42. 接雨水

class Solution:
    def trap(self, height: List[int]) -> int:
        ans = 0
        stack = []  # 下标对应的高度单调递减

        for i, current_height in enumerate(height):
            while stack and current_height > height[stack[-1]]:
                bottom = stack.pop()
                if not stack:
                    break

                left = stack[-1]
                width = i - left - 1
                bounded_height = min(height[left], current_height) - height[bottom]
                ans += width * bounded_height

            stack.append(i)

        return ans

对应思路：弹栈元素是凹槽底部，新栈顶和当前柱子分别是左右边界。本层雨水为 宽度 × 有效高度。

例题三：最大矩形（矩阵版）

题目链接：LeetCode 85. 最大矩形

class Solution:
    def maximalRectangle(self, matrix: List[List[str]]) -> int:
        if not matrix:
            return 0

        heights = [0] * len(matrix[0])
        ans = 0

        for row in matrix:
            for i, value in enumerate(row):
                heights[i] = heights[i] + 1 if value == '1' else 0
            ans = max(ans, self.largestRectangleArea(heights))

        return ans

    def largestRectangleArea(self, heights: List[int]) -> int:
        heights = [0] + heights + [0]  # 两侧哨兵
        stack = []  # 下标对应的高度单调递增
        ans = 0

        for i, current_height in enumerate(heights):
            while stack and current_height < heights[stack[-1]]:
                height = heights[stack.pop()]
                width = i - stack[-1] - 1
                ans = max(ans, height * width)
            stack.append(i)

        return ans

对应思路：把每一行当作柱状图底边，heights[i] 记录该列连续出现 1 的高度。遇到更矮柱子时，弹出的高度不能再向右扩展；新栈顶和当前下标就是它的左右边界。

三题的共同点

  • 每日温度：弹栈时确定“右侧第一个更大元素”。
  • 接雨水：弹栈时用左右边界结算凹槽面积。
  • 最大矩形：逐行转换为柱状图，弹栈时确定当前高度能够覆盖的最大宽度。
