矩阵模拟：用四条边界走完螺旋

用螺旋矩阵解释未访问区域、四边界收缩与转向条件，重点处理只剩一行或一列时可能出现的越界与重复访问。

当只剩一行或一列时，一次转向就可能耗尽剩余区域，所以不能只在外层循环开始时检查边界。

先识别问题的结构

题目给定访问或移动规则，要求按顺序输出或修改矩阵，通常可以直接模拟。本篇螺旋遍历的具体依据是：每访问完一条外边，未访问区域仍能用一个更小的矩形表示，因此只需维护四个边界，不必额外标记每个格子。

把状态和不变量想清楚

先明确状态（位置、方向或边界）、移动规则、访问时机和结束条件。本篇采用四边界收缩：每完成一条边就收缩对应边界，再判断剩余区域是否有效。保持不变量：“四个边界围住的区域恰好尚未访问”，防止最后只剩单行或单列时重复访问。

教学骨架：四边界收缩

以下为非空矩阵的伪代码；“访问一条边”需要展开为相应的遍历循环。其他矩阵模拟题应按其规则选择状态，不一定能用四边界。

top = 0，bottom = 行数-1，left = 0，right = 列数-1
while top <= bottom 且 left <= right：
    访问上边：从左到右；top += 1
    若区域已空：结束
    访问右边：从上到下；right -= 1
    若区域已空：结束
    访问下边：从右到左；bottom -= 1
    若区域已空：结束
    访问左边：从下到上；left += 1

例题：螺旋矩阵

题目链接：LeetCode 54. 螺旋矩阵

class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        ans = []
        top, left, bottom, right = 0, 0, len(matrix) - 1, len(matrix[0]) - 1

        while top <= bottom and left <= right:
            if top <= bottom:
                for i in range(left, right + 1):
                    ans.append(matrix[top][i])
                top += 1
            if left <= right:
                for j in range(top, bottom + 1):
                    ans.append(matrix[j][right])
                right -= 1
            if top <= bottom:
                for k in range(right, left - 1, -1):
                    ans.append(matrix[bottom][k])
                bottom -= 1
            if left <= right:
                for l in range(bottom, top - 1, -1):
                    ans.append(matrix[l][left])
                left += 1

        return ans

实现细节：按上、右、下、左的顺序遍历一圈，并分别更新 top/right/bottom/left。额外的边界判断用于避免单行或单列在最后一圈被重复访问。
