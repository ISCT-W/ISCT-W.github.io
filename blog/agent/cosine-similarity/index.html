检索分数为什么都在 0.9 附近？从余弦相似度到 Agent 的证据判断

区分高维集中、共同方向、训练温度与分数转换，解释为什么高余弦不等于可靠证据，并给出 Agent 检索的检查方法。

W韦君豪约 7 分钟

做 Agent 的知识检索时，可能会看到这样的结果：第一条得分 0.93，第二条 0.92，后面几条也都在 0.9 左右。看起来每条都很相关，但点进去读，才发现有些只是话题相近，并不能回答问题。

这很容易让人想到“维度灾难”：是不是 embedding 的维度太高，余弦相似度就失去了区分能力？

需要把两件事分开：分数为什么集中，以及为什么集中在一个很高的位置。 高维几何可以解释特定条件下的集中现象，但不能直接解释 0.9。

高维随机向量，余弦其实接近 0

余弦相似度衡量两个非零向量的方向是否接近：

cos⁡(x,y)=x⊤y∥x∥∥y∥\operatorname{cos}(x,y)=\frac{x^\top y}{\|x\|\|y\|}cos(x,y)=∥x∥∥y∥x⊤y​

对于单位向量，它就是内积。

如果 x,yx,yx,y 独立且均匀地分布在 ddd 维单位球面上，那么：

E[x⊤y]=0,Var⁡(x⊤y)=1d\mathbb E[x^\top y]=0,\qquad \operatorname{Var}(x^\top y)=\frac1dE[x⊤y]=0,Var(x⊤y)=d1​

这个结果可以直接从旋转对称性理解：固定一个向量的方向，内积就相当于另一个随机单位向量在该方向上的坐标。各个坐标地位相同，平方和为 1，因此每个坐标的二阶矩是 1/d1/d1/d。

在 1024 维中，内积的标准差只有约 0.031。维度越高，两个随机方向越容易接近垂直，余弦越集中在 0 附近。球面随机夹角的研究对这一现象给出了严格结果。Cai、Fan 与 Jiang，2013

这里的前提不能省略：独立、均匀、单位球面。真实文本 embedding 是训练得到的，通常不满足这些假设。向量有多少维，本身不足以告诉我们它的相似度分布。

共同方向可以把分数整体抬高

理解高分基线，可以先看一个简化模型。设：

x=α u+1−α ax=\sqrt{\alpha}\,u+\sqrt{1-\alpha}\,ax=α​u+1−α​a y=α u+1−α by=\sqrt{\alpha}\,u+\sqrt{1-\alpha}\,by=α​u+1−α​b

其中 u,a,bu,a,bu,a,b 都是单位向量，a,ba,ba,b 与 uuu 垂直。两个向量都包含共同方向 uuu，而 a,ba,ba,b 表示各自不同的部分。

这时：

cos⁡(x,y)=α+(1−α)a⊤b\operatorname{cos}(x,y)=\alpha+(1-\alpha)a^\top bcos(x,y)=α+(1−α)a⊤b

如果差异部分 a,ba,ba,b 独立、均匀地分布在垂直于 uuu 的高维单位球面上，a⊤ba^\top ba⊤b 就会接近 0。当 α=0.9\alpha=0.9α=0.9 时，两个向量的余弦便会集中在 0.9 附近。

这个例子把两个作用拆开了：共同方向决定高分基线，差异部分的高维分布决定波动大小。 它只是一个数学示例，不代表真实模型都可以按固定比例拆成这两部分。

早期研究确实在 BERT、ELMo 和 GPT-2 的上下文词表示中观察到了明显的方向偏置，也就是通常讨论的各向异性。但这不能推广成“所有 Transformer 的表示都挤在同一个方向”；后续研究已经给出了反例。Ethayarajh，2019；Anisotropy is Not Inherent to Transformers，2024

还要注意，平均余弦高低并不能完整描述各向异性。即使向量只分布在一条直线的正反两个方向，只要两边对称，平均余弦也可以为 0。

训练时，小分差也能产生很强的区分信号

E5 的官方 FAQ 明确提到：其余弦分数分布在 0.7–1.0 是预期行为，并将这一现象与 InfoNCE 对比学习使用的低温度 0.01 联系起来。E5 官方说明

对比学习中，一个正样本对应的损失可以写成：

L=−log⁡exp⁡(s+/τ)∑jexp⁡(sj/τ)L=-\log\frac{\exp(s_+/\tau)}{\sum_j\exp(s_j/\tau)}L=−log∑j​exp(sj​/τ)exp(s+​/τ)​

其中 sjs_jsj​ 是 query 与候选的相似度，τ\tauτ 是温度。

假设正负样本的相似度只差 0.05，温度为 0.01，那么两者指数项的比值是：

exp⁡(0.050.01)=e5≈148\exp\left(\frac{0.05}{0.01}\right)=e^5\approx148exp(0.010.05​)=e5≈148

因此，肉眼看起来很小的分差，也可以在训练目标中产生明显区别。

不过，这个计算只能说明温度如何放大分差，不能推导出低温度必然让余弦集中在 0.9。具体分数分布还受到数据、模型和完整训练过程的影响。

对固定 query，将所有候选分数加上相同常数，也不会改变上面的 softmax。这说明该目标没有直接规定“0.9 应当对应多少相关概率”。它产生的是候选间的相对竞争，而不是天然校准的置信度。

还有两个更直接的原因：分数转换和 Top-K

在讨论向量几何前，先确认界面显示的究竟是什么。

例如，Elasticsearch 的 dense_vector 在使用 cosine 相似度时，文档 _score 的计算方式是：

_score=1+cos⁡(q,d)2\text{\_score}=\frac{1+\operatorname{cos}(q,d)}2_score=21+cos(q,d)​

在这个配置下，显示的 0.9 对应原始余弦 0.8。这个转换还会把分差缩小一半。不同查询方式可能使用不同评分，因此应核对实际配置，不能把所有名为 score 的字段都当成原始余弦。Elasticsearch 官方文档

另一方面，检索结果通常只展示 Top-K。假设整个文档库的分数分布很宽，取其中最高的几条，它们也可能恰好落在一个很窄的区间。重复内容或高度重叠的分块，还可能让这些候选更加相似。

所以，“返回的十条都在 0.9 附近”和“随机抽取的无关文档也都在 0.9 附近”，需要分别检查。

对 Agent 来说，关键是文档能否支持回答

下面是一个示意例子，并非真实模型测量：

候选文档 余弦分数 实际内容
A 0.93 包含问题所需的明确结论
B 0.92 讨论同一主题，但缺少答案
C 0.91 适用版本不同，不能直接引用

三个分数都很高，但作为证据的价值差别很大。语义接近并不保证满足问题中的版本、时间、条件，也不保证文档支持 Agent 最后写出的结论。

检查检索系统时，我会依次看：

  1. 确认分数定义。 手动计算少量向量对的原始余弦，与检索服务返回值比较。
  2. 检查输入处理。 query 与文档是否使用配套模型、正确的前缀和 pooling，关键内容是否被截断。例如 E5 明确要求按任务使用相应前缀。E5 使用说明
  3. 比较不同类型的候选。 同时观察随机文档、真正相关文档，以及“同主题但不能回答”的困难负样本，而不只看已经筛过的 Top-K。
  4. 分别评估排序与拒答。 用 Recall@K、MRR 或 nDCG 检查召回和排序；需要判断“没有足够证据”时，另外准备无答案查询，在验证集上选择阈值，并用留出的测试集确认效果。

如果正确答案已经被召回，但排位不理想，可以评估 reranker。它能够联合读取问题和文档，做更细致的相关性判断，但重排分数仍不应未经校准就解释成回答正确率。

也没必要为了让分数更分散，直接对所有向量做白化或降维。L2 归一化本来就不会改变余弦；单调地拉伸分数不会改变排序；中心化、白化和降维则会改变几何结构，是否有益必须通过任务评测判断。关于各向异性的研究也表明，“越均匀越好”并不是普遍规律。Stable Anisotropic Regularization

当检索结果全挤在 0.9 附近时，值得检查的是分数的含义、相关与无关文档的区分程度，以及候选是否真正支持回答。余弦相似度适合帮助 Agent 找到值得阅读的材料；材料能否成为证据，还需要进一步判断。
